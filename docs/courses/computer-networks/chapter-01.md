| 点对点式网络 | 建立通信的两台计算机之间由一条物理信道相连，其他计算机不检测该分组 | 简答 |

| 语义 | 规定通信需要发出的控制信息、完成的操作动作和响应 | 填空 |
| 同步 | 网络事件实现顺序的详细说明 | 填空 |

| 可靠性 | 网络尽可能长时间稳定运行、故障时及时恢复并把损失减小的能力，靠增加冗余度提高 | 简答 |

### 必背清单

**第 1 节**

1. 【考纲 1.1】计算机网络从资源共享角度的定义：以能够相互共享资源的方式互联起来的自治计算机系统的集合。
2. 【考纲 1.2】最初的网络雏形是以单台计算机为中心的远程联机系统，代表是 IBM 的 SABRE-1 订票系统；终端不是真正的计算机，不能处理数据，要分时使用中央计算机，且每个终端独占一条通信线路。
3. 【考纲 1.3】真正意义上的计算机网络以美国 ARPANET 的建成为标志，采用分组交换技术，最初 4 个结点分别位于加州大学洛杉矶分校、加州大学伯克利分校、斯坦福研究院和犹他大学；1975 年接入 100 多个结点、结束实验阶段，1990 年被 NSFNET 代替。
4. 【考纲 1.4】ARPANET 的六条贡献：完成对计算机网络定义和分类方法的研究；提出资源子网和通信子网的结构概念；提出并实现分组交换技术；采用层次结构的网络体系结构和研究方法；促进 TCP/IP 模型的研究和应用；为 Internet 的形成和发展奠定基础。

**第 2 节**

5. 【考纲 2.1】按覆盖范围分局域网、城域网、广域网和互联网；局域网区别于其他网络的三方面是覆盖的物理范围、使用的传输技术和网络的拓扑结构。
6. 【考纲 2.2】五种拓扑结构：总线型、环形、星形、树形和网状；树形是星形的特例，把结点通过多级处理主机分层相连，比星形更节省线路成本。
7. 【考纲 2.3】总线型节省线路、结构简单、价格便宜，但不能同时支持多个结点通信，线路一处故障全网不能运行；环形一次通信的最大延迟固定、控制机制简单，一处故障全网不能通信。
8. 【考纲 2.4】星形以一台数据设备为中心，其他结点必须经中心转发，局部故障不影响全网，但对中心处理机性能要求高、线路利用率低；网状两个结点可直接通信或经其他结点转接，局部故障不影响全网、可靠性强，但结构复杂、不易管理和控制。
9. 【考纲 2.5】按介质分有线网络与无线网络：有线导向性强、带宽通常较宽、受外界干扰小、不易被监听和截获，但布线成本高、受线路布局制约；无线不受地点限制，但导向性差、易受干扰和衰落、传输带宽较小。
10. 【考纲 2.6】按所有权分公用网与专用网；按逻辑功能分通信子网与资源子网；按传输技术分广播式与点对点式，传统以太网是典型的广播式网络，基于 TCP/IP 的 Internet 属于点对点式网络。

**第 3 节**

11. 【考纲 3.1】按物理性质分硬件设备和软件设备：硬件主要包括计算机、服务器、交换机、路由器和通信介质，软件主要包括网络协议、网络操作系统和应用程序。
12. 【考纲 3.2】按逻辑位置分终端设备和网络中间设备：终端设备用于数据输入输出和处理，是资源和服务的提供者；中间设备用于传输、交换、路由和控制。
13. 【考纲 3.3】交换机是某种交换式网络内部的核心装置，负责网络内部数据的调度和转发，按处理的协议层次分为二层交换机和三层交换机。
14. 【考纲 3.4】路由器连接 IP 网络中不同类型的网络，为不同格式的数据分组选择通信路径并转发；交换机实现某种网络内部的数据存储转发，路由器在不同网络之间实现数据的路由和中转。
15. 【考纲 3.5】网络协议的三要素是语法、语义和同步；网络操作系统分任务型与通用型，代表有 Novell 的 Netware 与 Microsoft 的 Windows NT、Windows Server 系列。

**第 4 节**

16. 【考纲 4.1】定量的性能指标四项：速率、带宽、端到端延迟和吞吐量；非定量的性能指标六项：QoS、可靠性、可扩展性、安全性、标准化和成本。
17. 【考纲 4.2】发送延迟是终端或网络中间结点发送数据分组的时间；传播延迟是承载数据的电磁波信号在信道中传播所消耗的时间；处理延迟是分析处理分组的时间；排队延迟是在路由器上排队等待转发的时间。
18. 【考纲 4.3】网络情况良好时处理延迟和排队延迟都较小，总延迟主要由发送延迟决定；网络拥塞时处理延迟和排队延迟大大增加，可能在总延迟中占主导地位。
19. 【考纲 4.4】可靠性最直接的提高方法是增加网络的冗余度，即完成某种网络功能或服务时应有不止一个设备，故障时可迅速启用备用设备。

**第 5 节**

20. 【考纲 5.1】五大功能：实现数据通信、提供资源共享、提高计算机系统的可靠性、进行分布式处理、对分散对象提供集中控制与管理。
21. 【考纲 5.2】数据通信是计算机网络最基本的功能，其他功能都建立在数据通信功能之上；分布式处理可减轻主处理器负担并降低主机和链路成本，同时提高网络可靠性。

**第 6 节**

22. 【考纲 6.1】对应关系：ISO 制定开放系统互联参考模型 OSI，把网络分成 7 个层次；ITU 制定的 X 系列标准包括 X.25；EIA 制定数字设备之间串行通信的接口标准 RS-232；IEEE 制定局域网技术的 IEEE 802 系列标准。
23. 【考纲 6.2】标准不是具体的软硬件产品，而是对某种技术或产品的功能、结构或形态的描述和定义，以文字形式存在；按制定和使用标准的组织性质分为企业标准、行业标准、国家标准和国际标准。

### 必背数字与公式

| 项目 | 必背内容 |

| 字节与比特 | $1\text{ B}=8\text{ bit}$，1200 B 的分组即 9600 bit |

| 传播延迟 | 距离 $\div$ 信号传播速度，单位 s |
| 端到端延迟 | 发送延迟＋传播延迟＋处理延迟＋排队延迟 |

| 标准组织数 | ISO、ITU、EIA、IEEE 共 4 个 |

### 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 发送速率与传输速率 | 前者是每秒发出的比特数，后者是每秒传播的千米数 | 看单位是 bit/s 还是 km/s |
| 信道带宽与信号传输带宽 | 前者是信道固有特性、只与介质有关；后者是业务信号最高与最低分量之差 | 说的是信道本身还是某一路信号 |
| 模拟带宽与数字带宽 | 模拟系统用 Hz 描述频率范围，数字系统用 bit/s 描述传输能力 | 看单位与语境 |
| 通信子网与资源子网 | 前者管传输、转发、交换和路由，后者管数据处理与服务 | 对象是通信控制处理机还是主机 |
| 总线型与环形 | 总线是一条公共线路、同一时刻只能两个结点通信；环形把终端连成闭合环，最大延迟固定 | 线路是否闭合 |
| 星形与树形 | 树形是星形的特例，用多级中心处理机分层相连 | 有几级中心处理机 |
| 广播式与点对点式 | 广播式各站都要检测分组目的地址；点对点式其他计算机不检测 | 其他计算机是否参与判断 |
| 局域网与广域网 | 局域网最常使用共享信道；广域网采用交换技术，通过交换结点连接 | 是否经过交换结点 |
| 语法、语义与同步 | 语法管格式，语义管含义和动作，同步管事件顺序 | 问的是“怎么讲”“讲什么”还是“先后” |

### 简答答题模板

**计算机网络的定义（从资源共享角度）**

一句话：计算机网络是以能够相互共享资源的方式互联起来的自治计算机系统的集合。补两点：参与互联的计算机本身具有处理能力；共享的对象包括硬件、软件和信息资源。

**ARPANET 对推动计算机网络理论和技术发展的作用**

六条按顺序写：完成定义和分类方法研究；提出资源子网与通信子网的结构概念；提出并实现分组交换技术；采用层次结构的网络体系结构和研究方法；促进 TCP/IP 模型的研究和应用；为 Internet 的形成和发展奠定基础。

**网络协议包括的基本要素**

三要素各一句：语法规定数据与控制信息的分组结构或格式；语义规定通信需要发出的控制信息、完成的操作动作和响应；同步是网络事件实现顺序的详细说明。

**端到端延迟的组成**

四部分各一句：发送延迟是发送分组的时间；传播延迟是电磁波信号在信道中传播的时间；处理延迟是分析处理分组的时间；排队延迟是在路由器上等待转发的时间。网络良好时由发送延迟决定，拥塞时后两部分可能占主导。

**带宽在模拟通信系统与数字通信系统中的含义**

模拟系统有信道带宽和信号传输带宽两个概念，前者是信道能通过的模拟信号最高频率与最低频率之差，后者是业务信号最高分量与最低分量之差，单位都是 Hz。数字系统中带宽表示通信线路传送数据的能力，即单位时间能通过的最高数据量，单位 bit/s。

**四个标准化组织及其代表标准**

ISO 制定 OSI 参考模型；ITU 的 X 系列标准包括 X.25；EIA 制定串行通信接口标准 RS-232；IEEE 制定 IEEE 802 系列局域网标准。组织名、标准名与具体产品是三类不同对象。

## 1 网络的形成与资源共享 {#s1}

**必背：** 计算机网络是以能够相互共享资源的方式互联起来的自治计算机系统的集合；它的出现以 ARPANET 的建成为标志，ARPANET 提出了资源子网与通信子网的结构概念并实现了分组交换。

网络把能够独立工作的自治计算机连接起来，使它们可以交换数据、共享资源。关键不只是存在多台机器，还要有连接、通信规则和共享能力。早期远程联机系统由终端使用中央计算机的处理能力；计算机网络则允许参与节点本身具有处理能力。

复习发展过程时，抓住“单机与远程终端—分组交换网络—不同网络互联”的变化。ARPANET 推动了分组交换、分层研究以及通信子网与资源子网的结构思想，也为 TCP/IP 的研究应用和 Internet 的形成提供了条件。不要把某一项技术的产生与整个互联网在一次事件中建成混为一谈。

## 2 分类维度与拓扑结构 {#s2}

**必背：** 分类先认依据：按覆盖范围分局域网、城域网、广域网、互联网；按介质分有线与无线；按所有权分公用网与专用网；按拓扑分总线、环形、星形、树形、网状；按逻辑功能分通信子网与资源子网；按传输技术分广播式与点对点式。

给网络分类先说依据。同一网络可以同时是局域网、有线网和专用网，几个名称并不互相排斥。局域网侧重较小范围内的设备连接；城域网与广域网覆盖更大地域；互联网把不同网络连接起来。覆盖范围不能直接决定某条链路的实际速率。

| 分类依据 | 需要分清的对象 |
| --- | --- |
| 介质 | 有线：双绞线、同轴电缆、光纤；无线：空间传播 |
| 所有权与用途 | 公用网面向社会用户；专用网面向特定组织或用途 |
| 拓扑 | 总线、环形、星形、树形、网状 |
| 逻辑职责 | 通信子网传输交换路由；资源子网信息处理服务 |
| 传输技术 | 广播式共享信道按址接收；点对点式逐段传送 |

判断：一间机房的终端都连接中心交换机，物理连接可以画成星形；如果同时存在其他上行链路，整个校园的拓扑还需另画，不能拿一小段图概括全网。星形的单条支线故障与中心设备故障，影响范围不同；网状提供更多路径，但设备、线路和管理代价也增加。

## 3 硬件、协议与网络操作系统 {#s3}

**必背：** 硬件是计算机、服务器、交换机、路由器和通信介质，软件是网络协议、网络操作系统和应用程序；网络协议的三要素是语法、语义和同步。

沿一次通信识别组成：终端发起或接收应用数据，传输介质承载信号，交换机在相应网络内部转发，路由器连接 IP 网络并选择下一跳。服务器强调提供服务的角色，不是与所有终端截然不同的物理物种。

硬件连接只是基础。网络协议规定格式、动作和顺序；网络操作系统在资源管理之上提供通信与共享服务；应用程序把这些能力组织成用户可使用的功能。例如，能看到网卡不代表已经有可用的文件共享服务，还需要协议配置、服务进程和适当的访问权限。区分组件时，可以分别问“谁承载、谁转发、谁规定规则、谁提供服务”。

## 4 速率、带宽、吞吐量与延迟 {#s4}

**必背：** 定量的性能指标是速率、带宽、端到端延迟和吞吐量，非定量的性能指标是 QoS、可靠性、可扩展性、安全性、标准化和成本；端到端延迟=发送延迟＋传播延迟＋处理延迟＋排队延迟。

速率通常用 bit/s 表示；模拟信道的带宽描述频率范围，单位为 Hz；数字网络也用带宽表示额定传输能力，单位为 bit/s。遇到“带宽”先看语境和单位。吞吐量是实际观测到单位时间通过的数据量，不能把标称速率直接抄成实测结果。

端到端延迟分为发送延迟、传播延迟、处理延迟和排队延迟。发送延迟为分组位数除以发送速率；传播延迟为距离除以信号传播速度。提高发送速率可以缩短前者，却不会按相同比例缩短后者。排队延迟还取决于当时负载，不能只由链路长度求出。

单链路模型：1200 B 分组、12 Mbit/s 发送速率、300 km 距离、传播速度 $2×10^8$ m/s，忽略处理与排队。发送为 0.8 ms，传播为 1.5 ms，最后一位到达需要 2.3 ms。这里 B 为字节，Mbit/s 按十进制换算。

评价网络还要看 QoS、可靠性、可扩展性、安全性、标准化与成本。QoS 关注不同业务的服务要求；冗余可以帮助故障恢复，但有建设和运维代价。这些维度不能仅靠一个“网速”数字替代。

## 5 功能与应用之间的关系 {#s5}

**必背：** 五大功能是实现数据通信、提供资源共享、提高计算机系统的可靠性、进行分布式处理、对分散对象提供集中控制与管理，其中数据通信是其他功能的基础。

数据通信让信息从一个节点到另一个节点，是资源共享、分布式处理和集中控制的基础。共享可以是打印机等硬件、应用软件或文档信息；分布式处理把任务交给不同计算机；集中控制则从统一管理点协调分散对象。它们可以在一个系统中同时存在。

学校把课程资料放在服务器上，学生下载属于数据通信和信息共享；几台计算机分担资料处理属于分布式处理；管理员从控制台统一调整设备配置属于集中控制。多个节点互为后备还可提高服务可靠性，但“连网”本身不自动生成备份和故障切换。

## 6 标准组织与互操作 {#s6}

**必背：** 四个组织对应四类标准：ISO 制定 OSI 参考模型，ITU 的 X 系列标准包括 X.25，EIA 制定串行接口标准 RS-232，IEEE 制定 IEEE 802 系列局域网标准。

标准约定技术接口和行为，产品则实现这些约定。两家设备能否互通，要核对它们实现的具体规则，不能只看品牌或接口外形。制定共同标准有助于独立制造的设备互相通信，也方便分层研究和维护。

按本版教材记忆四组对应关系：ISO 对应 OSI 参考模型；ITU 的 X 系列中包括 X.25；EIA 的串行接口工作可联系 RS-232；IEEE 的局域网标准可联系 IEEE 802。组织名、标准名与具体设备是三类不同对象。这里列的是教材范围内的代表联系，不是各组织全部工作的清单。

## 本章小结

- 网络分类按范围、介质、所有权、拓扑等分别判断；同一系统可以同时具有多个标签，设备与协议也不是同类对象。
- 发送延迟=分组位数÷发送速率，传播延迟=距离÷传播速度；吞吐量还受负载、协议和设备约束，不能由标称带宽直接推出。
- 把应用功能落实到资源共享、通信、分布式处理或集中控制，再按标准和接口核对互操作；一个速率数字无法覆盖可靠性、安全和成本。

## 练习

**1. 资料室从“所有终端借用一台主机计算”变成“多台独立计算机共享文件”。说明自治性与共享各体现在哪里，并说出 ARPANET 与分组交换、TCP/IP 的联系。**

考点：第 1 节；层次：识记。

**答案：** 后者的计算机本身可以处理任务，通过网络交换和共享文件；前者的终端主要依赖中央主机。ARPANET 推动分组交换和分层体系研究，促进 TCP/IP 应用，并为不同网络互联奠定基础。

**2. 给“学校所有的机房，终端用双绞线接中心交换机”同时写出三个分类标签。中心故障与一条终端支线故障为何应分开分析？**

考点：第 2、3 节；层次：领会。

**答案：** 可按范围、介质、所有权分别描述为局域网、有线网络、专用网，局部物理拓扑为星形。中心承担各支线间转发，中心故障可能影响整个局部网络；单条支线故障通常直接影响该支线终端。还需区分交换机硬件与负责通信规则的软件。

**3. 在本章单链路模型上，仅把发送速率提高到 24 Mbit/s，其余条件不变。最后一位到达时间变成多少？能否据此断言实际应用吞吐量也翻倍？**

考点：第 4 节；层次：领会。

**答案：** 发送时间降为 1200×8÷(24×10⁶)=0.4 ms，传播仍为 1.5 ms，总计 1.9 ms。应用吞吐量还受排队、协议开销和其他设备等约束，题设只证明发送这一个分组的单链路模型变化。

**4. 管理员用一台控制台配置多台路由器，学生同时共享一台打印机。指出功能、硬件和软件各至少一项。**

考点：第 3、5 节；层次：领会、识记。

**答案：** 前者体现集中控制，后者体现资源共享，均依赖数据通信。控制台、路由器、打印机是硬件对象；协议、管理应用和提供共享的网络操作系统服务是软件对象，不能把功能名称与设备名称相互替代。

**5. 有人用“IEEE 是某种交换机，OSI 是某个厂商的产品”解释采购要求。请改正，并补全 ITU 和 EIA 在教材中的代表标准。**

考点：第 6 节；层次：识记。

**答案：** IEEE 是标准相关组织，OSI 是 ISO 提出的参考模型，都不是某台交换机产品。教材中的对应关系还包括 ITU 的 X.25 与 EIA 的 RS-232；采购时应核对具体实现的标准和接口要求。

**6. 两个方案速率相同，一方案便于扩容且有备用设备，另一方案更便宜。为什么不能只凭速率决定选型？**

考点：第 2、4、5 节；层次：领会、识记。

**答案：** 还应比较故障恢复、扩展方式、QoS、安全与标准兼容，以及建设和运行成本。备用设备有助于可靠性，也会增加投入；选择需要围绕任务要求权衡，不能把资源共享或冗余当作无成本效果。
