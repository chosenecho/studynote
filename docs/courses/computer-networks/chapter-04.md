### 必背名词

| 术语 | 必背一句话 | 常考 |
| --- | --- | --- |
| IEEE 802 委员会 | 1980 年成立的局域网标准委员会，其标准只对应数据链路层和物理层 | 填空 |
| LLC | 逻辑链路控制子层，负责与介质接入无关的内容，如逻辑连接、帧序号、高层接口和差错控制 | 填空、简答 |
| MAC | 介质访问控制子层，负责与接入传输介质有关的内容，如成帧、寻址和比特差错检测 | 填空、简答 |
| CSMA/CD | 载波监听多路访问/冲突检测，共享介质以太网的介质访问控制方法 | 简答 |
| 载波监听 | 发送前检测总线上是否有高低电平变化，以判断信道是否被占用 | 填空 |
| 冲突检测 | 发送过程中检测信号电压变化幅度是否超过阈值，以判断是否有多站在同时发送 | 填空 |
| 退避 | 检出冲突后停止发送，等待一段随机时间再重试 | 填空 |
| MAC 地址 | 48 位二进制数、固化在网卡 ROM 中的局域网物理地址，又称硬件地址 | 填空 |
| 以太网 MAC 帧 | 由目的地址、源地址、类型、数据和 FCS 组成的帧结构 | 简答 |
| FCS | 帧检测序列，用循环冗余 CRC 校验对 MAC 帧做差错检测，长 4 B | 填空 |
| 中继器 | 物理层设备，对衰减的信号放大整形后转发，不关心帧内容 | 单项选择 |
| 集线器 | 一种特殊形式的中继器，位于网段中心、有多个物理接口，对物理信号放大转发 | 单项选择 |
| 网桥 | 数据链路层设备，按 MAC 帧的目的地址转发和过滤，内部维护转发表 | 简答 |
| 转发表 | 网桥或交换机中记录目的地址与接口对应关系的表，靠自学习建立 | 填空 |
| 自学习 | 交换机按收到帧的源地址和入端口在转发表中登记，从而知道该主机从哪个端口可达 | 简答 |
| 泛洪 | 目的地址查不到表项时，向除入端口外的其他所有端口转发该帧 | 简答 |
| 过滤 | 目的地址对应端口与入端口一致时丢弃该帧，不再转发 | 简答 |
| 直通交换 | 收到帧后只检测目的地址并查表转发，不做差错校验，速度快 | 单项选择 |
| 存储转发交换 | 先接收并暂存整帧、做差错校验，无差错再转发，避免转发无效帧 | 单项选择 |
| VLAN | 由一些局域网网段构成的与物理位置无关的逻辑组，这些网段有某些共同的需求 | 填空、简答 |
| 802.1Q | 定义 VLAN 环境下以太网帧格式的标准，在源地址与类型之间插入 4 B 标记 | 填空 |
| VID | VLAN 标记中的 12 位虚拟局域网标识符，用于表明该帧属于哪个 VLAN | 填空 |
| Access 端口 | 只属于一个 VLAN、靠手工设置的交换机端口 | 单项选择 |
| Trunk 端口 | 默认属于本交换机所有 VLAN、能收发多个 VLAN 数据并靠标记区分的端口 | 单项选择 |
| WLAN | 无线局域网，在便携设备之间以无线方式建立数据连接 | 填空 |
| AP | 接入点，移动站通过无线方式与之相连，再由 AP 经有线介质连其他网络 | 填空 |
| BSS | 基本服务集，WLAN 的最小单位，包含一个 AP 和多个移动设备 | 填空 |
| ESS | 扩展服务集，由 BSS 经分配系统连接而成，覆盖范围更大 | 填空 |
| SSID | 服务集标识符，用来表明一个 BSS，长度不超过 32 B | 填空 |
| CSMA/CA | 载波监听多路访问/冲突避免，802.11 在 MAC 层使用的介质访问方法 | 简答 |
| Ad Hoc | 无固定基础设施的无线自组网络，各站点地位平等并兼做转发 | 单项选择 |

### 必背清单

**第 1 节**

1. 【考纲 1.1】1975 年美国施乐公司研制出基于总线的以太网；1980 年 DEC、Intel 和施乐联合提出以太网规约第一版 DIX V1，1982 年改为 DIX V2；同年 IEEE 成立 802 委员会专门从事局域网标准化。
2. 【考纲 1.2】IEEE 802 标准只研究局域网内部的数据传输与控制，无须考虑路由和交换，因此只对应 OSI 参考模型的数据链路层和物理层两个层次。
3. 【考纲 1.3】数据链路层分为 LLC 与 MAC 两个子层：与接入各种传输介质有关的内容放在 MAC 子层，包括成帧发送、寻址和比特差错检测；LLC 负责与介质接入无关的内容，包括建立和释放逻辑连接、提供帧序号、提供高层接口和差错控制。
4. 【考纲 1.4】802.3 是 CSMA/CD 总线访问控制方法及物理层规范，即以太网标准；802.4 是令牌总线，802.5 是令牌环网，802.11 是无线局域网；由于以太网占优，很多设备不再使用 LLC 协议，而是直接把数据封装在 MAC 帧中。

**第 2 节**

5. 【考纲 2.1】共享介质局域网的介质访问控制要解决三个问题：某一时刻哪个结点可以发送；发送时是否会出现冲突；出现冲突时如何处理。
6. 【考纲 2.2】CSMA/CD 的基本思想是“先监听，再发送；边发送，边监听”：发送前检测总线是否被占用，空闲才发；发送中继续检测，检测到信号电压变化幅度超过阈值就判定冲突，立即停止发送，等待一段时间后重发。
7. 【考纲 2.3】电磁波在总线上以有限速率传播，监听到空闲时可能仍有信号在传播，所以载波监听不能绝对排除冲突；以太网使用曼彻斯特编码，各站检测的是总线上有无高低电平变化。

**第 3 节**

8. 【考纲 2.4】MAC 地址是 IEEE 为局域网设定的 48 位（6 B）全球地址，标识每一块局域网适配器，生产时固化在适配器的 ROM 中；一台设备装多个适配器就有多个 MAC 地址。
9. 【考纲 2.5】IEEE 注册管理机构 RA 负责分配 MAC 地址的前 3 个字节，厂商购买地址块号后自行分配后 3 个字节，只要不重复即可。
10. 【考纲 2.6】以太网 MAC 帧由目的地址（6 B）、源地址（6 B）、类型（2 B）、数据（46～1500 B）和 FCS（4 B）组成；数据不足 46 B 要填充，除数据外的各部分共 18 B，故有效帧长为 64～1518 B。
11. 【考纲 2.7】以太网 V2 帧与 IEEE 802.3 帧的差别只在类型字段：值大于 0x0600 表示上层协议类型，小于 0x0600 表示数据部分的字节数；发送时还要在帧前插入 8 B 前导码与帧前定界符用于同步。
12. 【考纲 2.8】共享式以太网的工作过程：发送站把目的地址、源地址和数据封装成帧，监听空闲后以广播方式发出并继续监听是否碰撞；各站检查目的地址，不符则丢弃，符合则再检查是否无效帧。
13. 【考纲 2.9】无效 MAC 帧有三种：长度不是整数字节、FCS 检测出错、长度不在 64～1518 B 之间；被丢弃的帧不负责重传，是否重传由高层协议决定。
14. 【考纲 2.10】产品名称的含义：10 表示 10 Mbit/s，Base 表示电缆上传的是基带信号，末尾的 5 表示每段电缆最大长度 500 m、T 表示双绞线；10Base-5 最多 4 个中继器连 5 条干线、最大网络干线 2469 m、一条干线最多 100 个工作站；10Base-2 站点间最大干线 200 m、最大网络干线 910 m、一条干线最多 30 个工作站；10Base-T 一段双绞线最长 100 m。
15. 【考纲 2.11】快速以太网 100Base-T 保留原帧格式和 CSMA/CD，速率提高到 100 Mbit/s，有 TX（两对 5 类 UTP）、T4（四对 3、4 或 5 类 UTP）和 FX（光缆）三种物理层规范；万兆位以太网不再支持 CSMA/CD，只支持全双工。

**第 4 节**

16. 【考纲 3.1】以太网扩展按设备工作层次分为物理层扩展和数据链路层扩展：物理层用中继器和集线器，数据链路层用网桥和交换机。
17. 【考纲 3.2】中继器连接两个网段、对衰减信号放大整形后转发，保持与原数据相同；集线器是特殊形式的中继器，位于网段中心、有多个物理接口。
18. 【考纲 3.3】多级集线器构成的以太网仍采用 CSMA/CD，会在整个以太网范围内形成很大的碰撞域，任意时刻只能有一个主机发送；各集线器不级联时，每个小网段是独立的冲突域。
19. 【考纲 3.4】网桥工作在数据链路层，通常有 2～4 个接口，按 MAC 帧的目的地址查转发表决定转发或丢弃：目的在另一网段就转发，目的在入端口所在网段就丢弃，查不到表项就向除来源接口外的所有接口转发。
20. 【考纲 3.5】网桥用自学习算法建立转发表：表初为空，从某接口 x 收到主机 a 发出的帧时，就把 a 的地址与接口 x 记入表；所有主机都发过帧后，转发表即建立完成。网桥只适用于用户数不太多的以太网，否则广播信息过多会造成广播风暴。
21. 【考纲 3.6】以太网交换机是工作在数据链路层的多接口网桥，接口直接连主机或集线器，通过自学习建立转发表；转发时先按源地址学习，再按目的地址查表，查到就定向转发或过滤，查不到就泛洪。
22. 【考纲 3.7】交换机有两种交换方式：直通方式只检测目的地址并查表转发，不做差错校验，速度快；存储转发方式先接收暂存并校验，无差错再转发，避免把无效帧转发出去。
23. 【考纲 3.8】交换式以太网的优点：可在保留现有基础设施上扩展；允许多对主机同时通信、各自独占传输媒体实现无碰撞传输；可连接不同速率的以太网；可基于交换机实现帧过滤、传输控制和 VLAN 等功能。

**第 5 节**

24. 【考纲 4.1】IEEE 802.1Q 对 VLAN 的定义：由一些局域网网段构成的与物理位置无关的逻辑组，这些网段具有某些共同的需求；每个 VLAN 帧都有明确的标识符，指明发送该帧的主机属于哪个 VLAN。
25. 【考纲 4.2】VLAN 的基本原理：同一 VLAN 内的主机都能收到本 VLAN 内其他主机发出的广播，VLAN 外的主机收不到；这样可限制接收广播的主机数，使局域网不会因广播过多而性能恶化，即抑制广播风暴。
26. 【考纲 4.3】划分 VLAN 的三种方法：基于交换机端口划分，由管理员静态指定，又称静态 VLAN，最常用；基于 MAC 地址划分，需要 VLAN 配置服务器和数据库，用户移动时可自动划分；基于上层协议类型或地址划分，有利于组成基于应用的 VLAN。
27. 【考纲 4.4】802.1Q 在以太网帧的源地址字段和类型字段之间插入 4 B 的 VLAN 标记：前两字节固定为 0x8100 作为标记类型，后两字节中前 3 位是用户优先级、接着 1 位是规范格式指示符 CFI、最后 12 位是 VID。
28. 【考纲 4.5】VLAN Trunk 在不同交换机之间用一条骨干链路连接，并把对应端口设为 Trunk，利用 VLAN 标记识别和承载来自多个 VLAN 的数据帧，使两台交换机上同一 VLAN 的主机能够通信。
29. 【考纲 4.6】Access 端口只能属于一个 VLAN 并由手工设置，不能直接与其他 VLAN 收发信息；Trunk 端口默认属于本交换机的所有 VLAN，能收发来自所有 VLAN 的数据信息。

**第 6 节**

30. 【考纲 4.7】配置顺序：enable 进入特权模式，configure terminal 进入全局配置模式，vlan vlan-id 创建或修改 VLAN（vlan-id 范围 1～4094）；删除 VLAN 用 no vlan vlan-id。
31. 【考纲 4.8】把端口设为 Access 成员用 interface port-id 进入端口后执行 switchport access vlan vlan-id；把端口设为 Trunk 用 switchport mode trunk，再用 switchport trunk allowed vlan 设置许可列表，参数 all、add、remove、except 分别表示全部、加入、移除和排除。
32. 【考纲 4.9】把端口从 VLAN 移出要分清对象：Access 端口用 no switchport access vlan；Trunk 端口用 switchport trunk allowed vlan remove vlan-id。删除 VLAN 定义与只改变某条中继链路的承载范围不是同一件事。
33. 【考纲 4.10】查看 VLAN 信息在特权模式下用 show vlan 或 show vlan id，核对配置时要把业务终端、Access 端口和 Trunk 链路三者的对应关系一起核对。

**第 7 节**

34. 【考纲 5.1】无线局域网按结构分两类：有固定基础设施的 WLAN 预先存在固定的数据处理和转发设备，可经有线方式连其他网络；无固定基础设施的 WLAN 中每个成员都是对等的可移动设备。
35. 【考纲 5.2】IEEE 于 1997 年制定 802.11 标准，采用星形拓扑，移动站通过无线方式与 AP 相连，再由 AP 经有线介质连其他网络；使用 802.11 的无线局域网也称 Wi-Fi 网络。
36. 【考纲 5.3】802.11 用冲突避免 CA 代替冲突检测 CD 的原因有两条：无线环境下信号强度动态范围非常大，接收端不易根据信号强度判断是否碰撞；电磁波向所有方向传播，容易出现“检测到空闲其实不空闲、检测到忙其实不忙”的错误。
37. 【考纲 5.4】CSMA/CA 的核心思想三条：采用停止等待的可靠传输方式，必须收到确认帧才继续发送，超时未收到确认就重发；采用虚拟载波监听，让发送方把要占用信道的时间通知其他所有站点；信道由忙转空闲时各站执行退避算法，等待随机时间再发送。
38. 【考纲 5.5】BSS 是 WLAN 的最小单位，包含一个 AP 和多个移动设备，覆盖范围一般不超过 100 m；每个 BSS 设置不超过 32 B 的 SSID；BSS 经分配系统连接其他 BSS 构成 ESS。移动设备与 AP 建立关联可用被动扫描或主动扫描。
39. 【考纲 5.6】无固定基础设施的无线局域网没有 AP，各站点功能平等、自动组成临时网络，称无线自组网络 Ad Hoc；每个移动站既是收发设备也是转发设备，能随拓扑变化更新路由，常用于军事、救灾、勘探和航海。在其基础上还发展了无线传感器网络 WSN 和车载自组网 VANET。

### 简答答题模板

**IEEE 802 把数据链路层分为哪两个子层，各有什么功能**

LLC 负责与介质接入无关的内容：建立和释放数据链路层的逻辑连接、提供帧序号、提供高层接口和差错控制。MAC 负责与接入传输介质有关的内容：把上层数据封装成帧发送、寻址和比特差错检测。这样网络层不必关心介质、拓扑和访问方法，只处理格式统一的 LLC 帧。

**CSMA/CD 的基本思想**

十个字概括：先监听，再发送；边发送，边监听。展开说：发送前检测总线是否被占用，占用就等到空闲；由于信号传播有延迟，监听空闲时可能仍有信号在途中，所以发送后要继续检测；检测到信号电压变化幅度超过阈值就判定冲突，立即停止发送以免浪费资源，等待一段时间后重发。

**共享式以太网的基本工作原理**

发送站把目的 MAC 地址、源 MAC 地址和上层数据封装成帧，监听信道空闲后以广播方式发出并继续监听是否碰撞。各站收到帧后先看目的地址，不是自己的就丢弃；是自己的再检查是否为无效帧（长度不是整数字节、FCS 出错、长度不在 64～1518 B 之间），无效则丢弃，有效则接收。被丢弃的帧不重传，是否重传由高层决定。

**以太网交换机自学习算法的过程**

交换机每收到一帧，先按源 MAC 地址查转发表，没有记录就把源地址和入端口写入表中，完成一次学习；再按目的 MAC 地址查表，有记录就向对应端口转发（若目的端口与入端口相同则丢弃），没有记录就向除入端口外的所有端口泛洪。

**以太网交换机的两种交换方式**

直通方式：收到帧后只检测目的地址并查表转发或丢弃，不做差错校验，把校验留给目的主机，速度快。存储转发方式：先接收并暂存整帧、做差错校验，无差错再按目的地址转发，有差错就丢弃，可避免转发无效帧、浪费信道。

**虚拟局域网为什么可以抑制广播风暴**

VLAN 把广播范围限制在本逻辑组内：同一 VLAN 的主机都能收到本 VLAN 的广播，VLAN 外的主机收不到。这样接收广播的主机数被限制，局域网不会因广播信息过多而性能恶化。VLAN 用软件方式划分，不受物理位置限制。

**划分虚拟局域网的方法**

三种：基于交换机端口划分，由管理员静态指定，简单有效、最常用，又称静态 VLAN；基于 MAC 地址划分，需 VLAN 配置服务器保存管理数据库，用户移动或新增时可自动划分；基于上层协议类型或地址划分，按帧中数据的协议类型或地址定义成员，有利于组成基于应用的 VLAN。

**802.1Q 定义的 VLAN 标记格式**

在以太网帧的源地址与类型字段之间插入 4 B：前 2 B 固定为 0x8100，作为 IEEE 802.1Q 标记类型；后 2 B 中前 3 位是用户优先级，接着 1 位是规范格式指示符 CFI，最后 12 位是 VLAN 标识符 VID。

**无线局域网为什么用冲突避免代替冲突检测**

两条原因：无线环境下信号强度的动态范围非常大，接收端不容易根据收到的信号强度判断是否发生碰撞；电磁波向所有方向传播，多个站点同时通信时容易出现“检测到信道空闲其实并不空闲、检测到信道忙其实并不忙”的错误。不检测冲突就要尽量少发生冲突，因此改用 CA。

**CSMA/CA 的核心思想**

三条：采用停止等待的可靠传输，发送方必须收到确认帧才继续发送，超时未收到确认就重发；采用虚拟载波监听，发送方把要占用信道的时间通知其他站点，使其在这段时间停止发送；信道由忙转空闲时各站执行退避算法，等待随机时间再发送，以降低碰撞概率。

## 1 局域网层次与 IEEE 802 {#s1}

**必背：** IEEE 802 标准只对应 OSI 参考模型的数据链路层和物理层；数据链路层分 LLC 与 MAC 两个子层，MAC 管成帧、寻址和比特差错检测，LLC 管与介质接入无关的逻辑连接、帧序号、高层接口和差错控制。

局域网围绕局部范围的数据通信和资源共享发展，早期方案包括环网、令牌总线和以太网。IEEE 802 为多种局域网技术制定相应标准；本课程把 802.3 与以太网、802.11 与无线局域网联系起来，不把整个 802 系列当成一种接入方法。

IEEE 802 的层次模型把数据链路层分为 LLC 与 MAC。LLC 侧重与具体介质接入无关的逻辑服务，MAC 处理成帧、地址和介质访问等相关工作。分层模型便于比较技术，但不意味着所有以太网产品在实际通信中都必须使用同一套 LLC 封装。

## 2 共享以太网与 CSMA/CD {#s2}

**必背：** CSMA/CD 的基本思想是先监听、再发送，边发送、边监听；因信号传播需要时间，监听空闲不等于一定不会冲突，检出冲突要立即停止发送并按退避规则等待重试。

载波监听与冲突检测用于协调共享介质访问。传统共享介质以太网让多个站点使用同一信道。CSMA/CD 先监听，空闲时尝试发送，发送过程中继续检测；检出冲突便停止相应发送并按退避规则等待后重试。监听空闲不等于远处没有刚发出的信号，因为信号到达需要传播时间。

可以把冲突想成两个相距较远的站点各自都暂未听见对方：它们都认为可发，随后信号在介质上相遇。因此不能把载波监听解释为绝对排除冲突。这里讨论的是教材的共享介质模型；书中交换式以太网允许不同端口上的多对主机通信，不应把共享总线上的竞争过程套给所有链路。

## 3 MAC 地址、帧与产品标识 {#s3}

**必背：** MAC 地址是 48 位（6 B）、生产时固化在网卡 ROM 中的物理地址；以太网 MAC 帧由目的地址、源地址、类型、数据和 FCS 组成，除数据的 18 B 外数据可 46～1500 B，故有效帧长 64～1518 B。

以太网硬件地址即 MAC 地址，本书采用 48 位表示，常写成六组十六进制字节。地址用于链路上的帧交付，与 IP 地址的网络前缀功能不同。交换设备读取目的地址作转发判断，同时可利用源地址学习位置。

本书以太网 MAC 帧由目的地址、源地址、类型、数据及 FCS 等部分组成；目的和源地址各 6 B，类型 2 B，FCS 4 B，数据部分在规定范围内并可能包含填充。读长度题要先声明是否计前导部分、是否带 VLAN 标记，不能混用不同边界。FCS 用于检测帧差错，不是应用层收件确认。

教材列出的产品从粗缆 10Base-5、细缆 10Base-2、双绞线 10Base-T，到 100Base-T、千兆和万兆以太网，体现介质、拓扑与速率的变化。名称相近不代表线缆、接口、距离与接入机制完全相同；比较时逐项查看技术条件。

## 4 中继、集线与交换学习 {#s4}

**必背：** 中继器和集线器在物理层放大转发信号，网桥和交换机在数据链路层按 MAC 帧转发；交换机先按源地址和入端口完成学习，再按目的地址查表定向转发或过滤，查不到表项就泛洪。

中继器和集线器在物理层处理信号，不依据目的 MAC 选择单一转发端口。网桥在链路层读取帧并查转发表，以太网交换机可理解为多端口网桥；想减少不必要的帧传播时，不能把集线器与交换机当成等价扩展设备。

交换机收到帧后先用源地址学习“该主机可从哪个端口到达”，再用目的地址查表：已知目的在另一端口时定向转发；目的在入端口所接网段时过滤；未知目的时在相应范围向入端口以外的端口泛洪。学习看源地址，转发看目的地址，两步不可颠倒。

过程：初始表为空，A 从端口 2 发给 B，交换机先记 A→2，再向其他合适端口泛洪；B 从端口 4 回复 A 时记 B→4，再向端口 2 转发。直通交换与存储转发的区别在于是否等待并检查完整帧，不能仅用外观判断。

## 5 VLAN 成员、标记与中继 {#s5}

**必背：** VLAN 是由一些局域网网段构成的与物理位置无关的逻辑组，可抑制广播风暴；802.1Q 在源地址字段与类型字段之间插入 4 B 标记，类型值 0x8100，其中 12 位是 VID。

VLAN 用逻辑方式划分局域网广播范围，使分组组织不必完全随物理楼层变化。可以按端口、MAC 地址，或上层协议类型与地址划分。基于端口的成员关系随端口配置确定；按 MAC 的方式则把成员身份与设备地址关联，用户移动时需要关注不同的维护对象。

802.1Q 在源 MAC 后、原类型字段前插入 4 B 标记，标记类型为 0x8100，后续部分包括优先级及 12 位 VID 等。不能把 VLAN 标记理解成重新分配的 IP 地址。Access 端口在本章基本模型中归属一个 VLAN；Trunk 跨交换机承载多个被允许的 VLAN，以标记等机制保持逻辑区分。

两台交换机都创建了 VLAN，并不说明跨交换机已经连通：端口成员、互联链路模式和许可列表还要一致。不同 VLAN 的通信还需要相应三层转发，不能仅因同插一台交换机就判定属于同一广播范围。

## 6 按任务核对 VLAN 配置 {#s6}

**必背：** 配置 VLAN 要分三件事核对：用 vlan 创建定义、用 switchport access vlan 设成员、用 switchport mode trunk 配合 allowed vlan 设许可；删除 VLAN 定义与从 Trunk 许可列表移除某 VLAN 不是同一操作。

以下按教材 Cisco 命令语境设计一个新的练习配置：VLAN 20 用于资料组，端口 FastEthernet 0/3 加入该组；FastEthernet 0/24 作为中继，仅允许 VLAN 20、30。命令用于读懂配置顺序和作用，具体设备接口名及支持范围要以其环境为准。

```text
enable
configure terminal
vlan 20
exit
vlan 30
exit
interface FastEthernet 0/3
switchport access vlan 20
exit
interface FastEthernet 0/24
switchport mode trunk
switchport trunk allowed vlan 20,30
end
show vlan
```

创建 VLAN、设置端口成员和设置中继许可列表是三件事，完成一件不代替其他两件。删除 VLAN 使用 `no vlan vlan-id`；从中继许可列表移除某 VLAN 则是 `switchport trunk allowed vlan remove vlan-id`，不能把两者当成相同操作。核对配置时同时画出业务终端、Access 和 Trunk 的对应关系，不只查某条命令是否输入。

## 7 无线局域网与 CSMA/CA {#s7}

**必背：** 802.11 在 MAC 层用 CSMA/CA 而不是 CSMA/CD；BSS 是 WLAN 的最小单位、含一个 AP，SSID 标识该 BSS，多个 BSS 经分配系统构成 ESS，没有 AP 且站点地位平等的情形是 Ad Hoc。

有基础设施的 WLAN 由移动站连接接入点 AP，基本服务集 BSS 可经分配系统连接其他 BSS，构成 ESS。SSID 用于标识相应服务集；识别到 SSID 与已获准接入是不同问题。无基础设施的 Ad Hoc 网络没有同样的固定 AP，各移动站可参与临时组网与转发。

802.11 的 CSMA/CA 侧重尽量避免冲突：在本书模型中结合确认、虚拟载波监听和随机退避。无线站点不易像共享有线介质那样可靠检测发送期间的冲突，还可能出现本地监听与接收方环境不一致，因此不能把 CA 翻译成“已经保证不会碰撞”。未按时收到所需确认仍可能需要重发。

## 本章小结

- LLC、MAC 是子层，802.3 与 802.11 是不同技术标准的联系；共享以太网的 CSMA/CD 不可直接套给所有交换链路。
- 交换机用源地址及入端口学习，用目的地址查表转发；表为空时的泛洪不是“学习目的地址”。
- VLAN 定义、Access 成员和 Trunk 许可分别检查，相同 VID 不自动打通链路；CSMA/CA 降低碰撞机会，也不保证无线发送绝无冲突。

## 练习

**1. 把 LLC、MAC、802.3 与 802.11 放进一张说明表时，哪些属于层次，哪些属于标准联系？为何不能说“所有 IEEE 802 都使用同一种介质访问方法”？**

考点：第 1、2 节；层次：识记、领会。

**答案：** LLC 与 MAC 是数据链路层的子层；802.3 联系以太网，802.11 联系无线局域网。不同局域网技术可以在 MAC 和物理层采用不同方案；CSMA/CD 与 CSMA/CA 的处理对象和机制也不同。

**2. 共享信道两端的站点同时认为介质空闲并开始发送，是否说明载波监听没有执行？检测到冲突后应怎样理解退避的作用？**

考点：第 2、3 节；层次：领会。

**答案：** 不一定。信号传播有延迟，监听时远端信号可能尚未到达；继续检测才可能发现冲突。退避让竞争站点错开重试，降低再次冲突机会，不是对每次发送都成功的保证，MAC 帧的检错也不能替代这种访问协调。

**3. 交换机仅有端口 1、2、3、4，均在同一 VLAN，初始表为空。A 从 2 发给 B，B 从 4 回复 A，随后 A 再发给 B。忽略老化与其他流量，逐步列出学习和出端口。**

考点：第 4 节；层次：简单应用。

**答案：** 第一帧学习 A→2，向 1、3、4 泛洪；第二帧学习 B→4，查 A 后只从 2 转发；第三帧查 B 后只从 4 转发。学习来自源地址和入端口，不是从未知目的猜出位置。

**4. 需要把远端支线接入并减少无关帧传播，有人认为增加集线器即可获得交换机的定向转发效果。指出设备层次和依据的差别。**

考点：第 3、4 节；层次：领会、简单应用。

**答案：** 集线器在物理层扩展信号，不按 MAC 表选择出口；网桥和交换机在链路层依据目的地址查表，可过滤或定向转发帧。选择设备应看所需功能，不能把接口数量多理解成具备地址学习。

**5. 资料组在两台交换机上均为 VLAN 20，但互联 Trunk 只允许 VLAN 30。两组内同交换机通信正常、跨交换机失败。应首先核对哪一项？标签中 VID 能否替代 IP 子网？**

考点：第 5、6 节；层次：综合应用。

**答案：** 首先核对并按业务要求修正两端 Trunk 的 VLAN 20 许可状态，同时检查成员端口与互联模式。VID 识别链路层 VLAN，不是 IP 网络前缀；跨 VLAN 的业务通信还需要三层处理。

**6. 将 FastEthernet 0/3 加入已创建的 VLAN 20，随后只从中继许可列表移除 VLAN 20。分别应查哪类命令，为什么不直接删除 VLAN？**

考点：第 6 节；层次：综合应用。

**答案：** 在接口配置下用 switchport access vlan 20 设置成员；在对应 Trunk 接口下用 switchport trunk allowed vlan remove 20 移除许可。no vlan 20 删除的是 VLAN 定义，影响与仅改变某条中继链路的承载范围不同。

**7. 移动站能扫描到 SSID，却在发送后等待不到确认。能否说“CSMA/CA 已消除冲突，所以一定是 IP 地址错了”？顺便区分 BSS 与 Ad Hoc 的基础设施条件。**

考点：第 7 节；层次：领会。

**答案：** 不能。CA 旨在降低冲突概率，不承诺零冲突；无确认还需检查无线与接入过程等条件，不能直接定位 IP。基础设施 BSS 围绕 AP 组织，而 Ad Hoc 不依赖同样的固定 AP。
