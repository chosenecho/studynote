## 1 操作系统的职责与特征 {#s1}

**必背：** 操作系统是硬件之上的第一层软件，4 个特征是并发、共享、虚拟、异步，5 大功能是处理机、存储器、设备、文件和接口管理；多道批处理 3 特征、分时 4 特征、实时分两类。

操作系统是硬件上的第一层软件，协调资源，也给用户和程序留出口。处理机安排谁先跑，存储器管空间怎么分，设备管 I/O 怎么走，文件管信息怎么存，接口管程序怎么调。服务器也一样，进程和存储管理一样少不了。

并发是多个任务在一段时间里交替推进，共享是资源被几方一起用，虚拟把物理的变成逻辑的，异步说的是推进节奏不固定。五类系统的脾气差异见下表。

| 类型 | 主要组织方式 | 易混点 |
| --- | --- | --- |
| 批处理 | 作业成批提交，由系统调度执行 | 多道共享处理机，完成未必按提交序，交互少 |
| 分时 | 多个终端共享系统，按时间片分配处理机 | 时间片轮转，重交互，任务不独占整机 |
| 实时 | 按时间或事件驱动任务，在规定时限内响应 | 判断是否满足时间约束，不能只看平均处理速度 |
| 微机 | 随微机能力发展，支持个人使用及更多任务和用户 | 关注开放性、通用性与硬件条件 |
| 分布式 | 多台计算机通过通信协同完成任务和资源管理 | 各节点与通信协作共同构成系统的工作过程 |

## 2 网络操作系统的分类与服务 {#s2}

**必背：** 网络操作系统是网络环境下用户与网络资源之间的接口，基本任务 4 条；按范围分专用型与通用型，按结构分对等与非对等；主要功能 6 项：文件、打印、数据库、通信、网络管理和 Internet 服务。

网络操作系统是用户和网络资源之间的一层，管共享，也提供通信和服务。按范围分专用型和通用型；按结构分对等和非对等。对等结构里每个节点既干本地活又对外服务；非对等结构把服务器和工作站分开，各管一摊。

服务清单里有文件服务、打印服务、数据库、通信、网络管理、Internet 相关服务。名字列在表上，不代表每台机器都开着这些功能。部署前先问：资源在哪、谁来访问、谁认证、谁管理，再定结构。上来就把所有机器设成共享服务器，顺序反了。

## 3 教材中的常见系统 {#s3}

**必背：** UNIX 突出安全可靠并能方便接入 Internet，NetWare 以文件和打印服务闻名但早期用 IPX/SPX，Linux 是开源的多用户多任务类 UNIX 系统；Windows 系列按 LAN Manager、NT、2000、2003、2008 五代演进。

| 系统 | 本章辨认线索 |
| --- | --- |
| UNIX | 多用户、多任务，带权限管理与网络、文件工具 |
| Linux | 类 UNIX，多用户多任务，源码开放 |
| NetWare | 文件服务器为核心，服务器与工作站分工 |
| Windows 系列 | 局域网服务到集中管理、域服务、多服务器角色 |

Linux 另外支持网络协议和常见 UNIX 工具；NetWare 早期跑 IPX/SPX。

用途相近，不等于命令、目录和授权方式能直接互换。

教材按 LAN Manager、Windows NT、Windows 2000、Windows Server 2003、Windows Server 2008 一路讲下来，操作练习用的是 Server 2008 的安装、账户和域服务。这一节按该版产品背景讲，界面名称也照它写，为的是看清职责和过程。这份历史环境的练习，不能当今天的服务器选型或上线指南。

## 4 安装任务与方案核对 {#s4}

**必背：** 安装有全新安装、升级安装、远程安装和安装 Server Core 4 种方式；最低配置为 1 GHz 的 CPU、512 MB 内存、10 GB 硬盘，建议 2 GB 内存与 40 GB 剩余空间；远程安装要求网卡支持 PXE。

在 Server 2008 的教材环境里，先看硬件兼容、磁盘空间、安装介质，再想清楚原有系统和数据怎么办，最后定安装方式。全新安装是重新搭一套；升级安装想保住原配置，但得看系统条件；远程安装靠部署服务和网络引导；Server Core 只留精简组件，用命令行管。

安装按“确认条件、选方式和版本、装系统、初始配置、查服务”往下走。能不能升级，看具体版本和支持路径；教材的概述不等于任何旧系统都能原地升。版本和路径没给全，就把核对步骤写出来。

## 5 本地账户、域账户与组 {#s5}

**必背：** 本地账户存在本机 SAM 中、只能登录本机，域账户存在域控制器活动目录中、可登录域内任何计算机；组用于一次指派公共权限但不能用于登录，Administrator 与 Guest 是内置账户。

本地账户存在本机的 SAM 里，域账户由域控制器的目录服务集中管。登录身份跟权限有关，但验证通过不等于什么资源都能动。跨机器共享，先弄清账户属于哪一边。

用户组把需要同样授权的成员拢在一起，一次配一组权限。人要登录，用的是自己的账户；组不是几个人共用的登录名。一个账户可以在多个组里，做分析时把成员关系和资源权限列清楚，别把“在组里”当成什么都放行。

教材的练习是在“计算机管理”的本地用户和组里建用户、设账户选项，再建组、加成员。Administrator 和 Guest 是内置账户，用的时候看清各自的角色和权限。练手不需要真密码，也不用让所有人共用一个管理员账户。

## 6 活动目录、域与成员加入 {#s6}

**必背：** 活动目录是存储网络对象信息的分布式数据库，域是核心单元与安全边界与复制单位，OU 是域内组织与委派管理的容器，森林是一棵或多棵域树的集合；域是逻辑管理单位、站点是物理结构；安装前提含 NTFS 分区存 SYSVOL、名称符合 DNS 规范、配置 TCP/IP 与 DNS，加入域还需成员机 DNS 指向域控制器。

Active Directory 存用户、计算机、服务这些对象和它们的属性。容器装对象，OU 是域里用来组织和委派管理的那一层，域是逻辑管理单位，域树按连续命名把几个域串起来，林装一棵或多棵域树。域控制器跑目录服务和认证；成员服务器干文件、邮件、Web 这类活。两者不是一回事。

站点说的是物理连接，域说的是逻辑管理。一个域能跨几个站点，一个站点也能装几个域，所以别把一栋楼、一条子网和一个域当成同一条边界。命名空间按 DNS 格式读，目录访问协议按 LDAPv3 记。活动目录自 Windows 2000 Server 起提供。

按教材环境，建域的过程是这样：

1. 准备符合要求的名称、TCP/IP 和 DNS 配置，以及用于 SYSVOL 的 NTFS 分区。
2. 在服务器管理器中添加 Active Directory 域服务角色，再运行相应目录安装配置向导；“已装角色”与“已完成域配置”是不同阶段。
3. 按任务选择新林或现有结构，设置域名、功能级别和相关域控制器选项，明确 DNS 安排。
4. 设置数据库、日志和 SYSVOL 位置及还原模式凭据，完成向导和所需重启。
5. 将成员机的 DNS 指向能够解析该域所需记录的服务器，再按域名和有权加入的账户完成成员加入，并验证域登录与目标资源权限。

检查时说明每个条件管什么：名称定位、目录存储、身份认证、授权。“IP 能通”不等于能发现域，更不等于能加进去。

## 本章小结

- 网络服务站在处理机、内存、设备、文件这些能力上。对等还是非对等，看资源和服务怎么分工，不看机器数量。
- 本地账户归本机管，域账户归目录服务管。组攒的是授权，不是共用的登录名。验证通过，权限另算。
- 域画逻辑边界，站点画物理边界。加入域还要名称解析和目录配置到位。本章的 Server 2008 操作是教材环境，不能照抄成今天的部署方案。

## 练习

**1. 服务器上同时运行文件服务和备份程序，偶有一个等待磁盘。用并发、共享和异步解释现象，并区分处理机管理与文件管理。**

考点：第 1 节；层次：识记。

**答案：** 两活动在同一时间段推进体现并发，共用磁盘等资源体现共享，等待条件使进展节奏变化体现异步。处理机管理安排执行机会，文件管理组织文件和访问；等待并不能单独说明系统已失去并发能力。

**2. 小组每台机器既处理本地任务也提供共享，另一方案集中到专用服务器。按结构怎样比较？再列三项可能由网络操作系统提供的服务。**

考点：第 2 节；层次：领会。

**答案：** 前者可按对等结构分析，后者更接近非对等服务器/工作站分工。服务可包括文件、打印、通信、数据库或管理等。比较应看共享范围、管理和认证责任，不能只凭机器数目判断结构。

**3. 把教材中的 UNIX、Linux、NetWare 与 Windows Server 2008 当作相同界面的四个名字，为何会影响复习？Server Core 又应与什么区分？**

考点：第 3、4 节；层次：识记、综合应用。

**答案：** 它们在系统组织、命令和管理环境上有差别，应抓各自特点。Server Core 是教材中一种精简安装与管理形态，不是把安装介质换成网络下载的同义词；全新、升级、远程安装描述的选择维度也需要分清。

**4. 一台保有资料的旧服务器准备改装教材环境。题设没给原系统版本与升级路径，能否直接承诺原地升级？请给出先做哪些核对。**

考点：第 4 节；层次：综合应用。

**答案：** 不能。先保全与核对资料、硬件兼容和空间，再查明确版本及升级支持条件，并确定介质、回退和验证安排。缺少路径条件时应列核对过程，而不是凭“升级”一词保证配置和数据都可原样保留。

**5. 三名资料员要访问同一共享目录，有人建议共用 Administrator 密码，并把“资料员组”直接作为登录账户。怎样改成可管理的设计？**

考点：第 5 节；层次：综合应用。

**答案：** 为每人保留可区分的用户账户，用组组织共同授权，再按任务配置共享和资源权限。组用于汇总成员与权限，不直接作为一个共用登录账户；也不需要因为访问同一目录而共享最高权限身份。

**6. 域控制器上已添加域服务角色，成员机用外部 DNS，管理员因 IP 可达便跳过目录配置。列出仍缺少的阶段，并区分域与站点。**

考点：第 5、6 节；层次：综合应用。

**答案：** 仍需完成目录/域配置、名称解析和存储等前提，核对成员 DNS、域名及加入权限，再验证域登录与资源授权。域描述逻辑管理，站点描述物理网络关系；IP 可达只证明一部分通信条件，不能替代域发现。
