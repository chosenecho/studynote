### 必背名词

| 术语 | 必背一句话 | 常考 |
| --- | --- | --- |
| 操作系统 | 配置在计算机硬件上的第一层软件，是控制和管理计算机硬件和软件资源、合理组织处理流程并方便用户使用计算机的系统软件 | 填空、简答 |
| 并发性 | 两个及两个以上的事件或活动在同一时间间隔内发生，系统中的若干程序交错执行 | 填空 |
| 共享性 | 系统中的硬件和软件资源不再为某个程序独占，而由多个并发执行的程序共享 | 填空 |
| 虚拟性 | 通过某种技术把一个物理上的实体变为若干逻辑上的对应物 | 填空 |
| 异步性 | 多道程序环境下程序走走停停，多个程序的执行顺序与所需执行时间不可预知 | 填空 |
| 网络操作系统 | 在网络环境下用户与网络资源之间的接口，用以实现用户对网络资源的管理和控制，是各种网络服务软件和网络协议的集合 | 简答 |
| 对等结构 | 网络中各个结点地位平等、每台计算机操作系统功能相同、各种资源都可共享的结构，各机以前后台方式工作 | 简答 |
| 非对等结构 | 按功能把结点分为服务器和工作站两类，服务器提供网络服务与资源，工作站处理本地信息并访问服务器的结构 | 简答 |
| 用户账户 | 计算机的基本安全组件，计算机通过它辨别用户身份，是系统环境中用户的唯一标识符 | 填空 |
| 本地账户 | 在本地安全目录数据库中建立、只能登录建立该账户的计算机并访问该机资源的账户 | 简答 |
| 域账户 | 建立在域控制器活动目录数据库中、具有全局性、可登录域内任何一台计算机的账户 | 简答 |
| 组 | 用户账户与计算机账户与联系人和其他组的集合，用于为多个账户一次指派公共权限，不能用于登录计算机 | 简答 |
| 活动目录 | 动态的分布式文件系统，用于存储用户感兴趣的网络对象信息的信息库 | 简答 |
| 域 | 活动目录的核心单元，是共享同一活动目录的一组计算机的集合，是 Windows 的逻辑管理单位，也是安全边界和复制单位 | 填空、简答 |
| 组织单元 OU | 组织和管理一个域内对象的容器，比域的管理边界更小，可包含用户、组、计算机、打印机和其他组织单元 | 单选 |
| 域树 | 具有共同模式和配置、形成临近名字空间的若干域的集合，加入的第一个域是根结点 | 填空 |
| 森林 | 一棵或多棵活动目录树的集合，各树地位相当并由双向传递的信任关系相关联 | 填空 |
| 域控制器 | 安装并运行了 Active Directory 的服务器，存储域范围内的账户和策略信息 | 填空 |
| 站点 | 表示网络物理结构或拓扑的单元，由一个或多个子网构成，与域没有必然联系 | 简答 |

### 必背清单

**第 1 节**

1. 【考纲 1.1】操作系统是配置在计算机硬件上的第一层软件，既承担管理硬件和软件资源的角色，又兼有服务者的职责，是其他所有软件运行的平台。
2. 【考纲 1.1】操作系统的目标是提高效率、方便用户；从系统角度看它是资源管理程序，通过进程机制管理 CPU、通过虚拟内存管理内存、通过中断与设备驱动管理外设、通过文件系统管理文件。
3. 【考纲 1.1】操作系统的 4 个基本特征是并发性、共享性、虚拟性和异步性。
4. 【考纲 1.1】共享性是因为并发性而产生的，二者互相依存。
5. 【考纲 1.2】操作系统应具备 5 大管理功能：处理机管理、存储器管理、设备管理、文件管理和接口管理。
6. 【考纲 1.2】处理机管理归结为对进程的管理，功能是进程的描述与创建与撤销、同步或互斥使用临界资源、进程间通信、按算法分配处理机。
7. 【考纲 1.2】存储器管理的功能是内存的分配和回收、地址映射和内存的扩充；设备管理的功能是缓冲区管理、设备分配、设备处理、虚拟设备及 I/O 设备的独立性。
8. 【考纲 1.2】文件管理的功能是文件存储空间的管理、目录文件、文件的读写管理以及文件的共享与保护；接口管理分用户接口和程序接口两类。
9. 【考纲 1.3】多道批处理系统有 3 个特征：多道性、调度性、无序性，一般用于交互性不太强、较大的计算机系统。
10. 【考纲 1.3】分时系统有 4 个特征：同时性、独立性、及时性、交互性，主要目标是使用户能与系统交互并及时响应请求。
11. 【考纲 1.3】实时操作系统分实时控制系统和实时信息处理系统两大类，主要特点是响应及时、可靠性高，交互能力较弱而及时性较强。
12. 【考纲 1.3】实时系统与批处理、分时系统的主要区别是设计目标、响应时间长短、交互性强弱和资源利用率不同。
13. 【考纲 1.3】微机操作系统的特点是开放性、通用性和高性能；分布式系统把多台分散的计算机通过互联网连接，各机高度自治又互相协调。

**第 2 节**

14. 【考纲 2.1】网络操作系统的定义：网络环境下用户与网络资源之间的接口，用以实现用户对网络资源的管理和控制，是各种网络服务软件和网络协议的集合。
15. 【考纲 2.1】网络操作系统的基本任务 4 条：屏蔽本地资源与网络资源的差异性、为用户提供各种基本网络服务功能、完成网络共享系统资源的管理、为网络安全提供保障。
16. 【考纲 2.1】按适用范围分专用型和通用型：专用型为某种特定网络应用或环境设计、实现特定功能；通用型提供各种基本网络服务、适用于多个领域。
17. 【考纲 2.1】按结构分对等结构和非对等结构；对等结构的优点是结构简单、任意两个结点都可通信，缺点是每台计算机负荷都很重。
18. 【考纲 2.1】共享硬盘方式把共享空间分为专用盘体、公用盘体和共享盘体 3 种，专用盘体只给特定用户、公用盘体只能读、共享盘体可读写。
19. 【考纲 2.1】早期的共享硬盘方式使用效率低、易产生安全隐患，后来发展为文件服务器方式，目前的网络操作系统基本都属于文件服务器系统。
20. 【考纲 2.2】网络操作系统的主要功能 6 项：文件服务、打印服务、数据库服务、通信服务、网络管理服务和 Internet 服务。

**第 3 节**

21. 【考纲 3.1】UNIX 是典型的多用户多任务网络操作系统，最突出的特点是安全可靠、能很方便地与 Internet 相连，其功能位于 OSI 参考模型传输层以上的层次。
22. 【考纲 3.1】NetWare 由 Novell 公司开发，大部分安装于服务器上（主网络操作系统），客户机安装 NetWare Shell，服务器与客户机是主从式关系，以文件和打印服务闻名。
23. 【考纲 3.1】NetWare 最大的缺点是最初版本没有采用 TCP/IP 而使用自己指定的 IPX/SPX，与 Internet 脱节。
24. 【考纲 3.1】Linux 由 Linus Torvalds 于 1991 年开发，是基于 POSIX 和 UNIX 的多用户多任务、支持多线程和多 CPU 的操作系统，是自由和开放源代码的。
25. 【考纲 3.2】Windows 系列的发展顺序是 LAN Manager、Windows NT、Windows 2000、Windows Server 2003、Windows Server 2008。
26. 【考纲 3.2】Windows NT 有两个版本：NT Workstation 面向交互式桌面环境，NT Server 面向企业级网络，两者系统结构完全一样。
27. 【考纲 3.2】Windows 2000 有 4 个产品：Server、Advanced Server、Datacenter Server 和 Professional，其中 Datacenter Server 支持最多 32 个 CPU、可管理高达 64 GB 内存。
28. 【考纲 3.2】Windows Server 2003 只有服务器版本而没有单机版，含 Web 版、标准版、企业版和数据中心版。
29. 【考纲 3.3】Windows Server 2008 于 2008 年 3 月发布，继承了 Windows Server 2003 的稳定性和 Windows XP 的易用性。
30. 【考纲 3.3】Windows Server 2008 的主要特点 5 项：可操作性、可管理性、可扩展性、可用性和安全性。
31. 【考纲 3.3】新增功能包括服务器核心 Server Core、Power Shell、虚拟化、网络访问保护 NAP、只读域控制器 RODC、Windows 防火墙高级安全功能、服务器管理器、增强的终端服务和下一代加密技术 CNG。
32. 【考纲 3.3】Server Core 是不包含服务器图形用户界面、纯命令行的操作系统，只安装必要的服务和应用程序，暴露的攻击面较少。
33. 【考纲 3.3】Windows Server 2008 有 6 个版本：标准版、企业版、数据中心版、Web 版、安腾版和 HPC 版。

**第 4 节**

34. 【考纲 4.1】安装前要检查硬件配置是否满足要求、是否在硬件兼容列表 HCL 中；最低配置为 32 位 1 GHz 的 CPU、512 MB 内存、10 GB 硬盘空间。
35. 【考纲 4.1】安装有 4 种方式：全新安装、升级安装、通过 Windows 部署服务远程安装和安装 Server Core。
36. 【考纲 4.1】升级安装不卸载原系统、在原系统基础上进行并可保留原来的配置，一般用于企业对现有生产系统的升级。
37. 【考纲 4.1】远程安装要求服务器网卡支持 PXE 预引导执行环境，可通过应答文件实现自动安装。
38. 【考纲 4.1】光盘全新安装的流程：设为光盘引导、选择安装版本、接受授权协议、选择自定义（高级）安装、选择安装分区、复制文件并安装、首次登录改密码。
39. 【考纲 4.2】Windows Server 2008 支持两种用户账户：域账户和本地账户；本地账户的用户信息保存在 Systemroot 目录下 system32 中 config 文件夹的安全数据库 SAM 中。
40. 【考纲 4.2】Administrator 是系统管理员账户，具有最高权限，第一次启动时设置其名称和密码，可以改名或禁用但无法删除。
41. 【考纲 4.2】Guest 是为临时访问计算机的用户设置的账户，安装时自动添加且不能删除，默认是禁用的，只有很少的权限。
42. 【考纲 4.2】账户名必须在本机唯一，不能包含问号与星号与斜杠等字符，长度可超过 20 个字符但系统只识别前 20 个。
43. 【考纲 4.2】密码最多 128 个字符、推荐最小长度 8 个字符，应由大小写字母、数字和合法符号混合组成，并给 Administrator 指定复杂密码。
44. 【考纲 4.2】组是账户与计算机账户与联系人和其他组的集合，可用于为多个账户一次指派公共权限，但组账户不能用于登录计算机，一个账户可同时属于多个组。
45. 【考纲 4.2】默认组有 Administrator 组、Backup Operators 组、Guests 组和 Users 组；每个组有唯一的安全标识符 SID，删除后不能恢复。
46. 【考纲 4.3】活动目录是从 Windows Server 2003 开始采用的技术，是动态的分布式文件系统，支持 LDAP 协议，其命名空间采用 DNS 格式命名。
47. 【考纲 4.3】活动目录的主要作用 4 条：提高定义的安全性、把目录分布在多台计算机上提高可靠性、复制目录使更多用户获得并减少管理开销、把目录分配到多个存储介质以存储大规模对象。
48. 【考纲 4.3】与活动目录有关的概念有命名空间、对象、容器、域、组织单元、树和森林；域是核心单元、是安全边界也是复制单位。
49. 【考纲 4.3】域是逻辑管理单位，站点代表网络的物理结构，一个站点可包含多个域，一个域也可跨越多个站点。
50. 【考纲 4.3】域控制器是安装并运行了 Active Directory 的服务器；成员服务器是域环境中提供文件、邮件或 Web 等服务的服务器，二者不可等同。
51. 【考纲 4.3】安装活动目录的前提 4 条：有 NTFS 格式分区存放 SYSVOL 文件夹、服务器名称符合域名系统命名规范、正确配置 TCP/IP 参数和 DNS 客户端、通常同时安装 DNS 服务器。
52. 【考纲 4.3】安装顺序是先添加 Active Directory 域服务角色，再运行域服务安装向导，选择在新林中新建域、设置林和域功能级别、指定数据库与日志与 SYSVOL 位置、设置还原模式密码。
53. 【考纲 4.3】把计算机加入域的步骤：把客户端首选 DNS 指向域控制器地址、在系统属性中把隶属于改为域并输入域名、提供有权加入该域的账户和密码、重启后设置生效。

### 简答答题模板

**操作系统的作用和 5 大管理功能**

作用从三个角度看：对用户是屏蔽烦琐、提供图形与字符界面和系统调用接口；对系统是资源管理程序，用进程管理 CPU、用虚拟内存管理内存、用中断与驱动管理外设、用文件系统管理文件；对软件设计是一组程序与数据结构的集合。功能五项各一句：处理机管理即进程管理，存储器管理负责分配回收与地址映射与扩充，设备管理负责缓冲与分配与处理与虚拟设备，文件管理负责存储空间与目录与读写与保护，接口管理分用户接口与程序接口。

**网络操作系统的定义、分类与主要功能**

定义一句：网络环境下用户与网络资源之间的接口，是网络服务软件与网络协议的集合，基本任务是屏蔽差异、提供基本服务、管理共享资源、保障安全。分类两个维度：按范围分专用型与通用型，按结构分对等与非对等。功能 6 项：文件服务、打印服务、数据库服务、通信服务、网络管理服务、Internet 服务。

**对等结构与非对等结构的区别**

对等结构中各结点地位平等、安装的操作系统功能相同、各种资源都可共享，各机以前后台方式工作，优点是结构简单、任意两结点可通信，缺点是每台计算机既要当工作站又要当服务器、负荷重。非对等结构把结点分为服务器与工作站，服务器提供网络服务与资源、需要较高性能硬件，工作站处理本地信息并访问服务器、对硬件要求不高。

**本地账户与域账户的区别**

本地账户建立在本地安全目录数据库中，用户信息保存在本机 SAM 里，只能登录建立该账户的计算机并访问该机资源。域账户建立在域控制器的活动目录数据库中，具有全局性，可登录域内任何一台计算机并获得访问域网络的权限，需要管理员在域控制器上为每个用户创建。身份验证通过不等于对所有资源有管理权。

**把成员机加入域要满足哪些条件，步骤是什么**

前提：域控制器已安装活动目录、域内有可解析该域所需记录的 DNS、成员机 TCP/IP 与首选 DNS 指向能解析该域的服务器、有具备加入权限的账户。步骤：改客户端首选 DNS、在系统属性中把隶属于改为域并填域名、输入有权加入的账户与密码、加入成功后重启使设置生效，再验证域登录与资源权限。

## 1 操作系统的职责与特征 {#s1}

**必背：** 操作系统是硬件之上的第一层软件，4 个特征是并发、共享、虚拟、异步，5 大功能是处理机、存储器、设备、文件和接口管理；多道批处理 3 特征、分时 4 特征、实时分两类。

操作系统协调计算机资源并为使用者和程序提供接口。处理机管理安排执行，存储器管理组织空间，设备管理协调 I/O，文件管理组织持久信息，接口管理提供使用途径。网络服务运行在这些基础能力之上，不能因为是服务器便不需要进程与存储管理。

并发描述任务在一段时间内交错推进，共享描述资源被多个活动使用，虚拟把物理资源抽象为逻辑对象，异步说明各活动受条件影响而以不预先固定的节奏推进。各类系统的组织方式可按下表辨认。

| 类型 | 主要组织方式 | 易混点 |
| --- | --- | --- |
| 批处理 | 作业成批提交，由系统调度执行 | 多道共享处理机，完成未必按提交序，交互少 |
| 分时 | 多个终端共享系统，按时间片分配处理机 | 时间片轮转，重交互，任务不独占整机 |
| 实时 | 按时间或事件驱动任务，在规定时限内响应 | 判断是否满足时间约束，不能只看平均处理速度 |
| 微机 | 随微机能力发展，支持个人使用及更多任务和用户 | 关注开放性、通用性与硬件条件 |
| 分布式 | 多台计算机通过通信协同完成任务和资源管理 | 各节点与通信协作共同构成系统的工作过程 |

## 2 网络操作系统的分类与服务 {#s2}

**必背：** 网络操作系统是网络环境下用户与网络资源之间的接口，基本任务 4 条；按范围分专用型与通用型，按结构分对等与非对等；主要功能 6 项：文件、打印、数据库、通信、网络管理和 Internet 服务。

网络操作系统把用户与网络资源联系起来，管理共享并提供通信和服务。按适用范围可分专用型与通用型；按结构可分对等与非对等。对等结构中各节点可兼顾本地任务与共享服务，非对等结构则更明确地区分服务器与工作站的职责。

服务范围包括文件共享、打印服务、数据库访问、节点通信、网络管理及 Internet 相关服务。服务名描述能力，不能据此判断每台节点都同时开放了这些功能。部署分析应先列资源在哪里、哪些用户访问、由谁认证和管理，再选择结构，而不是先把所有计算机都设置成共享服务器。

## 4 安装任务与方案核对 {#s4}

**必背：** 安装有全新安装、升级安装、远程安装和安装 Server Core 4 种方式；最低配置为 1 GHz 的 CPU、512 MB 内存、10 GB 硬盘，建议 2 GB 内存与 40 GB 剩余空间；远程安装要求网卡支持 PXE。

在 Server 2008 的教材环境中，先核对硬件兼容、磁盘空间、安装介质及原有系统和数据的处置，再选择安装方式。全新安装重新建立环境；升级安装考虑保留原配置与系统条件；通过部署服务的远程安装依赖网络引导等前提；Server Core 以精简的服务器组件和命令行管理方式为特点。

安装按“确认条件、选择方式与版本、安装系统、初始配置、检查服务”推进。能否升级取决于具体版本与支持路径，教材的概述不等于任意旧系统都能直接升级；没给确切版本和路径时，列出核对步骤即可。

## 5 本地账户、域账户与组 {#s5}

**必背：** 本地账户存在本机 SAM 中、只能登录本机，域账户存在域控制器活动目录中、可登录域内任何计算机；组用于一次指派公共权限但不能用于登录，Administrator 与 Guest 是内置账户。

本地账户保存在相应计算机的本地安全数据库 SAM 中，域账户由域控制器上的目录服务集中管理。登录身份与访问权限有关，但“身份验证通过”不等于对所有资源有管理权。跨多台机器共享资源时，需要先辨认账户属于哪里。

用户组把具有共同授权需要的成员组织起来，便于一次分配一组权限；用户通过自己的账户登录，组本身不是一个可供多人共用密码登录的用户。一个账户可以属于多个组，分析时列成员关系与资源权限，不要把“在组中”当作所有操作均允许。

教材界面练习从“计算机管理”中的本地用户和组创建用户、设置有关账户选项，再创建组并添加成员。Administrator 与 Guest 是教材讨论的内置账户，使用时应结合各自角色与权限；练习设计不需要给出真实密码或让全体用户共同使用管理员账户。

## 6 活动目录、域与成员加入 {#s6}

**必背：** 活动目录是存储网络对象信息的分布式数据库，域是核心单元与安全边界与复制单位，OU 是域内组织与委派管理的容器，森林是一棵或多棵域树的集合；域是逻辑管理单位、站点是物理结构；安装前提含 NTFS 分区存 SYSVOL、名称符合 DNS 规范、配置 TCP/IP 与 DNS，加入域还需成员机 DNS 指向域控制器。

Active Directory 保存用户、计算机、服务等对象及其属性。容器组织对象，OU 是域内用于组织和委派管理的单元，域是相应的逻辑管理单元，域树按连续命名关系组织多个域，林包含一棵或多棵域树。域控制器承担目录服务和认证等职责，成员服务器则可提供文件、邮件或 Web 等服务，二者不可等同。

站点用于表示物理网络连接关系；域是逻辑管理关系。一个域可以跨站点，站点也可以涉及多个域，所以不能把一栋楼、一条子网和一个域机械画成同一边界。这里采用成书对原书第 196 页的明确校注 LDAPv3；不使用“第 8 版”字样，也不把尚待核实的活动目录起始年份当成记忆结论。

按教材环境整理建立域的过程：

1. 准备符合要求的名称、TCP/IP 和 DNS 配置，以及用于 SYSVOL 的 NTFS 分区。
2. 在服务器管理器中添加 Active Directory 域服务角色，再运行相应目录安装配置向导；“已装角色”与“已完成域配置”是不同阶段。
3. 按任务选择新林或现有结构，设置域名、功能级别和相关域控制器选项，明确 DNS 安排。
4. 设置数据库、日志和 SYSVOL 位置及还原模式凭据，完成向导和所需重启。
5. 将成员机的 DNS 指向能够解析该域所需记录的服务器，再按域名和有权加入的账户完成成员加入，并验证域登录与目标资源权限。

检查时说明各条件怎样支持名称定位、目录存储、身份认证与授权。不能把“IP 能通”当成已满足域发现和加入条件。

## 本章小结

- 网络服务依赖处理机、内存、设备和文件等操作系统能力；对等/非对等结构按资源及服务分工辨认，不能只按机器数量分类。
- 本地账户在本机管理，域账户由目录服务管理；用户组汇总成员授权，不是多人共用的登录账户，认证成功也不代表拥有全部权限。
- 域描述逻辑管理，站点描述物理连接；加入域还须满足名称解析和目录配置。本章 Server 2008 操作属于教材历史环境，不能作为现行部署指南。

## 练习

**1. 服务器上同时运行文件服务和备份程序，偶有一个等待磁盘。用并发、共享和异步解释现象，并区分处理机管理与文件管理。**

考点：第 1 节；层次：识记。

**答案：** 两活动在同一时间段推进体现并发，共用磁盘等资源体现共享，等待条件使进展节奏变化体现异步。处理机管理安排执行机会，文件管理组织文件和访问；等待并不能单独说明系统已失去并发能力。

**2. 小组每台机器既处理本地任务也提供共享，另一方案集中到专用服务器。按结构怎样比较？再列三项可能由网络操作系统提供的服务。**

考点：第 2 节；层次：领会。

**答案：** 前者可按对等结构分析，后者更接近非对等服务器/工作站分工。服务可包括文件、打印、通信、数据库或管理等。比较应看共享范围、管理和认证责任，不能只凭机器数目判断结构。

**3. 把教材中的 UNIX、Linux、NetWare 与 Windows Server 2008 当作相同界面的四个名字，为何会影响复习？Server Core 又应与什么区分？**

考点：第 3、4 节；层次：识记、综合应用。

**答案：** 它们在系统组织、命令和管理环境上有差别，应抓各自特点。Server Core 是教材中一种精简安装与管理形态，不是把安装介质换成网络下载的同义词；全新、升级、远程安装描述的选择维度也需要分清。

**4. 一台保有资料的旧服务器准备改装教材环境。题设没给原系统版本与升级路径，能否直接承诺原地升级？请给出先做哪些核对。**

考点：第 4 节；层次：综合应用。

**答案：** 不能。先保全与核对资料、硬件兼容和空间，再查明确版本及升级支持条件，并确定介质、回退和验证安排。缺少路径条件时应列核对过程，而不是凭“升级”一词保证配置和数据都可原样保留。

**5. 三名资料员要访问同一共享目录，有人建议共用 Administrator 密码，并把“资料员组”直接作为登录账户。怎样改成可管理的设计？**

考点：第 5 节；层次：综合应用。

**答案：** 为每人保留可区分的用户账户，用组组织共同授权，再按任务配置共享和资源权限。组用于汇总成员与权限，不直接作为一个共用登录账户；也不需要因为访问同一目录而共享最高权限身份。

**6. 域控制器上已添加域服务角色，成员机用外部 DNS，管理员因 IP 可达便跳过目录配置。列出仍缺少的阶段，并区分域与站点。**

考点：第 5、6 节；层次：综合应用。

**答案：** 仍需完成目录/域配置、名称解析和存储等前提，核对成员 DNS、域名及加入权限，再验证域登录与资源授权。域描述逻辑管理，站点描述物理网络关系；IP 可达只证明一部分通信条件，不能替代域发现。
