| 自治计算机 | 自身具备数据处理能力、不必分时借用中央计算机的计算机 | 单项选择 |
| 通信子网 | 负责数据传输、转发、交换和路由，由通信控制处理机、通信线路和其他网络设备构成 | 填空、简答 |
| 资源子网 | 负责数据处理业务，由主机、终端、外部设备、软件和信息资源构成 | 填空、简答 |

| 互联网 | 把世界各地的局域网和广域网连接起来、由网关完成转换的网络 | 单项选择 |
| 公用网 | 由电信部门建设、供任何个人和单位使用、用户缴费获取服务的网络 | 填空 |

| 点对点式网络 | 建立通信的两台计算机之间由一条物理信道相连，其他计算机不检测该分组 | 简答 |
| 网络协议 | 为进行网络中的数据通信而制定的规则、标准和约定 | 填空 |
| 语法 | 规定数据与控制信息的分组结构或格式 | 填空 |
| 语义 | 规定通信需要发出的控制信息、完成的操作动作和响应 | 填空 |
| 同步 | 网络事件实现顺序的详细说明 | 填空 |
| 网络操作系统 | 在网络环境下为用户和网络资源提供接口、实现对网络资源管理和控制的程序集合 | 简答 |
| 发送速率 | 终端或网络中间结点每秒向网络发送的比特数，单位 bit/s，主要反映设备性能 | 单项选择 |
| 传输速率 | 数据信号在传输线路上每秒传播的千米数，单位 km/s，主要反映信号及信道性能 | 单项选择 |
| 带宽 | 模拟系统指最高频率与最低频率之差，单位 Hz；数字系统指单位时间能通过的最高数据量，单位 bit/s | 填空、简答 |
| 端到端延迟 | 一个分组从一个端点到达另一个端点所花的时间，由发送、传播、处理和排队四部分组成 | 简答 |
| 吞吐量 | 单位时间内通过某个网络、信道或接口的数据量，受带宽或额定速率限制 | 填空 |
| QoS | 网络利用各种基础技术为指定通信提供更好服务的能力，是预防拥塞和从拥塞中恢复的机制 | 单项选择 |
| 可靠性 | 网络尽可能长时间稳定运行、故障时及时恢复并把损失减小的能力，靠增加冗余度提高 | 简答 |

## 必背清单

**第 1 节**

1. 【考纲 1.1】计算机网络从资源共享角度的定义：以能够相互共享资源的方式互联起来的自治计算机系统的集合。
2. 【考纲 1.2】最初的网络雏形是以单台计算机为中心的远程联机系统，代表是 IBM 的 SABRE-1 订票系统；终端不是真正的计算机，不能处理数据，要分时使用中央计算机，且每个终端独占一条通信线路。
3. 【考纲 1.3】真正意义上的计算机网络以美国 ARPANET 的建成为标志，采用分组交换技术，最初 4 个结点分别位于加州大学洛杉矶分校、加州大学伯克利分校、斯坦福研究院和犹他大学；1975 年接入 100 多个结点、结束实验阶段，1990 年被 NSFNET 代替。
4. 【考纲 1.4】ARPANET 的六条贡献：完成对计算机网络定义和分类方法的研究；提出资源子网和通信子网的结构概念；提出并实现分组交换技术；采用层次结构的网络体系结构和研究方法；促进 TCP/IP 模型的研究和应用；为 Internet 的形成和发展奠定基础。

**第 2 节**

5. 【考纲 2.1】按覆盖范围分局域网、城域网、广域网和互联网；局域网区别于其他网络的三方面是覆盖的物理范围、使用的传输技术和网络的拓扑结构。
6. 【考纲 2.2】五种拓扑结构：总线型、环形、星形、树形和网状；树形是星形的特例，把结点通过多级处理主机分层相连，比星形更节省线路成本。
7. 【考纲 2.3】总线型节省线路、结构简单、价格便宜，但不能同时支持多个结点通信，线路一处故障全网不能运行；环形一次通信的最大延迟固定、控制机制简单，一处故障全网不能通信。
8. 【考纲 2.4】星形以一台数据设备为中心，其他结点必须经中心转发，局部故障不影响全网，但对中心处理机性能要求高、线路利用率低；网状两个结点可直接通信或经其他结点转接，局部故障不影响全网、可靠性强，但结构复杂、不易管理和控制。
9. 【考纲 2.5】按介质分有线网络与无线网络：有线导向性强、带宽通常较宽、受外界干扰小、不易被监听和截获，但布线成本高、受线路布局制约；无线不受地点限制，但导向性差、易受干扰和衰落、传输带宽较小。
10. 【考纲 2.6】按所有权分公用网与专用网；按逻辑功能分通信子网与资源子网；按传输技术分广播式与点对点式，传统以太网是典型的广播式网络，基于 TCP/IP 的 Internet 属于点对点式网络。

**第 3 节**

11. 【考纲 3.1】按物理性质分硬件设备和软件设备：硬件主要包括计算机、服务器、交换机、路由器和通信介质，软件主要包括网络协议、网络操作系统和应用程序。
12. 【考纲 3.2】按逻辑位置分终端设备和网络中间设备：终端设备用于数据输入输出和处理，是资源和服务的提供者；中间设备用于传输、交换、路由和控制。
13. 【考纲 3.3】交换机是某种交换式网络内部的核心装置，负责网络内部数据的调度和转发，按处理的协议层次分为二层交换机和三层交换机。
14. 【考纲 3.4】路由器连接 IP 网络中不同类型的网络，为不同格式的数据分组选择通信路径并转发；交换机实现某种网络内部的数据存储转发，路由器在不同网络之间实现数据的路由和中转。
15. 【考纲 3.5】网络协议的三要素是语法、语义和同步；网络操作系统分任务型与通用型，代表有 Novell 的 Netware 与 Microsoft 的 Windows NT、Windows Server 系列。

**第 4 节**

16. 【考纲 4.1】定量的性能指标四项：速率、带宽、端到端延迟和吞吐量；非定量的性能指标六项：QoS、可靠性、可扩展性、安全性、标准化和成本。
17. 【考纲 4.2】发送延迟是终端或网络中间结点发送数据分组的时间；传播延迟是承载数据的电磁波信号在信道中传播所消耗的时间；处理延迟是分析处理分组的时间；排队延迟是在路由器上排队等待转发的时间。
18. 【考纲 4.3】网络情况良好时处理延迟和排队延迟都较小，总延迟主要由发送延迟决定；网络拥塞时处理延迟和排队延迟大大增加，可能在总延迟中占主导地位。
19. 【考纲 4.4】可靠性最直接的提高方法是增加网络的冗余度，即完成某种网络功能或服务时应有不止一个设备，故障时可迅速启用备用设备。

**第 5 节**

20. 【考纲 5.1】五大功能：实现数据通信、提供资源共享、提高计算机系统的可靠性、进行分布式处理、对分散对象提供集中控制与管理。
21. 【考纲 5.2】数据通信是计算机网络最基本的功能，其他功能都建立在数据通信功能之上；分布式处理可减轻主处理器负担并降低主机和链路成本，同时提高网络可靠性。

**第 6 节**

22. 【考纲 6.1】对应关系：ISO 制定开放系统互联参考模型 OSI，把网络分成 7 个层次；ITU 制定的 X 系列标准包括 X.25；EIA 制定数字设备之间串行通信的接口标准 RS-232；IEEE 制定局域网技术的 IEEE 802 系列标准。
23. 【考纲 6.2】标准不是具体的软硬件产品，而是对某种技术或产品的功能、结构或形态的描述和定义，以文字形式存在；按制定和使用标准的组织性质分为企业标准、行业标准、国家标准和国际标准。

## 必背数字与公式

| 项目 | 必背内容 |

## 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 发送速率与传输速率 | 前者是每秒发出的比特数，后者是每秒传播的千米数 | 看单位是 bit/s 还是 km/s |
| 信道带宽与信号传输带宽 | 前者是信道固有特性、只与介质有关；后者是业务信号最高与最低分量之差 | 说的是信道本身还是某一路信号 |
| 模拟带宽与数字带宽 | 模拟系统用 Hz 描述频率范围，数字系统用 bit/s 描述传输能力 | 看单位与语境 |
| 通信子网与资源子网 | 前者管传输、转发、交换和路由，后者管数据处理与服务 | 对象是通信控制处理机还是主机 |
| 总线型与环形 | 总线是一条公共线路、同一时刻只能两个结点通信；环形把终端连成闭合环，最大延迟固定 | 线路是否闭合 |
| 星形与树形 | 树形是星形的特例，用多级中心处理机分层相连 | 有几级中心处理机 |
| 广播式与点对点式 | 广播式各站都要检测分组目的地址；点对点式其他计算机不检测 | 其他计算机是否参与判断 |
| 局域网与广域网 | 局域网最常使用共享信道；广域网采用交换技术，通过交换结点连接 | 是否经过交换结点 |
| 语法、语义与同步 | 语法管格式，语义管含义和动作，同步管事件顺序 | 问的是“怎么讲”“讲什么”还是“先后” |

## 简答答题模板

**计算机网络的定义（从资源共享角度）**

一句话：计算机网络是以能够相互共享资源的方式互联起来的自治计算机系统的集合。补两点：参与互联的计算机本身具有处理能力；共享的对象包括硬件、软件和信息资源。

**ARPANET 对推动计算机网络理论和技术发展的作用**

六条按顺序写：完成定义和分类方法研究；提出资源子网与通信子网的结构概念；提出并实现分组交换技术；采用层次结构的网络体系结构和研究方法；促进 TCP/IP 模型的研究和应用；为 Internet 的形成和发展奠定基础。

**网络协议包括的基本要素**

三要素各一句：语法规定数据与控制信息的分组结构或格式；语义规定通信需要发出的控制信息、完成的操作动作和响应；同步是网络事件实现顺序的详细说明。

**端到端延迟的组成**

四部分各一句：发送延迟是发送分组的时间；传播延迟是电磁波信号在信道中传播的时间；处理延迟是分析处理分组的时间；排队延迟是在路由器上等待转发的时间。网络良好时由发送延迟决定，拥塞时后两部分可能占主导。

**带宽在模拟通信系统与数字通信系统中的含义**

模拟系统有信道带宽和信号传输带宽两个概念，前者是信道能通过的模拟信号最高频率与最低频率之差，后者是业务信号最高分量与最低分量之差，单位都是 Hz。数字系统中带宽表示通信线路传送数据的能力，即单位时间能通过的最高数据量，单位 bit/s。

**四个标准化组织及其代表标准**

ISO 制定 OSI 参考模型；ITU 的 X 系列标准包括 X.25；EIA 制定串行通信接口标准 RS-232；IEEE 制定 IEEE 802 系列局域网标准。组织名、标准名与具体产品是三类不同对象。
