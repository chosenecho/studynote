## 必背名词

| 术语 | 必背一句话 | 常考 |
| --- | --- | --- |
| 消息 | 人类能够感知的描述，如文字、图像、声音和气味，是信息的载体 | 填空 |
| 信息 | 消息中所包含的有意义的内容，是对事物状态或存在方式的不确定性表述 | 填空、简答 |
| 信号 | 传递信息的载体，通常以电磁或光的形式存在，用幅值、频率和相位的变化表示信息 | 填空 |
| 数据 | 对客观事物的性质状态及相互关系进行记载的物理符号及其组合 | 填空 |
| 数据通信 | 实现计算机系统中以编码方式处理和存储的数据的远距离传输 | 单项选择 |
| 信源 | 将消息转换为电信号的设备，如电话机、摄像机和计算机 | 填空 |
| 发送设备 | 把信源产生的信号进行编码和调制，使其适合在信道中传输 | 填空 |
| 信道 | 信号传输的媒介，分为有线信道和无线信道两大类 | 填空 |
| 接收设备 | 完成发送设备的反变换，即译码和解调，还原原始发送信号 | 填空 |
| 信宿 | 信号的终点，把信号转换为人们能识别的消息 | 填空 |
| 模拟信号 | 因变量完全随连续消息变化、因变量一定连续的信号 | 单项选择 |
| 数字信号 | 因变量离散、自变量时间取值也离散且状态有限的信号 | 单项选择 |
| 单向通信 | 又称单工通信，任何时间只能有一个方向的通信，如无线电广播 | 单项选择 |
| 双向交替通信 | 又称半双工通信，双方都能发送但不能同时，如无线对讲机 | 单项选择 |
| 双向同时通信 | 又称全双工通信，双方可同时发送和接收，如电话网 | 单项选择 |
| 基带传输 | 直接在信道中传送基带信号，以太网和令牌环网都采用 | 单项选择 |
| 频带传输 | 用基带信号去调制与信道特性匹配的载波后再传送 | 单项选择 |
| 码元速率 | 每秒传送的码元数目，又称波特率，单位 Baud，$R_B=1/T$ | 填空、综合应用 |
| 信息速率 | 每秒传送的二进制比特数，又称比特率，单位 bit/s，$R_b=R_B\log_2 M$ | 填空、综合应用 |
| 频带利用率 | 每赫兹内实现的传输速率，$\eta=R_b/B$ 或 $R_B/B$ | 综合应用 |
| 误码率 | 接收到的错误码元数在传输的总码元数中所占的比例 | 综合应用 |
| 误比特率 | 接收到的错误比特数在传输的总比特数中所占的比例 | 综合应用 |
| 信噪比 | 接收端有用信号功率与噪声功率的比值，比值越高可靠性越高 | 填空 |
| 信道极限容量 | 香农公式给出的最高信息传输速率，由带宽和信噪比决定 | 综合应用 |
| 抽样 | 以一定间隔时间采集模拟信号的瞬间值 | 填空 |
| 量化 | 把幅度上连续的抽样值用有限个量化电平表示 | 填空 |
| 编码 | 把量化得到的数值变换成一组二进制码 | 填空 |
| PCM | 脉冲编码调制，按抽样、量化、编码三步把模拟信号变为数字信号 | 简答 |
| 量化误差 | 量化信号与原信号之差的绝对值，均匀量化时最大为量化间隔的一半 | 填空 |
| 码片序列 | 码分复用中分配给每个站点的、相互正交的 N 位码组 | 简答 |
| 正交 | 两个码组的相关系数为 0，即内积为 0 | 简答、计算 |
| 检错重发 | 又称自动请求重传 ARQ，接收端检出错误后请求发送端重发 | 简答 |
| 前向纠错 | 利用纠错编码在接收端直接定位并纠正错误，不需要反馈信道 | 简答 |
| 电路交换 | 通信前建立专用通路、通信中独占资源、通信后拆除通路的交换方式 | 简答 |
| 报文交换 | 以完整报文为单位、在结点存储后转发，不预先建立连接 | 简答 |
| 分组交换 | 把报文拆成有限长度的分组、以存储转发方式逐段传送 | 简答 |
| 数据报 | 每个分组独立携带源和目的地址、分别选路、可能乱序的分组交换方式 | 简答 |
| 虚电路 | 传送前建立逻辑路径、分组按虚电路号转发的分组交换方式 | 简答 |

## 必背清单

**第 1 节**

1. 【考纲 1.1】消息是信息的载体，信息是消息中所包含的有意义的内容；香农在《通信的数学原理》中给出信息是对事物状态或存在方式的不确定性表述，某件事发生的概率越大，产生的信息量越小。
2. 【考纲 1.2】通信系统核心包括信源、发送设备、传输媒介、接收设备和信宿 5 个部分，另有不可避免的噪声；数据通信系统把这 5 部分中的信源和信宿限定为能产生、存储和处理二进制数据的设备。
3. 【考纲 1.3】模拟信号的因变量一定连续，自变量可以连续也可以离散；数字信号的因变量离散、自变量时间的取值也离散，因变量状态有限。
4. 【考纲 1.4】数据通信系统与数字通信系统不同：前者指信源和信宿处理的是二进制数据，信道中传的信号可以是模拟也可以是数字；后者只指信道中传的是离散数字信号。

**第 2 节**

5. 【考纲 2.1】按传输方向分单向通信、双向交替通信和双向同时通信，分别又称单工、半双工和全双工。
6. 【考纲 2.2】并行通信为一个字节的每一位各设一条通道、全部同时传送，速度快但耗材多、造价高，只用于内部总线等短距离；串行通信只设一条通道、逐位传输，节省开销但速度慢，用于长距离，RS-232 与 USB 都属串行接口。
7. 【考纲 2.3】异步传输以字符为单位，每字符 5～8 bit，前面加起始位、后面加 1 或 2 个停止位，不需传送时钟、实现简单，但传输效率低，只适用于低速系统。
8. 【考纲 2.4】同步传输以数据块为单位，块前加起始标志、块后加结束标志，效率高、开销小，但收发双方要建立同步时钟，实现和控制复杂，适合高速系统。
9. 【考纲 2.5】基带信号频率较低、频谱从零频附近开始、具有低通特性，适合近距离有线信道；频带传输用基带信号去调制载波，调制的基本方法有调幅、调频和调相。

**第 3 节**

10. 【考纲 3.1】有效性指信息传输的速率，可靠性指传输中出现差错的概率；两者是矛盾的指标，传输快了出错概率也高，需要折中平衡。
11. 【考纲 3.2】模拟通信系统用带宽衡量有效性、用信噪比衡量可靠性；数字通信系统用码元速率、信息速率和频带利用率衡量有效性，用误码率或误比特率衡量可靠性。
12. 【考纲 3.3】一个 M 进制码元携带 $\log_2 M$ 比特信息，因此 $R_b=R_B\log_2 M$；衡量有效性不能只看传输速率，还要看占用带宽，故有频带利用率。
13. 【考纲 3.4】香农公式 $C=W\log_2(1+S/N)$ 表明信道极限传输速率由带宽和信噪比决定；只要传输速率低于这个极限，就一定可以找到无差错的传输方法。

**第 4 节**

14. 【考纲 4.1】狭义信道仅指信号传输介质，广义信道还包括发送设备、接收设备、天线和调制器等变换装置；狭义信道又分有线信道和无线信道。
15. 【考纲 4.2】架空明线传输损耗较低，但易受天气和外界电磁干扰、带宽有限，现已基本被淘汰；双绞线绞合可减少对相邻导线的电磁干扰，屏蔽双绞线抗干扰更好但价格高、安装复杂，局域网更普遍使用非屏蔽双绞线。
16. 【考纲 4.3】同轴电缆的外导体接地，屏蔽作用好、抗电磁干扰性能好，曾用于早期局域网，现在主要用于有线电视这类频带传输；光纤利用光的全反射，具有损耗低、频带宽、抗腐蚀、不受电磁干扰和造价便宜的优点。
17. 【考纲 4.4】多模光纤用发光二极管作光源，光波有多条传输路径，时延不同会造成信号失真而限制带宽；单模光纤用激光器作光源，只有一种传播模式，传输容量大、损耗小，但制造安装工艺要求高、成本高。
18. 【考纲 4.5】无线信道的电磁波按频率划分频段：VHF 为 30～300 MHz，UHF 为 0.3～3 GHz，SHF 为 3～30 GHz；按频率、距离与位置不同，传播分为视线传播、地波和天波。

**第 5 节**

19. 【考纲 5.1】调制是用载波的振幅、频率和初始相位 3 个参数的变化表示 0 和 1；ASK 改变振幅，简单易实现但抗干扰能力较差；FSK 改变频率，简单且抗干扰能力较强；PSK 改变初始相位，可用多于二相以对传输速率起加倍作用。
20. 【考纲 5.2】单极不归零码用零电平和正电平，只有一个极性且脉冲期间电平不变，易产生但不适合长距离；双极不归零码用负电平和正电平，0 和 1 等概率时不产生直流分量、抗干扰能力强，V.24 与 RS-232C 采用它。
21. 【考纲 5.3】归零码在每个脉冲周期的中间时刻回到零电平，占空比为 50%，有利于提取时钟信号、便于同步；双极归零码同时具备无直流分量和便于同步两个特点。
22. 【考纲 5.4】差分码又称相对码，不用绝对电平而用电平变化与否表示信息，相邻脉冲有跳变表示 1、无跳变表示 0；解码时必须同时知道初始电平和变化约定。
23. 【考纲 5.5】双相码又称曼彻斯特码，只有正负两种电平，每个比特中间必定跳变，高到低表示 1、低到高表示 0；差分双相码的中间跳变只用于同步，用比特开始处有无跳变表示 1 和 0。10 Mbit/s 以太网用曼彻斯特码，IEEE 802.5 令牌环网用差分曼彻斯特码。
24. 【考纲 5.6】多元码把 k 个二进制符号映射为 $M=2^{k}$ 个离散脉冲幅值之一，每个脉冲携带的信息量更大，易于实现高速传输、提高频带利用率。

**第 6 节**

25. 【考纲 5.7】A/D 转换经过抽样、量化、编码三个环节：抽样使时间离散，量化把幅值归入有限个量化电平，编码把量化值写成二进制码组。
26. 【考纲 5.8】低通抽样定理：频带限于 $(0,f_h)$ 的信号，若 $f_s\ge 2f_h$，抽样值可完全确定原信号；$f_s=2f_h$ 称奈奎斯特速率，对应的最大间隔称奈奎斯特时间间隔；$f_s<2f_h$ 会产生混叠失真。
27. 【考纲 5.9】量化误差是量化信号与原信号之差的绝对值；均匀量化的量化间隔固定、最大误差为 $\Delta V/2$，非均匀量化按抽样值大小改变间隔，先压扩再均匀量化，可减小小信号的相对量化误差。
28. 【考纲 5.10】量化电平 $M=2^{N}$ 时可用 N 位二进制码编码；折叠二进制码最高位表示极性，其余位按零电平折叠对称，小信号误码影响小，语音 PCM 系统多采用它，通常 8 位即可保证满意质量。

**第 7 节**

29. 【考纲 6.1】多路复用的目的是充分利用信道资源、提高信道利用率和通信效率；FDM 在频域划分并留隔离频带，TDM 在时域划分等长时隙，WDM 在光纤中用不同波长，CDM 从编码域用正交码组划分。
30. 【考纲 6.2】STDM 按固定顺序分配时隙，某路无数据时该时隙空闲、浪费资源；ATDM 允许动态分配时隙，时隙与用户无固定对应关系，必须在每个时隙加用户标识，提高利用率但增加开销。
31. 【考纲 6.3】WDM 实质是频分多路复用，只是光载波频率很高、习惯用波长讨论；EDFA 不需光电转换即可直接放大光信号。
32. 【考纲 6.4】CDM 中各站码片序列相互正交，发送 +1 时发码片序列本身、发送 −1 时发其反码；接收端用目标码片与合成信号作内积再除以码片长度，结果为 1 表示发了 +1，为 −1 表示发了 −1，为 0 表示该站未发送。

**第 8 节**

33. 【考纲 7.1】随机噪声引起随机差错，具有独立性、稀疏性和非相关性，表现为随机的比特差错；冲击噪声引起突发差错，差错连续或成片、彼此相关。
34. 【考纲 7.2】检错重发（ARQ）简单、可有效纠正突发错误和严重干扰，但需要反馈信道、实时性较差；前向纠错（FEC）用纠错编码直接纠错，适用于单工系统或实时性要求高的系统。
35. 【考纲 7.3】反馈校验把收到的数据原样发回，发送端比对后重发；原理简单、无须差错编码，但需要相同传输能力的反向信道，传输效率低、实时性差；检错丢弃适用于容许一定差错且实时性要求高的系统。
36. 【考纲 7.4】停止等待 ARQ 每发一包就停下等确认，简单、所需缓冲小，但信道效率低；回退 N 步 ARQ 连续发送，接收端丢弃出错包之后的全部后续包，发送端重发该包及其后续，发送端缓存要求高、接收端很低；选择性重传只重发错包，两端都需较大缓存，但减少了重传开销。

**第 9 节**

37. 【考纲 7.5】差错编码在数据信息上附加冗余信息，建立数据与冗余之间的关联关系，接收端检查该关系是否成立；按能力分检错码与纠错码，按构成关系分线性码与非线性码，按分组映射分分组码与卷积码，按数据是否变化分系统码与非系统码。
38. 【考纲 7.6】编码效率即码率 $\alpha=k/n$，冗余度 $\beta=(n-k)/n$；冗余越多，有效数据传输效率越低。
39. 【考纲 7.7】奇校验使码字中 1 的个数为奇数，偶校验使其为偶数；单个奇偶位能检出奇数个位翻转，偶数个位翻转可能漏检，且不能定位和纠正错误；它编码简单、开销最小，但检错率不高。

**第 10 节**

40. 【考纲 8.1】电路交换包括建立电路、传输数据和拆除电路 3 个阶段，通信期间独占信道资源；优点是实时性高、时延和时延抖动小，缺点是信道利用率低、传输速率单一，且没有差错控制措施。
41. 【考纲 8.2】报文交换以完整报文为单位存储转发，不需预先建立连接，只有转发时才占用信道，线路利用率高，但结点需缓冲、报文需排队，延迟长且不固定，存储不够时会丢弃报文。
42. 【考纲 8.3】分组交换把报文拆成有限长度的分组，降低了对结点存储容量的要求，可用主存存储转发、处理更快，出错时只重发出错的分组，多个分组还可在不同链路上并发传送；代价是发送端拆分、接收端重组。
43. 【考纲 8.4】长度为 L 位的分组在传输率 R 的输出链路上产生的存储转发延迟为 $L/R$ 秒；分组在输出缓冲区等待还会产生排队延迟，缓冲区满时发生分组丢失。
44. 【考纲 8.5】数据报按目的地址选路、属无连接业务、各分组可能乱序、网络不处理丢失和差错；虚电路按虚电路号选路、属面向连接业务，由路径、每条链路各一个虚电路号和交换机内的 VC 号转换表三个要素构成，分永久型 PVC 与交换型 SVC。
45. 【考纲 8.6】虚电路与数据报的本质差别，是顺序控制、差错控制和流量控制由通信子网完成还是由端系统自己完成；虚电路保证按序到达并分担差错控制，但连接建立与拆除影响交互式应用的效率。

## 必背数字与公式

| 项目 | 必背内容 |
| --- | --- |
| 码元速率 | $R_B=1/T$，T 为码元长度，单位 Baud |
| 信息速率 | $R_b=R_B\log_2 M$，M 为信号进制 |
| 频带利用率 | $\eta=R_b/B$（bit/(s·Hz)）或 $\eta=R_B/B$（Baud/Hz） |
| 误码率 | $P_e=N_e/N$，错误码元数除以总码元数 |
| 误比特率 | $P_b=N_e^{b}/N^{b}$，错误比特数除以总比特数 |
| 香农公式 | $C=W\log_2(1+S/N)$，W 用 Hz，S/N 用功率比，C 用 bit/s |
| 低通抽样定理 | $f_s\ge 2f_h$，抽样间隔 $T\le 1/(2f_h)$ |
| 带通抽样定理 | $f_s=2B(1+k/n)$，n 为 $f_h/B$ 的整数部分，k 为小数部分 |
| PCM 码率 | 抽样频率 $\times$ 每样本位数，如 6000 次/秒乘 10 bit 得 60 kbit/s |
| 量化间隔 | 均匀量化 $\Delta V=(b-a)/M$，最大量化误差为 $\Delta V/2$ |
| 量化电平数 | $M=2^{N}$，N 为编码位数；10 位可表示 1024 个等级 |
| 编码效率 | $\alpha=k/n$；冗余度 $\beta=(n-k)/n$ |

## 简答答题模板

**消息与信息的关系**

先分定义：消息是人类能够感知的描述，是信息的载体；信息是消息中所包含的有意义的内容。再补一句度量：信息是对事物状态或存在方式的不确定性表述，某件事发生的概率越大，产生的信息量越小。

**数据通信系统模型的组成与各部分功能**

五部分加噪声：信源把消息转换为电信号；发送设备做编码和调制，使信号适合信道传输；信道是传输媒介，分有线与无线；接收设备做译码和解调，还原发送信号；信宿把信号转换为可识别的消息。噪声是固有的干扰，无法完全避免。

**异步传输与同步传输的基本原理**

异步以字符为单位，每字符前加起始位、后加 1 或 2 个停止位，接收方按起止位判断字符边界，不需传时钟，简单但效率低，用于低速。同步以数据块为单位，块前加起始标志、块后加结束标志，收发双方需建立同步时钟，效率高、开销小，用于高速。

**模拟通信系统与数字通信系统的性能指标**

模拟系统用带宽衡量有效性、用信噪比衡量可靠性。数字系统用码元速率、信息速率和频带利用率衡量有效性，用误码率或误比特率衡量可靠性。有效性与可靠性互相矛盾，速率提高往往出错概率上升，需要折中。

**抽样定理与 PCM 的三个步骤**

低通抽样定理：频带限于 $(0,f_h)$ 的信号，抽样频率 $f_s\ge 2f_h$ 时抽样值可完全确定原信号，$f_s<2f_h$ 会产生混叠失真。PCM 三步：抽样使时间离散，量化把幅值离散为有限个电平，编码把量化值写成二进制码组。量化必然带来量化误差。

**电路交换、报文交换与分组交换的区别**

电路交换先建立专用通路、通信中独占资源、结束后拆除，实时性好但利用率低。报文交换以完整报文存储转发，不需建立连接，利用率高但延迟长且不固定。分组交换把报文拆成有限长度的分组存储转发，存储要求低、出错只重发出错分组、可并发传送，代价是拆分与重组开销。
