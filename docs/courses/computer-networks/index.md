# 计算机网络技术

本课程依据张海霞主编《计算机网络技术》（机械工业出版社，2016 年版）及配套自学考试大纲，课程代码 02141。九章依次从通信基础走到协议、互联、应用、管理与安全。

## 复习路径

<ol class="course-steps" markdown>

<li><strong>背</strong>：进章节先看应试导航，分层、协议字段与端口号那张表要能默写，再做默写自测。</li>
<li><strong>读</strong>：读概念讲解，每节首行的“必背”一句钩回考点；协议题按“首部、状态、交互方向”三件事复述。</li>
<li><strong>练</strong>：做章节练习，应用题先写模型和单位；子网题区分地址总数与主机数。</li>

</ol>

应用题先写模型和单位；子网题区分地址总数与主机数；协议题区分首部、状态与交互方向。随堂自测另提供每章两道基础判断。
