### 必背清单

**第 1 节**

1. 【考纲 1】冯·诺依曼结构基本思想的四条：采用“存储程序”工作方式；由运算器、控制器、存储器、输入设备和输出设备五个基本部件组成；存储器不仅存数据也存指令，形式上数据和指令没有区别但计算机应能区分；计算机内部以二进制形式表示指令和数据，每条指令由操作码和地址码两部分组成。
2. 【考纲 1】五个基本部件的功能：运算器进行加减乘除四种基本算术运算并能进行逻辑运算；控制器自动执行指令；存储器存放指令和数据；输入设备把外部信息送入计算机；输出设备把结果送出。
3. 【考纲 1】CPU 主要包含两个基本部分：数据通路和控制器；最重要的运算部件是 ALU，ALU 中最基本的部件是加法器。
4. 【考纲 1】存储器分为内存和外存，内存包括主存储器和高速缓冲存储器，外存包括辅助存储器和海量后备存储器；目前主要的辅助存储器是磁盘存储器和固态硬盘，磁带和光盘用作海量后备存储器。
5. 【考纲 1】总线是传输信息的通路，CPU、主存和 I/O 模块通过总线互连；控制外部设备工作的控制逻辑称为 I/O 控制器或 I/O 适配器，统称设备控制器。

**第 2 节**

6. 【考纲 2】按软件的用途，一般分成系统软件和应用软件两大类。
7. 【考纲 2】系统软件四类：操作系统、语言处理系统、数据库管理系统、各类实用程序。
8. 【考纲 2】翻译程序三类：汇编程序把汇编语言源程序翻译成机器语言目标程序；解释程序把源程序中的语句按其执行顺序逐条用子程序解释并最终转换成机器指令执行；编译程序把高级语言源程序翻译成汇编语言或机器语言目标程序。
9. 【考纲 2】操作系统主要用来管理整个计算机系统的资源，包括调度、管理、监视和服务，并提供用户与硬件之间的人机交互界面和对应用软件的支持。

**第 3 节**

10. 【考纲 3】计算机系统是层次结构系统，通过向上层用户提供抽象的简洁接口而将较低层次的实现细节隐藏起来；ISA 处在硬件和软件的交界面上，是整个计算机系统的核心部分。
11. 【考纲 3】ISA 规定的内容包括数据类型及格式、指令格式、寻址方式和可访问地址空间大小、程序可访问的寄存器个数位数和编号、控制寄存器的定义、I/O 空间的编址方式、中断结构、机器工作状态的定义和切换、输入输出结构和数据传送方式、存储保护方式。
12. 【考纲 3】四类用户：最终用户、系统管理员、应用程序员、系统程序员。
13. 【考纲 3】各用户所在的层次：最终用户在最上面的应用程序层；系统管理员工作在操作系统层，看到操作系统虚拟机；应用程序员大多工作在语言处理系统层，看到高级语言虚拟机；系统程序员看到的是机器语言机器；汇编语言程序员看到汇编语言虚拟机。
14. 【考纲 3】透明：系统程序员所看到的底层机器级概念性结构和功能特性，对高级语言程序员来说是透明的。

**第 4 节**

15. 【考纲 4】从源程序到可执行目标文件的四个阶段：预处理、编译、汇编、链接；产物后缀依次为 .i、.s、.o 与可执行文件。
16. 【考纲 4】文本文件：用 ASCII 码字符或汉字字符表示的文件，源程序文件都是文本文件；目标文件是二进制文件，不可读。
17. 【考纲 4】模型机寄存器分工：ALU 进行算术和逻辑运算；通用寄存器组 GPRs 存放操作数或操作数的地址；标志寄存器存放 ALU 运算得到的标志信息，如结果是否为 0、有没有进位或借位、结果是否为负数；PC 存放将要执行的下一条指令的地址；IR 存放从主存读出的指令。
18. 【考纲 4】MAR 存放将要送到主存的主存地址，MDR 存放 CPU 与主存交换的数据；地址线单向由 CPU 送出，数据线双向。
19. 【考纲 4】指令执行的五个步骤：根据 PC 取指令到 IR；指令译码并送出控制信号；取操作数；指令执行；回写结果。
20. 【考纲 4】下一条指令地址的形成：定长指令字系统每次将 PC 自动加上指令长度，变长指令字系统需对指令译码后根据情况加上不同值；一条指令执行结束时 PC 中一定是下条指令的地址。
21. 【考纲 4】一个指令周期包含一个或多个时钟周期；时钟信号是 CPU 的主脉冲信号，其宽度称为 CPU 的时钟周期。

**第 5 节**

22. 【考纲 5】两个基本性能指标：吞吐率表示单位时间内所完成的工作量；响应时间指从作业提交开始到作业完成所用的时间。
23. 【考纲 5】用户感觉到的执行时间分 CPU 时间和其他时间；CPU 时间又分用户 CPU 时间和系统 CPU 时间；CPU 性能指用户 CPU 时间。
24. 【考纲 5】CPU 执行时间等于程序所含时钟周期数除以时钟频率，也等于程序所含时钟周期数乘时钟周期；程序总时钟周期数等于指令条数乘 CPI。
25. 【考纲 5】性能比：两台计算机性能之比是 CPU 时间之比的倒数；时钟周期、指令条数、CPI 三个因素相互制约，改变指令集减少指令条数可能引起时钟周期变宽。
26. 【考纲 5】MIPS 的含义是平均每秒钟执行多少百万条指令；它只反映定点指令执行速度，不同机器指令功能不同，用它比较性能可能不准确。

### 必背数字与公式

| 项目 | 必背内容 |
| --- | --- |
| CPU 执行时间 | $T=I\times CPI\times T_{C}=I\times CPI\div f$，I 为指令条数 |
| 程序总时钟周期数 | $\sum_{i=1}^{n}(CPI_{i}\times C_{i})$，$C_{i}$ 为第 i 类指令条数 |
| 综合 CPI | $\sum_{i=1}^{n}(CPI_{i}\times F_{i})=$ 程序总时钟周期数 $\div$ 指令条数，$F_{i}$ 为第 i 类指令所占比例 |
| 时钟周期与频率 | $T_{C}=1\div f$；1 GHz 对应 1 ns，1 MHz 对应 1 μs |
| 性能比 | 两机性能之比等于 CPU 时间之比的倒数 |
| MIPS | $f\div(CPI\times10^{6})$，单位为百万条指令每秒 |
| 主频换算套路 | 原时钟周期数 $=$ 原时间 $\times$ 原频率；新频率 $=$ 新时钟周期数 $\div$ 目标时间 |
| 五部件 | 运算器、控制器、存储器、输入设备、输出设备，共 5 个 |

### 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 吞吐率与响应时间 | 吞吐率是单位时间完成的工作量；响应时间是提交到完成的时间 | 关心“单位时间做多少”还是“这一件多久完” |
| 系统软件与应用软件 | 系统软件与具体应用关系不大，介于硬件与应用之间；应用软件面向具体应用任务 | 看是否服务于开发和运行其他软件 |
| 编译程序与解释程序 | 编译程序把高级语言源程序翻译成汇编或机器语言目标程序；解释程序按执行顺序逐条解释并最终转换成机器指令执行 | 是否先生成独立的目标程序 |
| ISA 与微体系结构 | ISA 是软件可见部分；微体系结构是软件不可感知的实现组织 | 换实现不改 ISA，程序仍能运行 |
| 字与字长 | 字表示被处理信息的单位，用来度量数据类型宽度；字长是 CPU 内部用于整数运算的数据通路宽度 | 同一机器上“字”可能固定为 16 位而字长为 32 位 |
| 主存与辅存 | 主存是 CPU 直接访问的内部存储器；辅存是运行时直接与主存交换信息的外部存储器 | 信息是否需要先调入主存才能被 CPU 访问 |
| 标志寄存器与通用寄存器 | 标志寄存器只存 ALU 运算的状态信息；通用寄存器存操作数或操作数地址 | 存的是结果状态还是数据本身 |
| CPU 时间与响应时间 | CPU 时间是 CPU 用于程序执行的时间，不含等待 I/O 的时间；响应时间含等待时间 | 程序是否在等 I/O |

### 简答答题模板

**冯·诺依曼结构计算机的基本思想**

分四条答：一、采用“存储程序”工作方式，程序和原始数据先送入主存再启动执行，启动后自动逐条取指执行；二、由运算器、控制器、存储器、输入设备、输出设备五个基本部件组成；三、存储器既存数据也存指令，形式上无区别但计算机能区分，控制器能自动执行指令，运算器能做四则运算和逻辑运算；四、内部以二进制表示指令和数据，每条指令由操作码和地址码组成，由一串指令组成程序。

**计算机硬件的基本组成与各部件功能**

先写五个部件名称，再逐条补功能一句。运算器做算术与逻辑运算；控制器译码并产生控制信号；存储器存放指令和数据；输入设备把外界信息变成计算机可接收的形式；输出设备把处理结果交付外界。CPU 由数据通路和控制器两部分组成，ALU 是最重要的运算部件。

**计算机系统的用户分类与层次**

四类用户：最终用户、系统管理员、应用程序员、系统程序员。再补各层：最终用户在应用程序层；系统管理员在操作系统层，看到操作系统虚拟机；应用程序员在语言处理系统层，看到高级语言虚拟机；系统程序员看到机器语言机器。

**指令的执行过程**

五步：按 PC 内容取出指令送 IR；对操作码译码并送出控制信号；取操作数；在 ALU 中执行运算或对存储单元读；把结果回写到寄存器或主存单元。全程由时钟信号定时，取一条指令并执行的时间就是指令周期。

**MIPS 为什么不能很好反映性能**

三点：不同机器指令集不同，指令功能不同，同样条数完成的功能可能完全不同；不同机器 CPI 和时钟周期不同，同一条指令用时也不同；MIPS 只反映定点指令速度，且峰值 MIPS 与实际性能有差距。比较性能应固定工作负载用 CPU 时间。

## 1 硬件组成与信息流 {#s1}

**必背：** 冯·诺依曼结构采用存储程序工作方式，由运算器、控制器、存储器、输入设备、输出设备五个基本部件组成，内部以二进制表示指令和数据，每条指令由操作码和地址码组成。

运算器处理数据，控制器组织操作，存储器保存指令与数据，输入设备把外部信息变为系统可处理的形式，输出设备把结果交给外界。存储程序思想使程序本身也能以编码形式存放，并由处理器按控制流程取出执行。

沿一次加法追踪：从 PC 指定位置取指到 IR，译码后读取操作数，ALU 运算，结果写回寄存器或内存，再按顺序或分支规则更新执行位置。总线或其他互连负责在部件间传递地址、数据及控制信息。CPU 由数据通路和控制器两部分组成，ALU 是最重要的运算部件，它的核心又是加法器。存储器按与 CPU 的距离分成内存与外存两段，外设则要经设备控制器接到总线上。

## 2 软件的职责 {#s2}

**必背：** 按用途软件只分系统软件与应用软件两大类；系统软件含操作系统、语言处理系统、数据库管理系统和实用程序；翻译程序分汇编程序、解释程序、编译程序三类。

系统软件为硬件使用、程序开发与运行提供基础能力，例如操作系统、编译器和链接器；应用软件面向具体任务。分类依据职责，不能只凭文件扩展名判断。库也可能服务于不同层次的软件。

汇编语言以助记符描述机器操作；高级语言提供较高层抽象。编译与解释是实现策略，某语言可以采用多种策略，不能把语言名称与唯一执行方式绑定。汇编程序把汇编语言源程序翻译成机器语言目标程序，编译程序把高级语言源程序翻译成汇编语言或机器语言目标程序，解释程序则按执行顺序逐条解释并最终转换成机器指令执行。

## 3 层次与接口 {#s3}

**必背：** ISA 处在硬件与软件交界面上，是软件可见部分；用户分最终用户、系统管理员、应用程序员、系统程序员四类；系统程序员的机器级概念对高级语言程序员是透明的。

数字逻辑实现状态与组合运算，微体系结构组织寄存器和数据通路，指令集规定机器级可见行为，操作系统提供受控服务，语言与应用在这些接口上工作。同一指令集可由不同流水线和 Cache 结构实现。

ISA 规定指令的结果与异常条件，微体系结构决定实现它的周期、通路和控制信号。四类用户分别工作在应用程序层、操作系统层、语言处理系统层和 ISA 层，越往下看到的机器细节越多。透明描述的是这种上下层之间的可见性差别。

## 4 开发、链接与执行 {#s4}

**必背：** 源程序经预处理、编译、汇编、链接生成可执行文件；PC 存下一条指令地址，IR 存现行指令，标志寄存器存 ALU 运算的状态信息，MAR 存主存地址，MDR 存交换的数据。

源文件经预处理、编译和汇编可形成目标文件；链接器解析跨模块符号并生成可装入产物；装入程序建立运行环境。动态库解析可在装入或运行时进行。程序能编译并不保证链接时一定找到全部定义。

运行时，PC 指示执行位置，IR 暂存指令，通用寄存器保存数据或地址，ALU 完成运算，条件标志在具有该机制的体系结构中记录结果性质。不是每种 ISA 都有相同的全局标志寄存器；例如经典 MIPS 的许多条件判断使用寄存器比较及分支。

一条指令的执行分取指、译码、取操作数、执行、回写五步，五步由时钟信号定时。定长指令字系统在取指时就把 PC 加上指令长度，变长指令字系统要译码后才知道加多少，两者都以“执行结束时 PC 指向下条指令”为准则。

## 5 性能评价 {#s5}

**必背：** CPU 执行时间等于指令条数乘 CPI 再除以主频；吞吐率与响应时间是两个基本指标；时钟周期、指令条数、CPI 三个因素相互制约。

同一任务的 CPU 时间可写成 $T=I×CPI/f$：I 是动态执行指令数，CPI 是平均每条指令的周期数，f 是频率。平均 CPI 依指令混合加权，频率高并不保证时间短。吞吐率、响应时间与 CPU 时间也要分开。

算例：处理器甲以 2 GHz 执行 $2×10^8$ 条指令，平均 CPI=1.5，用时 0.15 s；处理器乙执行相同条数，3 GHz、CPI=2.4，用时 0.16 s。对该任务甲快，性能比为 $0.16/0.15=16/15$。不同指令集或编译结果可能改变 I，不能只比 MIPS。

若原时间中有比例 a 的部分加速 s 倍，新旧时间比为 $(1-a)+a/s$。仅加速占比一半的部分，即便该部分无限快，整体加速比也最多趋近 2；这要求其余工作量与开销保持题设所述。

教材例 1.1 的解法值得记住：先由“原时间乘原频率”求出程序在原机器上的时钟周期数，再乘新机器的时钟周期数倍数，最后除以目标时间得到所需新频率。频率提高会带来 CPI 增大，所以频率提高的倍数不等于速度提高的倍数。

## 本章小结

- 沿指令的信息流区分存储器、控制器、ALU 和寄存器；ISA 约定可见行为，微体系结构决定内部怎样实现。
- 编译、链接、装入和运行是不同环节；链接符号问题不能靠改变运行时调度规则解决。
- CPU 时间=指令数×CPI÷主频。比较机器必须固定工作负载；若编译改变指令数，应重新计算，不能只比 GHz 或 CPI。

## 练习

**1. 追踪一条从内存读数并相加的指令，分别说明控制器、存储器、ALU 与寄存器的职责。**

考点：第 1、4 节；层次：领会。

**答案：** 存储器提供指令与数据，控制器解释指令并安排读写，寄存器保存地址、操作数和中间状态，ALU 做加法。执行中还要按 ISA 规则更新 PC，并处理可能的异常。

**2. 一个程序编译成功，链接时报符号未定义，能否通过更换操作系统调度算法解决？**

考点：第 2、4 节；层次：识记、领会。

**答案：** 不能。应检查定义、目标模块和库的链接关系；调度解决运行任务的处理器分配，不负责补齐链接符号。

**3. 两台机器使用同一指令集，但 Cache 容量和流水级数不同。应在哪些层次描述相同与不同？**

考点：第 3 节；层次：领会。

**答案：** 指令可见行为可按同一 ISA 描述，内部微体系结构不同。软件兼容仍需满足 ABI、操作系统等条件，不能仅凭 ISA 名称推断全部环境兼容。

**4. 甲：2 GHz、CPI=1.5；乙：3 GHz、CPI=2.4。各执行两亿条指令，谁先完成？若乙编译后只需一亿条，结论如何？**

考点：第 5 节；层次：简单应用。

**答案：** 由指令数×CPI÷主频，甲为 2×10⁸×1.5/(2×10⁹)=0.15 s，乙为 2×10⁸×2.4/(3×10⁹)=0.16 s，甲更快；乙只需一亿条时为 1×10⁸×2.4/(3×10⁹)=0.08 s，结论反转。
