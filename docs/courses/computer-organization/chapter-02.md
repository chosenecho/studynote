### 必背名词

| 术语 | 必背一句话 | 常考 |
| --- | --- | --- |
| 真值 | 机器数真正的值，即现实世界中带有正负号的数 | 填空、单选 |
| 机器数 | 数值数据在计算机内部编码表示的数，一定是一个 0/1 序列 | 单选 |
| 原码 | 符号位直接跟数值位的表示法，正负数仅符号位不同，零有两种表示 | 单选 |
| 补码 | 也叫 2-补码，由符号位后跟上真值的模 $2^{n}$ 补码构成，零的表示唯一 | 计算、填空 |
| 反码 | 负数补码末位不加 1 即得反码，零的表示不唯一，运算要考虑循环进位 | 单选 |
| 移码 | 阶的编码表示，等于偏置常数加阶，用于简化对阶时的比较 | 填空 |
| 模运算 | 若 A 与 B 各除以 M 后余数相同则称两者模 M 同余，n 位运算部件的模为 $2^{n}$ | 领会 |
| 溢出 | 剩下的低 n 位数不能正确表示运算结果，即丢掉的高位是结果的一部分 | 单选、计算 |
| 规格化 | 使尾数有效数字尽量占满尾数数位、并使浮点数表示具有唯一性的操作 | 简答 |
| 左规 | 结果为 $\pm0.0\cdots01b\cdots b$ 时尾数逐次左移、阶码逐次减 1 | 简答 |
| 右规 | 结果为 $\pm1b.bb\cdots b$ 时尾数右移一位、阶码加 1 | 简答 |
| 隐藏位 | IEEE 754 尾数中缺省不写的第一位 1，位置在小数点之前 | 填空、计算 |
| 非规格化数 | 阶码全 0 而尾数非 0 的数，隐藏位为 0，单精度阶为 −126 | 单选 |
| NaN | 阶码全 1 且尾数非 0 的无定义数，表示没有定义的数 | 单选 |
| 字长 | CPU 内部用于整数运算的数据通路宽度，等于运算器位数和通用寄存器宽度 | 填空 |
| 大端方式 | 最高有效字节 MSB 存放在最小地址单元中，数据地址就是 MSB 所在地址 | 单选 |
| 小端方式 | 最低有效字节 LSB 存放在最小地址单元中，数据地址就是 LSB 所在地址 | 单选 |
| 奇偶校验 | 对整段数据生成一位校验位，只能发现奇数位错、不能确定位置也没有纠错能力 | 单选 |
| 海明校验 | 把数据按规律分成若干组分别做奇偶检测，可提供多位校验信息以定位并纠正错误 | 简答 |
| 故障字 | 接收端校验位与发送端校验位按位异或的结果，位数与校验位相同 | 填空 |
| 循环冗余校验 | 把数据左移 k 位后用约定生成多项式做模 2 除，所得 k 位余数作为校验位 | 领会 |
| 全加器 | 同时考虑两个加数和低位进位的一位加法器 | 识记 |
| 溢出标志 OF | 符号位进位与最高数值位向符号位进位的异或 | 单选、简答 |
| 进位借位标志 CF | 加法时等于进位输出，减法时等于进位输出取反，统一写作 Sub 与 Cout 的异或 | 简答 |
| 保护位 | 紧跟尾数右边的一位附加位，用以保护尾数右移的位 | 填空 |
| 粘位 | 舍入位右边任何一位非 0 时被置 1 的附加位 | 填空 |

### 必背清单

**第 1 节**

1. 【考纲 1】计算机内部所有信息都用二进制表示的三条理由：二进制只有两种基本状态，容易用两个稳定状态的物理器件表示每一位；编码计数和运算规则简单，可用开关电路实现；1 和 0 与逻辑命题的真假相对应，便于实现逻辑运算和判断。
2. 【考纲 1】表示一个数值数据要确定三个要素：进位记数制、定/浮点表示和编码规则。
3. 【考纲 1】指令处理的基本数据类型分两种：数值数据和非数值数据；数值数据分整数和实数，整数又分无符号整数和带符号整数；整数用定点数表示，实数用浮点数表示。
4. 【考纲 1】R 进制系统的三个规定：采用 R 个基本符号 0 到 R−1，采用逢 R 进一的规则，第 i 位的权为 $R^{i}$。
5. 【考纲 1】十进制整数转 R 进制用“除基取余，上右下左”；十进制小数转 R 进制用“乘基取整，上左下右”；八进制一位对三位二进制，十六进制一位对四位二进制。
6. 【考纲 1】定点数编码表示主要有四种：原码、补码、反码、移码。
7. 【考纲 1】真值与机器数的关系：机器数是编码后的 0/1 序列，真值是它代表的带符号数值；同一个真值在不同位数编码下对应的机器数不同，给出编码时必须明确位数。

**第 2 节**

8. 【考纲 2】无符号整数没有符号位，默认符号为正，n 位可表示范围为 $0\sim(2^{n}-1)$，常用于地址运算或表示指针。
9. 【考纲 2】n 位补码定义：$[X_{T}]_{补}=2^{n}+X_{T}$，其中 $-2^{n-1}\leqslant X_{T}<2^{n-1}$，按模 $2^{n}$ 计算。
10. 【考纲 2】n 位补码的最大可表示值为 $2^{n-1}-1$，最小可表示值为 $-2^{n-1}$；8 位带符号整数范围是 −128 到 +127。
11. 【考纲 2】补码相对其他编码的四条优点：数 0 的表示形式唯一；是模运算系统可用加法实现减法且符号位可与数值位一起参加运算；比原码和反码多表示一个最小负数；不需要通过循环进位调整结果。
12. 【考纲 2】反码的三条不足：0 的表示不唯一；表数范围比补码少一个最小负数；运算时必须考虑循环进位。
13. 【考纲 2】移码定义：$[E]_{移}=$ 偏置常数 $+E$，偏置常数通常取 $2^{n-1}$ 或 $2^{n-1}-1$；用移码是为了对阶时按位从左到右比较正整数而不涉及符号。
14. 【考纲 2】负数补码的简便求法：符号位取 1，其余各位由数值部分“各位取反，末位加 1”得到；由补码求真值时若符号位为 1，数值部分同样“各位取反，末位加 1”。

**第 3 节**

15. 【考纲 3】实数的浮点表示格式：$X=(-1)^{s}\times M\times R^{E}$，s 决定符号，M 为尾数，E 为阶或指数，R 为基数；格式只需规定 s、M、E 各自的位数、编码方式和位置。
16. 【考纲 3】一般约定：尾数 M 用定点原码小数表示，阶 E 用移码表示。
17. 【考纲 3】规格化的两个目的：使有效数字尽量占满尾数数位以提高精度；使浮点数的表示具有唯一性。
18. 【考纲 3】规格化的两种操作：有效数位进到小数点前面时做右规，尾数每右移一位阶码加 1，阶码可能溢出；出现 $\pm0.0\cdots0bb\cdots b\times2^{E}$ 时做左规，尾数每左移一位阶码减 1。
19. 【考纲 3】IEEE 754 两种基本格式：32 位单精度含 1 位符号、8 位阶码、23 位尾数；64 位双精度含 1 位符号、11 位阶码、52 位尾数；基数隐含为 2。
20. 【考纲 3】IEEE 754 的隐藏位：尾数用原码表示且第一位总为 1，可缺省不写，因此单精度 23 位尾数实际表示 24 位有效数字，双精度 52 位实际表示 53 位。
21. 【考纲 3】IEEE 754 的偏置常数不是 $2^{n-1}$ 而是 $2^{n-1}-1$，单精度为 127、双精度为 1023；单精度阶的范围为 −126 到 127，双精度为 −1022 到 1023。
22. 【考纲 3】规格化非 0 数的值：单精度为 $(-1)^{s}\times1.f\times2^{e-127}$，双精度为 $(-1)^{s}\times1.f\times2^{e-1023}$。
23. 【考纲 3】四种特殊位序列：阶码全 0 尾数全 0 为 +0 或 −0；阶码全 0 尾数非 0 为非规格化数；阶码全 1 尾数全 0 为 $+\infty$ 或 $-\infty$；阶码全 1 尾数非 0 为 NaN。

**第 4 节**

24. 【考纲 4】逻辑数据：把一个 n 位数据看成 n 个 1 位数据，每位取 0 或 1，只能参加按位进行的逻辑运算；逻辑数据与数值数据形式相同，要靠指令操作码类型识别。
25. 【考纲 4】ASCII 码：每个字符由 7 个二进位 $b_{6}b_{5}b_{4}b_{3}b_{2}b_{1}b_{0}$ 表示，共 128 种编码；实际存储占 8 位，最高位 $b_{7}$ 一般取 0，需要奇偶校验时用作校验位。
26. 【考纲 4】ASCII 码的两条规律：数字字符 0 到 9 的高三位为 011，去掉高三位后低四位正是 8421 码；大小写字母编码只差 $b_{5}$ 这一位，该位为 0 是大写、为 1 是小写。
27. 【考纲 4】汉字系统要处理三种代码：输入码（外码）的码元是西文键盘上的按键；内码用于系统内存储查找传送；字模点阵码用于描述字形。
28. 【考纲 4】GB 2312 国标码：选出 6763 个常用汉字，码表由 94 行（区号）和 94 列（位号）组成，每个字符有唯一的区位码。

**第 5 节**

29. 【考纲 5】比特是计算机中处理、存储和传输信息的最小单位；一个字节等于 8 个比特；每个西文字符需 8 个比特、每个汉字需 16 个比特才能表示。
30. 【考纲 5】字与字长的区别：字表示被处理信息的单位，用来度量各种数据类型的宽度；字长通常指 CPU 内部用于整数运算的数据通路的宽度，等于运算器位数和通用寄存器宽度。
31. 【考纲 5】大端方式把 MSB 存放在最小地址单元、LSB 存放在最大地址单元；小端方式把 LSB 存放在最小地址单元、MSB 存放在最大地址单元；数据的地址指数所占连续存储单元中最小的地址。
32. 【考纲 5】单位换算的书写约定：本书用 K 表示 1024、用 k 表示 1000，其余前缀字母大写，其大小由上下文决定。

**第 6 节**

33. 【考纲 6】奇校验位 $P=b_{n-1}\oplus\cdots\oplus b_{1}\oplus b_{0}\oplus1$，即数据中有奇数个 1 时 P 取 0；偶校验位 $P=b_{n-1}\oplus\cdots\oplus b_{1}\oplus b_{0}$，即数据中有偶数个 1 时 P 取 0。
34. 【考纲 6】奇偶校验判定：最终校验位 $P^{*}=P'\oplus P''$，为 1 表示有奇数位错，为 0 表示正确或有偶数个错；只能发现奇数位错，不能确定位置，不具有纠错能力。
35. 【考纲 6】海明校验的主要思想：把数据按某种规律分成若干组，对每组做相应的奇偶检测以提供多位校验信息，从而对错误位置定位并纠正；它实质上是多重奇偶校验码。
36. 【考纲 6】校验位位数的确定：设数据 n 位、校验位 k 位，则故障字也有 k 位，须满足 $2^{k}\geqslant1+n+k$，即 $2^{k}-1\geqslant n+k$。
37. 【考纲 6】故障字的三种解释：各位全 0 表示无错；有且仅有一位为 1 表示校验位出错，不需要纠正；多位为 1 表示数据位出错，出错位置由故障字数值确定，将该位取反即可。
38. 【考纲 6】海明码的两种：单纠错码 SEC 只能对单个位出错定位和纠错；单纠错双检错码 SEC-DED 能发现两位错并纠正一位错，简称纠一检二。
39. 【考纲 6】CRC 的编码方式：把 n 位数据 $M(x)$ 左移 k 位，用约定的 $k+1$ 位生成多项式 $G(x)$ 做模 2 除，所得 k 位余数作为校验位拼在数据后面，形成 $(n+k,n)$ 码；校验时用同样多项式相除，能除尽表示无错。

**第 7 节**

40. 【考纲 7】全加器的两个输出：$F=A\oplus B\oplus Cin$，$Cout=A\cdot B+A\cdot Cin+B\cdot Cin$。
41. 【考纲 7】n 位加法器由 n 个全加器串行进位实现，速度慢；可用先行进位方式缩短进位等待。
42. 【考纲 7】四个标志的生成：溢出标志 $OF=C_{n}\oplus C_{n-1}$；符号标志 SF 就是和的最高位 $F_{n-1}$；零标志 ZF 为 1 当且仅当 F=0；进位借位标志 $CF=Cout\oplus Cin$，减法时 $CF=Sub\oplus Cout$。
43. 【考纲 7】溢出的两个判据：符号位产生的进位 $C_{n}$ 与最高数值位向符号位的进位 $C_{n-1}$ 不同则溢出；两个加数符号相同且与和的符号位不同则溢出。
44. 【考纲 7】补码加减运算器用一个 Sub 控制端同时完成两件事：Sub 为 1 时对 Y 各位取反并把 1 送到低位进位，实现减法；Sub 为 0 时直接相加，实现加法。
45. 【考纲 7】标志的意义随数据类型而变：ZF 对无符号数和带符号整数都有意义；SF 只对带符号整数有意义；CF 只对无符号数加减有意义，加法时 CF=1 表示无符号加法溢出，减法时 CF=1 表示有借位。
46. 【考纲 7】ALU 是能进行多种算术与逻辑运算的组合逻辑电路，核心部件是带标志加法器，多采用先行进位方式；ALUop 的位数决定操作种类，位数为 3 时最多 8 种操作。

**第 8 节**

47. 【考纲 8】原码乘法分两步：乘积符号位由两个乘数符号异或得到；乘积数值部分为两个乘数数值部分之积，按无符号数乘法实现。
48. 【考纲 8】无符号数乘法的三个要点：每求得一个 $X\times y_{i}$ 就与前面结果累加得到部分积；每次把部分积右移一位再相加，而不是把 $X\times y_{i}$ 左移；乘数位为 1 时做加法和右移，为 0 时只右移。
49. 【考纲 8】n 位原码一位乘法需 n 次“判断、加法、右移”循环，用一个 n 位加法器加一个专门进位位 C 即可实现。
50. 【考纲 8】Booth 乘法规则：乘数最低位增加辅助位 $y_{-1}=0$；$y_{i}y_{i-1}=01$ 时加 $[x]_{补}$，$=10$ 时加 $[-x]_{补}$，00 与 11 不作加减；随后算术右移一位得到部分积；重复 n 次。
51. 【考纲 8】补码乘法中遇到连续的 1 或连续的 0 可跳过加法直接右移，因此 Booth 算法效率较高；不能对需要保留负号的部分积使用逻辑右移。

**第 9 节**

52. 【考纲 9】除法前的三种判断：被除数为 0 或定点整数除法时被除数绝对值小于除数，则商为 0 余数为被除数；被除数非 0 而除数为 0，整数发生除数为 0 异常；两者都为 0，整数发生除法错异常。
53. 【考纲 9】原码除法与乘法一样要把符号位和数值位分开：商的符号为两数符号异或，商的数值为两数绝对值之商；n 位定点数除法实际是用 2n 位数除以 n 位数，因此要对被除数扩展。
54. 【考纲 9】恢复余数法的要点：试减结果为负时上商 0 并把除数加回来恢复中间余数；结果为正时上商 1。
55. 【考纲 9】不恢复余数法也称加减交替法，要点六个字“正、1、减，负、0、加”：中间余数为正则上商 1 下次做减法，为负则上商 0 下次做加法；若最后一步上商为 0 必须恢复余数。
56. 【考纲 9】循环次数：得 n 位无符号数的商需循环 n+1 次，第一次的结果用来判断溢出；n 位定点整数除法的商一定不超过 n 位，无需试商判断溢出，只要 n 次循环。
57. 【考纲 9】补码除法判断是否够减的规则：中间余数与除数同号时做减法，异号时做加法；加减后新余数与原余数符号一致则够减。

**第 10 节**

58. 【考纲 10】浮点加减的四个步骤：对阶、尾数加减、规格化、舍入，此外还要判断和处理阶的溢出。
59. 【考纲 10】对阶的原则是小阶向大阶看齐，阶小的那个数的尾数右移，右移位数等于两个阶差的绝对值。
60. 【考纲 10】尾数右移的细节：按原码小数方式右移，符号位不参加移位，数值位要把隐含的一位 1 右移到小数部分，空出位补 0；低位移出的位要保留并参加运算。
61. 【考纲 10】附加位的用法：IEEE 754 规定所有浮点运算的中间结果右边至少额外保留两位附加位，紧跟尾数右边的是保护位，其后是舍入位；舍入位右边有任何非 0 数字时粘位置 1。
62. 【考纲 10】四种舍入模式：就近舍入为默认方式，正好在两个可表示数中间时结果强迫为偶数；朝 $+\infty$ 方向舍入；朝 $-\infty$ 方向舍入；朝 0 方向舍入即直接截取。
63. 【考纲 10】浮点溢出判断看阶而不看尾数：尾数溢出可通过右规纠正，结果是否溢出主要看阶是否上溢；正阶超过最大允许值就发生阶上溢。
64. 【考纲 10】浮点乘除与加减的主要区别：乘除无需对阶，尾数用定点乘除、阶码用定点加减，后处理同样包括规格化、舍入和阶码溢出处理；IEEE 754 浮点乘法不需要左规，除法不需要右规。

### 简答答题模板

**表示一个数值数据的三个要素**

三要素：进位记数制、定/浮点表示和编码规则。任何给定的 0/1 序列，在未确定采用什么进位记数制、定点还是浮点表示以及编码表示方法之前，所代表的数值无法确定。

**为什么要对浮点数进行规格化，有哪两种操作**

两个理由：使有效数字尽量占满尾数数位，从而在运算过程中尽量多地保留有效数字；使浮点数的表示具有唯一性。两种操作：当有效数位进到小数点前面时做右规，尾数右移一位、阶码加 1，阶码可能溢出；当出现 $\pm0.0\cdots0bb\cdots b\times2^{E}$ 时做左规，尾数左移一位、阶码减 1，直到尾数变成规格化形式。

**CF、SF、ZF、OF 的产生方法**

CF 为进位借位标志，$CF=Cout\oplus Cin$，减法时 $CF=Sub\oplus Cout$，加法时 CF=1 表示无符号加法溢出、减法时 CF=1 表示有借位。SF 为符号标志，就是运算结果的最高位 $F_{n-1}$。ZF 为零标志，为 1 当且仅当结果 F 全为 0。OF 为溢出标志，$OF=C_{n}\oplus C_{n-1}$，也可由两个加数符号相同且与和的符号位不同来判定。

**补码为什么能实现减法**

补码是模运算系统，n 位部件的模为 $2^{n}$。在模 $2^{n}$ 意义下 $[x-y]_{补}=[x]_{补}+[-y]_{补}$，而 $[-y]_{补}$ 由 $[y]_{补}$ 各位取反末位加 1 得到。因此只要在加法器的 Y 输入端加反向器并用 Sub 控制端同时提供低位进位 1，就能用同一套加法电路完成加法与减法，符号位也与数值位一起参加运算。

**IEEE 754 单精度格式的组成**

1 位符号 s、8 位阶码 e、23 位尾数 f，基数隐含为 2，尾数用原码并表示且第一位总为 1 故缺省不写。偏置常数为 127，故阶等于 e−127。规格化非 0 数的值为 $(-1)^{s}\times1.f\times2^{e-127}$；阶码全 0 与全 1 留给零、非规格化数、无穷大和 NaN。

## 1 数制与转换 {#s1}

**必背：** 表示一个数值数据要确定进位记数制、定/浮点表示和编码规则三个要素；定点数编码有原码、补码、反码、移码四种。

位置计数制按位权求值。二进制与十六进制可按每四位分组互换；十进制整数转二进制可反复除以 2 取余并逆序排列，小数可反复乘 2 取整数部分。有限十进制小数不一定能用有限二进制精确表示。

转换：$(10110.101)_2=16+4+2+1/2+1/8=22.625$。8421 BCD 对每个十进制数字分别编码，因此十进制 26 的 BCD 为 0010 0110，而普通二进制为 0001 1010。

R 进制系统的三条规定是基本符号为 0 到 R−1、逢 R 进一、第 i 位权为 $R^{i}$。机器数一定是一个 0/1 序列，真值则是它代表的带符号数值；同一个真值在不同位数编码下对应的机器数不同，所以给出编码时必须说明位数。

## 2 定点整数 {#s2}

**必背：** n 位无符号整数范围为 $0\sim(2^{n}-1)$，n 位补码范围为 $-2^{n-1}\sim(2^{n-1}-1)$；负补码按“各位取反，末位加 1”求。

n 位无符号整数范围是 0 到 $2^n-1$；二进制补码范围是 $-2^{n-1}$ 到 $2^{n-1}-1$。负补码可通过模 $2^n$ 的同余解释。原码与反码有正负零，补码只有一种零编码且负端多一个数。

8 位下，+37 为 00100101，-37 的补码为 11011011。带符号扩展复制符号位，无符号扩展补零。

补码的定义是 $[X_{T}]_{补}=2^{n}+X_{T}$，按模 $2^{n}$ 计算，所以 n 位补码比原码和反码多表示一个最小负数 $-2^{n-1}$。反码的不足之处是零不唯一、少一个最小负数、运算要考虑循环进位。移码把阶加上偏置常数变成正整数，只用于浮点数的阶。

## 3 实数与浮点编码 {#s3}

**必背：** 浮点格式只规定符号、尾数、阶三部分；单精度为 1 位符号、8 位阶码、23 位尾数，偏置常数 127，值为 $(-1)^{s}\times1.f\times2^{e-127}$。

定点小数把小数点位置固定；浮点把符号、指数和有效数字分开。IEEE 754 binary32 的常见布局为 1 位符号、8 位指数编码、23 位尾数字段。正规数按 $(-1)^s×(1.f)×2^{E-127}$ 解释；指数全零和全一须按零、次正规数、无穷与 NaN 等规则处理。

算例：$-5.75=-(101.11)_2=-(1.0111)_2×2^2$，符号为 1，指数编码 129，尾数字段从 0111 开始，binary32 位型为十六进制 C0B80000。这里的位型顺序不等同于内存字节端序。

规格化的两个目的是把有效数位占满尾数并让表示唯一。右规发生在有效数位进到小数点前面时，尾数右移一位、阶码加 1；左规发生在结果形如 $\pm0.0\cdots0bb\cdots b\times2^{E}$ 时，尾数左移一位、阶码减 1。IEEE 754 的隐藏位位于小数点之前，所以单精度 23 位尾数实际表示 24 位有效数字。

## 4 非数值编码 {#s4}

**必背：** ASCII 码用 7 位表示一个字符共 128 种编码，实际存储占 8 位，最高位一般取 0 或作奇偶校验位；汉字要区分输入码、内码与字模点阵码。

字符编码把字符映射为数值，存储编码再决定如何变成字节序列。ASCII 定义一个有限字符集合，Unicode 码点不是固定的单字节值；UTF-8 对不同码点使用不同字节数。汉字数、码点数与文件字节数不能直接相等。

比较或排序字符串时还可能涉及大小写、组合字符和排序规则。数值 65 与字符 A 是否呈现同样字节取决于使用的表示方式，不是抽象值相同。

ASCII 的两条规律值得记住：数字字符 0 到 9 的高三位固定为 011，去掉高三位后低四位正是 8421 码；大小写字母只差 $b_{5}$ 一位。逻辑数据把 n 位看成一串独立的 1 位数据，只能按位运算，与数值数据形式相同，要靠指令操作码区分。

## 5 宽度、端序与对齐 {#s5}

**必背：** 字长是 CPU 内部整数运算数据通路的宽度；大端把 MSB 放最小地址，小端把 LSB 放最小地址。

机器字长、指令长度、地址宽度与总线宽度分别描述不同对象。大端把多字节值的高有效字节放在低地址，小端相反。值 0x6A2C 的小端内存从低地址起是 2C、6A，大端则是 6A、2C。

对齐要求起始地址满足粒度约束。结构体布局可能插入填充；跨行访问可能增加传输，一些原子操作跨边界时也有额外限制。Split Lock 是特定平台对跨缓存行锁定操作的术语，不能推广成所有未对齐访问都会报错。

比特是最小单位，一字节等于 8 比特，字则是度量数据类型宽度的处理单位，与字长不是同一概念。数据长度单位的换算还要看对象：描述容量时 K 表示 1024，描述带宽或传输率时 k 表示 1000。

## 6 检错与纠错 {#s6}

**必背：** 奇偶校验能发现奇数位错但不能定位也不能纠错；海明码需满足 $2^{k}\geqslant1+n+k$；CRC 用生成多项式做模 2 除，余数作校验位。

奇偶校验使指定范围的 1 的个数满足奇或偶条件，可检出奇数个位翻转，不能保证检出偶数个位翻转。海明码把校验位放在 1、2、4 等位置，通过校验组合生成综合征。最小距离为 3 的 SEC 方案只能保证单错纠正；若再加总校验位形成 SEC-DED，综合征和总校验结果可以把双错判为“可检测但不可纠正”。题目未说明附加总校验位时，不应擅自使用 SEC-DED 的结论。

偶校验海明例：把数据 1011 依次放在位置 3、5、6、7，算得位置 1、2、4 为 0、1、0，码字按位置 1 到 7 是 0110011。若位置 6 翻转，校验失败权重为 2 和 4，综合征 6，定位该位。CRC 则把比特串当多项式做模 2 除法；移位、异或与除数阶数都必须按约定。

奇校验位是各数据位的异或再与 1 异或，偶校验位就是各数据位的异或。接收端把重新算出的校验位与收到的校验位异或，结果为 1 表示有奇数位错，为 0 表示正确或有偶数个错。

## 7 加法器、ALU 与标志 {#s7}

**必背：** $OF=C_{n}\oplus C_{n-1}$；SF 是和的最高位；ZF 为 1 当且仅当结果为 0；$CF=Cout\oplus Cin$，减法时 $CF=Sub\oplus Cout$。

全加器由两输入和进位产生和位与输出进位；串行进位路径随位数延长，超前进位利用生成与传递关系缩短部分等待。ALU 在控制信号作用下选择算术、逻辑与移位等功能。

无符号进位与有符号溢出是两种判断。8 位下，01111100+00001010=10000110，即 124+10，超出有符号上界；但没有最高位输出进位。判断补码溢出可看同号相加是否得到异号结果。减法常用加上减数补码实现，借位标志的编码仍依 ISA 规定。

[补码加减练习](../../labs/complement.md)用两组加法对照输出进位与有符号溢出。

补码加减运算器只用一个 Sub 控制端：Sub 为 1 时把 Y 各位取反并把 1 送入低位进位，完成减法；Sub 为 0 时直接相加。标志的意义随数据类型而变，SF 只对带符号整数有意义，CF 只对无符号数加减有意义。

## 8 定点乘法 {#s8}

**必背：** 原码乘法符号由两乘数符号异或、数值部分按无符号乘法算；Booth 乘法按相邻位对 01 加 $[x]_{补}$、10 加 $[-x]_{补}$，其余只算术右移。

无符号移位加法按乘数位决定是否加入被乘数的移位项，完整乘积通常需要双倍位宽。补码乘法还要处理符号，可用符号扩展或 Booth 重编码等方案。

以相邻位对 (q_i,q_{i-1})、低端补 q_-1=0 为约定，Booth 的 01 加 M，10 减 M，00 与 11 不作加减，再按算法算术移位。追踪：乘数 0110 的非零重编码项是 $-2^1+2^3=6$，因此 $(-3)×6=(-3)×(-2+8)=-18$，8 位补码是 11101110。不要把逻辑右移用于需要保留负号的部分积。

原码一位乘法每次只判断乘数一位，n 位乘数就要 n 次“判断、加法、右移”，用一个 n 位加法器加一个专门进位位即可实现。两位一乘可以把循环次数减半，代价是增加少量逻辑线路。

## 9 定点除法 {#s9}

**必背：** 恢复余数法试减为负就加回除数；不恢复余数法按“正、1、减，负、0、加”交替加减；得 n 位商要循环 n+1 次。

除法迭代逐步生成商位并维护部分余数。恢复余数法在试减为负时恢复；不恢复余数法根据上一步余数符号选择下一步加或减，并在结束时按规则修正。两者的控制次序不能拼接使用。

无符号验证：29 除以 4 得商 7、余数 1，满足 $29=4×7+1$ 且 $0≤1<4$。带符号除法还需约定商的舍入方向和余数符号；除零及最小补码数除以 -1 都需要单独检查。

逐位恢复余数追踪：输入 11101，从 R=0 开始，每次移入下一位再试减 4。试减为负就恢复并置商位 0，否则保留差并置商位 1。

| 移入位 | 试减前的 R | R−4 | 恢复或保留后的 R | 商位 |
| --- | --- | --- | --- | --- |
| 1 | 1 | -3 | 1 | 0 |
| 1 | 3 | -1 | 3 | 0 |
| 1 | 7 | 3 | 3 | 1 |
| 0 | 6 | 2 | 2 | 1 |
| 1 | 5 | 1 | 1 | 1 |

商位串为 00111，最后 R=1。

不恢复余数法比恢复余数法少一次加法，控制更规整，所以计算机中普遍采用；但若最后一步上商为 0，仍必须把试商时减掉的除数加回去。补码除法还要按中间余数与除数是否同号来决定做减法还是加法。

## 10 浮点运算 {#s10}

**必背：** 浮点加减按对阶、尾数加减、规格化、舍入四步走，对阶原则是小阶向大阶看齐；浮点溢出看阶是否上溢，不看尾数。

浮点加减通常先检查特殊值，再对阶、运算、规格化、舍入并检查范围。对阶时移走的位会影响舍入，保护位、舍入位和粘滞位帮助判断截断部分。IEEE 754 有多种舍入方向，题中需固定规则。

精确算例：$1.5=(1.1)_2$，$0.375=(0.011)_2$，对阶相加为 $(1.111)_2=1.875$。与此不同，精度不足时小数可能被舍去，浮点加法一般不满足任意重排下的结合律。浮点乘法对指数相加、有效数字相乘，之后同样要规格化和舍入。

附加位的套路是保护位紧跟尾数右边、舍入位紧随其后、粘位在舍入位右边有任何非 0 时置 1。就近舍入是默认方式，正好落在两个可表示数中间时强迫结果为偶数。乘除与加减的差别在于不必对阶，尾数用定点乘除、阶码用定点加减。

## 本章小结

- 位串先声明编码与位宽再解释。n 位补码范围为 −2 的 n−1 次方到 2 的 n−1 次方减一；截断、符号扩展、进位与有符号溢出分别判断。
- 浮点编码先正规化，再填写符号、带偏置阶码和尾数字段；运算还要经历对阶、求和、规格化及舍入。编码位序与内存端序不要混用。
- 检错和纠错能力取决于具体冗余与错误模型；SEC 海明码不能保证双错纠正，CRC 计算须声明生成多项式、位序和初始化等约定。

## 练习

**1. 将二进制 10110.101 转成十进制，并比较十进制 26 的 BCD 与普通二进制。**

考点：第 1 节；层次：简单应用。

**答案：** 按位权相加，前者为 16+4+2+1/2+1/8=22.625；26 的 BCD 是 0010 0110，8 位普通二进制为 0001 1010。BCD 每一组表示一个十进制数字。

**2. 写出 -37 的 8 位补码并扩展到 16 位。计算 8 位补码 124+10，区分进位与溢出。**

考点：第 2、7 节；层次：简单应用。

**答案：** 37 的 8 位正数编码为 00100101，取反得 11011010，再加一得 −37 的补码 11011011；复制符号位扩展为 11111111 11011011。124+10 的低 8 位为 10000110，补码解释为 -122，有符号溢出；无最高位输出进位。

**3. 推导 -5.75 的 binary32 位型；若内存使用小端，最低地址字节是什么？**

考点：第 3、5 节；层次：简单应用。

**答案：** 正规化为 $-1.0111×2^2$，符号位为 1，阶码为 2+127=129=10000001，去掉隐含前导 1 后尾数为 0111 再补 19 个零；合并为 C0B80000，小端最低地址字节为 00。编码位序与字节地址顺序要分别处理。

**4. 为什么三个汉字不能一律按三字节计算文件长度？ASCII 字符编码与整数二进制表示的职责有什么不同？**

考点：第 4 节；层次：领会。

**答案：** 字符可能用 UTF-8 等多字节编码，长度取决于具体码点和编码。字符编码规定符号与数值的对应，整数表示规定一个数值如何放入位串，二者不能混为一谈。

**5. 对数据 1011 采用本节位置约定的偶校验海明码，给出码字与第 6 位翻转后的综合征。能否保证纠正两个错误？**

补充：对数据 1001 使用生成多项式位串 1011，不反射、不作初末异或，按模 2 长除求三位 CRC 余数。

考点：第 6 节；层次：简单应用、领会。

**答案：** 码字是 0110011，综合征为 6。本题没有附加总校验位，按 SEC 处理：可保证单错纠正，但双错的综合征不能可靠定位，不能把它当单错改正。若题干另加总校验位，则应按 SEC-DED 理解为单错纠正、双错检测。

CRC 把数据后补三位零，1001000 先异或 1011000 得 0010000，再异或 0010110 得 0000110，余数为 110。传送码字 1001110 可被 1011 模 2 整除。不同 CRC 初值与反射约定会改变结果。

**6. 用 Booth 重编码说明 6 为什么可写为 -2+8，再验证 -3 乘 6 与 29 除 4 的结果。**

考点：第 8、9 节；层次：领会、简单应用。

**答案：** 0110 的相邻位对在 i=1 产生减项、i=3 产生加项，所以是 -2+8。乘积 -18，8 位补码 11101110；除法商 7、余 1，满足被除数=除数×商+余数。

**7. 以二进制对阶计算 1.5+0.375。这个结果恰好精确，是否说明其他浮点加法都不会舍入？**

考点：第 10 节；层次：简单应用、领会。

**答案：** $1.100+0.011=1.111$，即 1.875。恰好可表示只说明该算例无舍入损失，不能推广到超出有效位数或不可精确二进制表示的数。
