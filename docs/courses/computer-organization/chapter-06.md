## 1 输入与输出设备 {#s1}

**必背：** 输入设备把外界信息转成计算机可处理的二进制代码，输出设备把处理结果转成人可识别的形式；键盘按列扫描接地检查得到扫描码；显示器行频帧频互为扫描周期的倒数。

输入设备把外界的信息翻成机器能读的二进制代码，输出设备把机器的结果翻回人能看的形式。键盘、显示器、传感器、网卡这几种，速率、传输单位、实时要求差得远。

设备一般都不直连处理器内部数据通路，要过接口和控制器。设备自己有多快，跟接口上标的带宽也不是一回事。

输入输出系统是外部设备及其接口线路、I/O 控制部件以及 I/O 软件的总称。四块各管一段：设备负责换能，接口线路负责电平与连接，控制部件负责时序与仲裁，软件把一次读写拆成命令、状态、数据三类交互。缺哪块，另一块再快也补不回来——盘本身 200 MB/s，挂在一个每笔事务要走 80 ns 才结束的旧总线上，实测吞吐照样被总线卡住。

颜色深度指每个像素对应的二进位数，它同时决定一帧占多少显存、刷新要多少带宽。24 位即 2²⁴=16 777 216 色；1024×768 的 24 位画面一帧要 1024×768×3 B=2 359 296 B≈2.25 MiB，按 60 Hz 刷新，显存带宽约为 2.25 MiB×60≈135 MiB/s，换成十进制是 141.6 MB/s。颜色深度翻到 48 位，帧缓存和带宽一起翻倍，高分辨率下先压颜色深度常常比换显卡划算。

键盘的扫描过程是每隔 3 到 5 ms 顺序把各列接 0 电平，被按下的键所在行输出变低电平，由列号与行号合成扫描码，再由单片机串行发出，主机收到后串并转换并向 CPU 发中断。打印机靠打印控制器与主机相连，控制器里数据锁存器暂存打印数据、命令译码器解释命令、控制锁存器存控制命令、状态锁存器存忙与缺纸等状态。显示器在字符模式下显存存字符编码与属性、字形在字符发生器中；图形模式下点阵信息直接存显存。

## 2 外部存储器 {#s2}

**必背：** 磁盘读写分寻道、旋转等待与读写三种操作，平均存取时间等于三者之和；RAID 用冗余换可靠性，RAID 0 无冗余、RAID 1 镜像、RAID 5 分布校验；SSD 用闪存，读快于写。

机械盘访问走寻道、旋转、传输三段；SSD 由闪存加控制器组成；光盘又是另一套读写机制。容量、持续带宽、随机延迟、耐久性、可恢复性，这五项得分开看。

机械模型：7200 rpm 每转约 8.333 ms，随机相位的平均旋转等待约 4.167 ms；给定寻道与传输时间后才能算访问总量。SSD 不包含机械旋转，不能把转速公式移植过去。

磁盘的地址由柱面号、磁头号、扇区号三者给出，磁头号就是盘面号，磁道号就是柱面号。温盘每个扇区由头空、ID 域、间隙、数据域和尾空组成，数据域中真正的数据为 512 B。硬盘与主机之间是高速外设接口，硬盘控制器与主机采用成批数据交换方式，经 DMA 把数据传送到主存储器。RAID 的级别不是简单的层次关系，而是具有三个共同特性的不同设计结构。

盘面参数要看两套密度：道密度是沿磁道分布方向上单位长度内的磁道数（TPI 或 TPM），位密度是沿磁道方向上单位长度内放进去的二进制位数（BPI 或 BPM）。同一盘片外圈周长长、里圈周长短，内圈位密度更高才挤得下同样多的扇区，所以标称位密度取最小位密度才安全。数据传输率则是完成磁头定位和旋转等待之后，单位时间内从介质读出或写入的二进制信息量，它只算数据域，不含头空、间隙这些开销。

算一例：道密度 1000 TPI、位密度 256 BPI，盘片直径 2 in，磁道只占半径 0.5 in 到 1 in 这一圈，共 1000×0.5=500 个磁道；最内圈直径 1 in，周长 π×1≈3.142 in，一圈存 3.142×256≈804 bit≈100.5 B。转速 7200 rpm 即每秒 120 转，最内圈的数据传输率约 100.5×120≈12 060 B/s≈12 KB/s。外圈直径 2 in、周长恰是最内圈的两倍，同一盘片在不同磁道上的传输率能差一倍，所以标称位密度取最内圈值、数据传输率也常报最小值。

冗余磁盘阵列是把多个独立操作的磁盘组织成阵列、以冗余技术提高可靠性，简称 RAID；冗余磁盘阵列关心的是可靠性和并行度，不是单盘参数。RAID 0 拼接无冗余，RAID 1 镜像写两遍，RAID 5 用分布校验。固态硬盘是用 NAND 闪存组成的外部存储系统，通过标准硬盘接口连接主机，简称 SSD。它没有磁道、柱面和旋转等待，所以道密度、位密度、半转等待这些式子一概不能套；按块擦写、写放大、垃圾回收才决定它的持续写入表现。

## 3 互连与总线 {#s3}

**必背：** 系统总线由地址线、数据线、控制线三组构成；带宽 $B=W\times F\div N$；同步总线靠公共时钟定时但有最慢设备与时钟偏移两个限制，异步握手以请求应答协调。

总线上跑的无非地址、数据、控制三类信息。同步总线按共同节拍采样，异步靠请求和应答握手；多个主控者抢总线时由仲裁定先后。串行的点到点链路和传统的共享并行总线，拓扑就不是一个路子。

模型：32 位数据宽、每周期一次数据传输、频率 50 MHz，理想数据带宽为 200 MB/s；若一次完整事务占 4 周期且只交付一个数据字，事务层有效值为 50 MB/s。

这里要分清三个词。总线宽度是数据线的条数，决定一次并行送出多少位；总线带宽是总线的最大数据传输率，它由宽度和频率一起定，宽度×频率就是理论上限；总线寻址能力由地址线位数确定，讲的是能编出多大的地址空间，跟一次搬多少无关。32 位宽、50 MHz 得 4 B×50×10⁶=200 MB/s；换成 64 位宽、同样频率翻成 400 MB/s，而地址线 32 根仍是 2³²=4 GiB 的寻址空间，只加数据线并不会让寻址变大。芯片内部连接各元件的总线叫内部总线，它和板上连 CPU、存储器、I/O 模块的系统总线不是一个层次，内部总线宽度常常比引出到片外的那条更宽。

异步总线不用公共时钟，靠前一信号的结束当作下一信号的开始，信息改变严格按顺序推进，所以快慢设备能混挂，代价是每次都要走一遍请求—应答，固定开销大。突发传送则是在给一次首地址之后连着搬一整块数据，后续地址默认等于前址加 1，省掉了重复发地址的周期；一次事务的有效值之所以低于节拍上限，正是发地址、等待、恢复这些周期在摊薄它。总线上有主控设备和从设备之分：主控设备发出总线控制命令，如处理器、DMA 控制器；从设备只接受命令并响应，如存储器、I/O 接口。谁能发起事务谁是主控，这个身份按事务算，不按器件算。

总线连接好在灵活、便宜，坏在容易变成通信瓶颈。同步总线的节拍得照最慢的设备定，时钟偏移又卡着长度，所以高速互连越来越多改成异步串行。PCI-Express 就是每对差分线单向收发，还把每个字节摊成 10 位传，好让接收端靠锁相环从 0-1 跳变里把时钟捞回来。

## 4 I/O 接口与寻址 {#s4}

**必背：** 接口四项职能是数据缓冲、错误或状态检测、控制和定时、数据格式转换；I/O 端口有独立编址与统一编址两种，后者也称存储器映射方式，用访存指令即可访问端口。

接口里的寄存器通常就三种用途：装数据、报状态、收命令。统一编址把设备寄存器摆进内存地址空间，独立编址另开一块 I/O 空间配专门指令。不管哪种，读写设备都得守它的副作用和顺序，不能当普通 RAM 随便缓存、随便重排。

一次典型交互先检查或等待就绪，再按方向搬运数据，最后确认完成或错误。读状态是否清除某些位、写控制是否启动操作，都要由接口协议定义。

三个寄存器各管一件事。数据缓冲寄存器是用于匹配主机与外设速度的寄存器，也就是数据端口，它把快速总线上的并行数据暂存起来，等慢速外设一位一位或一块一块取走，反过来也把外设送来的数据攒够再交给主机；它有端口地址，能被 CPU 直接读写，但不能当看不见延迟的普通变量。控制寄存器存放 CPU 送来的命令字，也称命令寄存器，启动设备、设定方向、选择模式、开中断都靠写入它某几位完成。状态寄存器只是报状态，供 CPU 查询就绪、忙、错误。

举例：一个设备要“启动一次接收并允许中断”，CPU 先往控制寄存器写命令字（置启动位与中断允许位），然后反复读状态寄存器看就绪位是否置 1，就绪后再读数据缓冲寄存器取走数据。三步顺序不能打乱——先取数据再清状态，会把下一次到达的数据当成这一次的；控制寄存器的启动位写完要等设备把它清回，才知道命令已被接受。

接口在主机侧叫内部接口、在外设侧叫外部接口，两侧的分工决定了整条通路是“CPU 和内存—I/O 总线—I/O 接口—接口电缆—外设”。独立编址下地址码形式无法区分两个空间，必须靠专门 I/O 指令；统一编址下靠地址范围区分，因此不需要专用指令。I/O 指令属于特权指令，只能在内核的底层 I/O 软件中使用。

## 5 控制方式与开销 {#s5}

**必背：** 三种控制方式是程序直接控制、中断控制、DMA 控制；中断响应三条件是开中断、有未屏蔽请求、当前指令执行完；DMA 请求总线控制权而中断请求处理器时间。

查询是 CPU 自己一遍遍问状态，中断是等设备来敲门，DMA 干脆把整批搬运交给设备侧的引擎。中断的响应顺序受优先级、屏蔽、嵌套三层影响；响应了中断，不等于就要切换进程。

程序直接控制分两种走法。无条件传送不看状态，直接搬，只适合状态永远就绪的设备；条件传送先读状态，就绪才传。条件传送里又有独占查询和定时查询：独占查询是设备被启动后 CPU 就一直持续对设备查询、完全控制 I/O 整个过程的方式，中间不干别的活，设备慢它就干等着，一个 10 000 字/s 的设备传 1 000 字要等 100 ms，这 100 ms 全烧在空转上；定时查询则隔一段时间问一次，空出的时间能做别的，代价是发现就绪变晚，响应延迟不再确定。

中断 I/O 是由外设向 CPU 发中断请求、CPU 转中断服务程序完成数据交换的方式，也称程序中断方式。它把“等”从 CPU 身上挪走：设备就绪时发请求，CPU 在两条指令之间响应，平时照常跑程序。和独占查询对比，同样 1 000 字、每次服务 5 μs，中断方式只花 5 ms 服务时间，其余时间都能还给其他任务；代价是每字一次响应与现场保存的固定开销，设备速率越高，这层固定开销占的比例越大。

中断要分清两种优先级。中断响应优先级由查询程序或中断判优电路决定，反映多个中断同时请求时谁先被响应，它在设备配置时就定下来了；中断处理优先级由各自中断屏蔽字动态设定，反映本中断与其他中断之间的处理优先关系，运行中改一个字的某一位就能改变。两者可以不一致，而且常常故意做成相反：把响应优先级给紧急设备（它必须被最先看到），把处理优先级给耗时长的设备（它一进来就把别人挡在外面，让紧急设备能插进来）。

中断响应周期里硬件执行的那条隐指令叫中断隐指令，它不由程序写，也读不出来，干三件事：关中断、保护断点、识别中断源。它保护的只是断点信息，即指令无法直接读取的程序计数器与程序状态字寄存器的内容，由处理器在中断响应时自动保存；现场信息是用户可见的通用寄存器内容，一般由中断服务程序通过指令保存到栈中。所以进服务程序后，先存现场再开中断的顺序不能反，否则新中断会覆盖掉还没存完的那批寄存器。

DMA 的三种传送安排也要分开记。CPU 停止法是 DMA 传输时由 DMA 控制器发停止信号使 CPU 脱离总线、停止访问主存直到传完一块的方式，吞吐高但 CPU 被整块时间锁死；交替分时访问法把每个存储周期分成两个时间片分别给 CPU 和 DMA，两边都不停，代价是 CPU 的有效访存速度降到原来的一半左右；周期挪用则只在 DMA 需要时才借走一个存储周期，CPU 大部分时间不受影响。

| 比较项 | 程序查询 | 中断控制 | DMA |
| --- | --- | --- | --- |
| 就绪通知 | CPU 反复读状态 | 事件引发中断 | 控制器按传送协议工作 |
| 常规模型中的数据搬运者 | CPU | CPU | DMA 控制器或设备 DMA 引擎 |
| CPU 的准备工作 | 设置命令和缓冲 | 设置命令、缓冲和中断 | 设置地址、长度、方向与描述符 |
| 等待期间 CPU | 查询占用执行机会 | 可执行其他任务 | 可执行其他任务 |
| 完成处理 | 查询发现完成 | 中断服务处理 | 常以完成中断通知 |
| 共享资源影响 | 指令与访存开销 | 服务程序和切换开销 | 总线或内存竞争及一致性维护 |

DMA 周期挪用使共享传输资源的部分周期交给 DMA，不保证 CPU 完全不停顿，也不要求整个传送阶段都停机。现代架构下的 DMA 还要处理设备可见地址、IOMMU 和 Cache 一致性；设备能访问物理资源，不表示可以无约束地绕过隔离。

开销模型：设备速率 10000 字/s，按每字一次中断、每次服务 5 μs 计，CPU 服务时间占比为 5%。若每 20 字一次 DMA 完成中断、每次 8 μs，则中断服务占比为 0.4%，但尚未计初始化、映射、同步与内存争用。

多重中断靠中断屏蔽字实现，屏蔽字决定本中断能被哪些中断打断。中断服务程序在准备与恢复阶段必须关中断，否则断点与现场可能被新中断破坏；进入处理阶段后再开中断，才能允许更高优先级的中断嵌套。

## 本章小结

- 挑接口别只盯峰值带宽，数据粒度、响应期限、完成一次要花多少 CPU 时间都得算进去。设备寄存器就算摆在统一编址的内存里，副作用和顺序照样跑不掉。
- 总线节拍上限看每次传几个字节、频率多高；一次事务真正交付多少，还得扣掉发地址、等待、恢复那几个周期。两个口径别混着用。
- 三种方式的 CPU 负担要拿题里的数算，别背印象。完成中断占比小了，不等于初始化、同步、内存争用这些成本就没了。

## 练习

**1. 为传感器与离线备份盘设计接口，为什么不能只比较最高带宽？机械盘的平均半转等待又有哪些假设？**

考点：第 1、2 节；层次：领会。

**答案：** 还要比较响应期限、数据粒度、随机延迟和可靠性。平均半转采用随机且均匀的到达相位等模型，不能描述 SSD，也不等于每次机械访问恰好等半转。

**2. 32 位、50 MHz 总线每事务用 4 周期传一个字，理想节拍带宽与该事务有效带宽各是多少？**

考点：第 3 节；层次：简单应用。

**答案：** 每字 32÷8=4 B，时钟周期 1/(50×10⁶)=20 ns；每周期一字的节拍上限为 4×50×10⁶=200 MB/s。每事务占 4×20=80 ns，只交付 4 B，故事务有效带宽为 4/(80×10⁻⁹)=50 MB/s。前提未包含其他仲裁和等待。

**3. 某设备把状态寄存器放在普通地址空间中，是否可以把读取它当作没有副作用、可任意重排的普通变量访问？**

考点：第 4 节；层次：领会。

**答案：** 不可以。统一编址只说明地址组织，设备访问仍需遵守缓存属性、顺序和副作用协议，例如读取清除状态位。

**4. 10000 字/s 的设备每字中断服务 5 μs，求服务占比；改为每 20 字一次、服务 8 μs 的 DMA 完成中断后，该占比是多少？是否等于全部 CPU 成本？**

考点：第 5 节；层次：简单应用、领会。

**答案：** 原占比 10000×5 μs=0.05，即 5%；新占比 500×8 μs=0.004，即 0.4%。这只计指定中断服务，还需考虑初始化、同步等开销。
