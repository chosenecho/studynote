### 必背清单

**第 1 节**

1. 【考纲 1】输入设备的功能是把数据、命令、字符、图形、图像、声音或电流电压等信息，以计算机可以接收和识别的二进制代码形式输入到计算机中。
2. 【考纲 1】输出设备的功能是把计算机处理的结果变成人最终可以识别的数字、文字、图形、图像或声音等信息，然后播放、打印或显示输出。
3. 【考纲 1】键盘采用“按列扫描、接地检查”方式工作：单片机每隔 3 到 5 ms 对各列顺序扫描，被扫描列接 0 电平，若该列有键按下则相应行输出变低电平，由列号与行号得到扫描码。
4. 【考纲 1】键盘发出的串行数据由 1 位起始位、8 位数据位、1 位奇偶校验位和 1 位停止位组成；主机收下后去掉附加位、串并转换后向 CPU 发键盘中断请求。
5. 【考纲 1】鼠标器是相对定位设备，分机械式与光电式两类；分辨率用 dpi 表示，指每移动一英寸光标在屏幕上移动的像素数；光电式的另一指标是帧速率。
6. 【考纲 1】打印机分击打式、激光和喷墨三种；打印控制器由数据锁存器、命令译码器、控制锁存器和状态锁存器四个基本部件组成。
7. 【考纲 1】显示器分 CRT 与 LCD 两种；水平扫描周期的倒数称行频，垂直扫描周期的倒数称帧频也称刷新频率；显示模式有字符模式和图形模式两种，颜色深度为 8 bit 时有 256 色、24 bit 时为真彩色。
8. 【考纲 1】输入输出设备工作原理的共同点：都要把一种形式的信息转换为计算机可处理或人可识别的另一种形式，都要经设备控制器与主机总线相连，速度与传输单位各不相同。

**第 2 节**

9. 【考纲 2】磁表面存储器中信息的存取由磁层和磁头完成：磁层是存放信息的介质，磁头是实现磁电和电磁转换的元件；一个磁化单元就是一个存储元，可存一位二进制信息。
10. 【考纲 2】磁表面存储器的四个性能指标：记录密度（用道密度和位密度表示）、存储容量、平均存取时间、数据传输速率。
11. 【考纲 2】磁盘的结构关系：每个盘片两个面各有一个磁头，磁头号就是盘面号；磁头和盘片相对运动形成的圆构成磁道，磁道号就是柱面号；每个磁道分成若干扇区，按扇区为单位读写。
12. 【考纲 2】低密度与高密度存储方式的差别：低密度方式所有磁道扇区数相同因而内道位密度高；高密度方式每个磁道位密度相同因而外道扇区数多，整个磁盘容量高得多。
13. 【考纲 2】磁盘读写的三种操作：寻道即磁头定位到指定磁道；旋转等待即等待要读写的扇区转到磁头下方；读写即按记录方式生成写电流脉冲或由读出放大电路读出内容。
14. 【考纲 2】硬盘的三个主要技术指标：未格式化容量、格式化后的实际容量、数据传输率与平均存取时间。
15. 【考纲 2】平均存取时间 $T$ 等于寻道时间加旋转等待时间加数据传输时间；平均寻道时间为 5 到 10 ms，平均等待时间取旋转一周时间的一半，约 4 到 6 ms；数据传输时间相对很短，故平均存取时间常近似等于前两者之和。
16. 【考纲 2】RAID 的三个特性：由一组物理磁盘驱动器组成且在操作系统下被视为单个逻辑驱动器；数据分布在一组物理磁盘上可连续或交叉分布；冗余磁盘用于存储校验信息以便磁盘损坏时恢复数据。
17. 【考纲 2】RAID 各级的关键差别：RAID 0 无冗余只讲容量与速度；RAID 1 用镜像盘一对一冗余、可靠性高但价格贵；RAID 2 用海明校验、校验盘与数据盘成正比因而开销太大已不再使用；RAID 3 用奇偶校验单个冗余盘加小条带交叉；RAID 4 用单个校验盘加大数据块交叉但校验盘成为 I/O 瓶颈；RAID 5 把奇偶校验块分布到各盘、成本不高效率高因而广泛使用；RAID 6 用双维块奇偶校验、可靠性最高但写入慢；RAID 7 是带 cache 的磁盘阵列。
18. 【考纲 2】SSD 的组织与特性：用 NAND 闪存组成，含闪存芯片与闪存翻译层，前者相当于硬盘驱动器、后者相当于磁盘控制器；因写入要先整块擦除，故读性能好于写性能，顺序读比顺序写约快一倍、随机读比随机写约快十倍；随机读写延时比硬盘低两个数量级。

**第 3 节**

19. 【考纲 3】部件之间互连的两种方式：各部件通过单独连线互连称分散连接；多个部件连接到一组公共信息传输线上称总线连接，后者灵活且成本低，但可能产生通信瓶颈。
20. 【考纲 3】系统总线由一组控制线、一组数据线和一组地址线构成；数据线承载数据指令或地址，地址线给出源数据或目的数据所在的主存单元或 I/O 端口地址且是单向的，控制线传输定时信号和命令信息。
21. 【考纲 3】同步总线的两个缺点：总线定时以最慢设备所用时间为标准，故只适合存取时间相差不大的部件之间通信；存在时钟偏移问题，导致同步总线不能过长。
22. 【考纲 3】总线的七项性能指标：总线宽度、总线的工作频率、总线的带宽、总线的寻址能力、总线的定时方式、总线的突发传送、总线的负载能力。
23. 【考纲 3】总线带宽的计算：$B=W\times F\div N$，其中 W 为总线宽度通常以字节为单位，F 为总线时钟频率，N 为完成一次数据传送所用的时钟周期数。
24. 【考纲 3】总线定时方式的三种：同步通信由时钟信号同步；异步通信指前一个信号的结束就是下一个信号的开始、信息改变是顺序的；半同步通信是两者的结合。
25. 【考纲 3】突发传送的原理：传送开始时先给出数据块在存储器中的首地址，然后连续传送数据块，后续数据的地址默认为前面数据的地址加 1，因而不必在地址线上传送后续地址，传输率高于正常传送方式。
26. 【考纲 3】总线的寻址能力由地址线位数确定，例如地址线 16 位且不分时多次传送地址时最多可访问 $2^{16}$ 个存储单元。
27. 【考纲 3】处理器总线即前端总线 FSB，是主板上最快的总线，主要用作处理器与北桥芯片的信息交换；存储器总线用于连接主存；I/O 总线为各种 I/O 设备提供输入输出通路。
28. 【考纲 3】PCI-Express 的带宽算法：1.0 规范支持每个方向 2.5 Gb/s，总带宽为 $2.5\ \mathrm{Gb/s}\times2\times$ 通路数 $\div10$，故 ×1 为 0.5 GB/s、×16 为 8 GB/s；数据字节被转换成 10 位传输以保证位流有足够跳变供接收端恢复时钟。

**第 4 节**

29. 【考纲 4】I/O 接口的四个别名：设备控制器、I/O 控制器、I/O 控制接口、I/O 模块；设备控制器通常独立于 I/O 设备，可集成在主板上或以插卡形式插在扩展槽上。
30. 【考纲 4】内部接口与外部接口：主机侧称内部接口，通过 I/O 总线和内存、CPU 相连；外设侧称外部接口，通过 I/O 接口电缆连到外设。
31. 【考纲 4】I/O 接口的四项职能：数据缓冲，用数据缓冲寄存器匹配主机与外设速度；错误或状态检测，用状态寄存器保存状态信息供 CPU 查用；控制和定时，接受系统总线来的控制命令和定时信号；数据格式转换，提供串并转换等部件。
32. 【考纲 4】I/O 接口中的三类端口与寄存器：数据缓冲寄存器即数据端口；状态寄存器即状态端口；控制寄存器即控制端口或命令端口；状态寄存器与控制在传送方向上相反、访问时间错开，故有的接口把两者合二为一。
33. 【考纲 4】独立编址方式的原理：对所有 I/O 端口单独编号形成独立的 I/O 地址空间，指令系统中需专门的 I/O 指令，I/O 指令的地址码部分给出端口号；因两个地址空间独立，无法从地址码形式上区分，必须靠专门指令表明访问 I/O 空间；Intel 处理器采用此方式，其 I/O 地址空间由 $2^{16}$ 即 64 K 个地址编号组成。
34. 【考纲 4】统一编址方式的原理：把主存地址空间分出一部分给 I/O 端口编号，端口和主存单元在同一地址空间的不同地址段中，根据地址范围即可区分；无需专门的 I/O 指令，用一般访存指令即可存取端口，因此也称存储器映射方式。
35. 【考纲 4】I/O 指令的性质：通过 I/O 指令访问数据缓冲寄存器、控制寄存器、状态寄存器；这些指令只能在操作系统内核的底层 I/O 软件中使用，因而是一种特权指令；IA-32 提供 IN、INS、OUT、OUTS 四条专门指令。

**第 5 节**

36. 【考纲 5】I/O 数据传送的三种控制方式：程序直接控制、中断控制和 DMA 控制。
37. 【考纲 5】程序直接控制的两种类型：无条件传送也称同步传送，通过程序定时来同步传送数据，无需检测接口或设备状态，适合简单外设与巡回采样检测；条件传送也称异步传送或程序查询，通过查询接口中的就绪、忙、完成等状态来控制数据传送。
38. 【考纲 5】查询的两种方式：定时查询指周期性查询接口状态，每次查询一直等到条件满足才传送一个数据；独占查询指设备被启动后 CPU 一直持续查询、完全控制 I/O 整个过程，此时外设和 CPU 完全串行工作。
39. 【考纲 5】程序查询方式的特点：简单、易控制、外围接口控制逻辑少；但 CPU 需从接口读状态并在外设未就绪时一直忙等待，浪费大量处理器时间。
40. 【考纲 5】中断 I/O 的基本思想：当前进程启动外设后即被挂起进入等待队列，CPU 调度其他进程执行，外设与 CPU 并行工作；外设完成指定操作后向 CPU 发中断请求，CPU 暂停当前进程转入中断服务程序，在其中启动后续数据的 I/O。
41. 【考纲 5】中断与异常的两个重要不同点：中断相对于指令执行是异步的、不与任何指令相关联也不阻止任何指令完成，故 CPU 只需在新指令的指令周期开始前检测；异常由 CPU 自身发现识别，而中断必须通过采样外部中断请求线并从总线取得中断源标识信息才能获知。
42. 【考纲 5】中断系统的五项基本职能：及时记录各种中断请求信号；自动响应中断请求；自动判优；保护被中断程序的断点和现场；中断屏蔽。
43. 【考纲 5】中断屏蔽的实现与作用：通过中断屏蔽字寄存器实现，屏蔽字中每一位对应一个外设或中断源；用 1 表示允许中断、0 表示屏蔽中断；CPU 执行指令修改屏蔽字内容即可动态改变中断处理的先后次序。
44. 【考纲 5】中断响应优先级与中断处理优先级的区别：前者由查询程序或中断判优电路决定，反映多个中断同时请求时谁先被响应；后者由各自的中断屏蔽字动态设定，反映本中断与其他所有中断之间的处理优先关系。
45. 【考纲 5】中断响应的三个条件：CPU 处于开中断状态；至少要有一个未被屏蔽的中断请求；当前指令刚执行完。
46. 【考纲 5】中断响应周期中隐指令完成的三个操作：关中断，把中断允许标志置为禁止状态以屏蔽所有可屏蔽中断请求；保护断点，把 PC 和 PSW 送入栈或特殊寄存器；识别中断源并转中断服务程序，取得优先级最高的中断源对应的服务程序首地址和初始 PSW 并分别送 PC 与 PSWR。
47. 【考纲 5】中断源识别的两类方法：软件查询法硬件结构简单、可通过改变查询顺序改变响应优先级因而灵活，但速度慢可能无法实时响应；硬件判优法即向量中断方法，由中断判优电路和编码器得到最高优先级中断源的类型号。
48. 【考纲 5】中断服务程序的三个阶段：准备阶段、处理阶段和恢复阶段；在保存断点、保护现场和旧屏蔽字、设置新屏蔽字的过程中 CPU 一直处于关中断状态。
49. 【考纲 5】现场信息与断点信息的保存主体不同：现场信息是用户可见的通用寄存器内容，由中断服务程序通过指令保存到栈中即软件实现；断点信息是 PC 与 PSWR 的内容，由处理器在中断响应开始时自动保存到特定地方即硬件实现。
50. 【考纲 5】DMA 方式的特点：用专门的 DMA 接口硬件控制外设与主存间的直接数据交换，数据不通过 CPU；传送时 CPU 让出总线控制权，由 DMA 控制器通过窃取一个主存周期或独占若干主存周期完成交换；主要用于磁盘等高速设备的成批数据交换。
51. 【考纲 5】DMA 的三种传送方式：CPU 停止法，DMA 控制器发停止信号使 CPU 脱离总线直到传完一块；周期挪用法，CPU 让出一个总线事务周期由 DMA 挪用主存周期传送一个数据后立即释放总线；交替分时访问法，每个存储周期分两个时间片分别给 CPU 和 DMA。
52. 【考纲 5】DMA 操作的三个步骤：预置即初始化，准备内存区、设置传送参数并发送启动命令后调度其他进程；数据传送，完全由 DMA 控制器完成，每传一个数据字计数器减 1 并修改地址；结束处理，字计数器为 0 时发 DMA 结束中断请求，转入中断服务程序做数据校验等后处理。
53. 【考纲 5】DMA 与中断方式的根本区别：中断方式请求的是处理器的时间，DMA 方式请求的是总线控制权；DMA 方式下 CPU 只在最初的初始化和最后的结束中断时介入，整块数据传送过程都不需要 CPU 参与，因而 CPU 用于 I/O 的开销非常小。
54. 【考纲 5】DMA 方式与中断方式一样采用请求响应方式，实际传送过程中仍会用到程序查询与中断处理：寻道结束后要用中断通知 CPU，传送参数要用程序查询方式设置，传送结束要用中断做后处理。

### 简答答题模板

**I/O 接口的基本功能**

四项。一、数据缓冲：主存和 CPU 寄存器速度很快而外设速度较低，故在接口中设数据缓冲寄存器以匹配两者速度。二、错误或状态检测：接口中提供状态寄存器保存设备是否完成、是否已准备好数据、是否缺纸等状态信息，供 CPU 查用；出错分设备电路故障与数据传输错两类，后者靠校验码检测。三、控制和定时：接受系统总线来的控制命令和定时信号，提供控制和定时逻辑，按命令字译码结果控制接口与设备之间的通信过程。四、数据格式转换：提供串并转换等部件，使外部接口得到的数据转换为内部接口需要的格式或反向转换。

**I/O 端口的两种编址方式**

独立编址：对所有 I/O 端口单独编号，形成独立的 I/O 地址空间；指令系统中需专门的 I/O 指令，I/O 指令的地址码部分给出端口号；因两个地址空间独立，无法从地址码形式上区分，必须靠专门指令表明访问的是 I/O 空间；CPU 执行 I/O 指令时产生 I/O 读或 I/O 写总线事务。统一编址：把主存地址空间分出一部分给 I/O 端口编号，端口与主存单元位于同一地址空间的不同地址段，按地址范围即可区分；无需专门 I/O 指令，用一般访存指令即可存取端口，因此也称存储器映射方式。

**中断响应周期的三个操作步骤**

中断响应周期中由硬件执行一条隐指令完成三件事。一、关中断：把中断允许标志置为禁止状态，屏蔽掉所有可屏蔽的中断请求，避免保存过程中被新中断破坏。二、保护断点：把 PC 与 PSW 送入栈或特殊寄存器，断点取哪一条指令由异常或中断类型决定。三、识别中断源并转中断服务程序：通过软件查询或硬件判优得到优先级最高的中断源所对应的服务程序首地址和初始 PSW，分别送 PC 与 PSWR，下个时钟周期即可转入服务程序。

**三种 I/O 控制方式的比较**

程序直接控制由 CPU 执行查询程序反复读接口状态，外设未就绪时 CPU 忙等待，接口简单但浪费处理器时间，适合低速或成批间隙长的字符设备。中断控制由外设完成后发中断请求，等待期间 CPU 可执行其他进程，开销只在响应与处理中断时发生，但高速设备请求频繁时额外开销变大。DMA 由 DMA 控制器控制总线在主存与设备间直接传送，CPU 只在初始化和结束中断时介入，开销极小，适合磁盘这类高速成批传送设备。

**DMA 方式的三个步骤**

第一步预置即初始化：准备内存区，执行 I/O 指令测试外设状态并设置传送参数，把内存首址送地址寄存器、字计数值送字计数器、读写命令送控制寄存器、设备地址送设备地址寄存器，然后发启动 DMA 传送命令并调度 CPU 执行其他进程。第二步数据传送：完全由 DMA 控制器完成，把内存地址送总线并在读写控制线上发命令，每传一个数据字计数器减 1 并修改地址寄存器，字计数器为 0 时结束。第三步结束处理：发出 DMA 结束中断请求，CPU 转入中断服务程序做数据校验等后处理。

## 1 输入与输出设备 {#s1}

**必背：** 输入设备把外界信息转成计算机可处理的二进制代码，输出设备把处理结果转成人可识别的形式；键盘按列扫描接地检查得到扫描码；显示器行频帧频互为扫描周期的倒数。

输入设备产生系统可接收的信息，输出设备把处理结果呈现或交付给外部。键盘、显示器、传感器和网络接口的速率、传输单位与实时要求不同。

设备不一定直接连接处理器内部数据通路，通常经接口、控制器和互连协作。设备自身速度与主机接口标称带宽也不能直接等同。

键盘的扫描过程是每隔 3 到 5 ms 顺序把各列接 0 电平，被按下的键所在行输出变低电平，由列号与行号合成扫描码，再由单片机串行发出，主机收到后串并转换并向 CPU 发中断。打印机靠打印控制器与主机相连，控制器里数据锁存器暂存打印数据、命令译码器解释命令、控制锁存器存控制命令、状态锁存器存忙与缺纸等状态。显示器在字符模式下显存存字符编码与属性、字形在字符发生器中；图形模式下点阵信息直接存显存。

## 2 外部存储器 {#s2}

**必背：** 磁盘读写分寻道、旋转等待与读写三种操作，平均存取时间等于三者之和；RAID 用冗余换可靠性，RAID 0 无冗余、RAID 1 镜像、RAID 5 分布校验；SSD 用闪存，读快于写。

机械磁盘访问包含寻道、旋转及传输，SSD 由非易失存储与控制器组织，光盘等介质又有不同读写机制。容量、持续带宽、随机延迟、耐久性与可恢复性是不同指标。

机械模型：7200 rpm 每转约 8.333 ms，随机相位的平均旋转等待约 4.167 ms；给定寻道与传输时间后才能算访问总量。SSD 不包含机械旋转，不能把转速公式移植过去。

磁盘的地址由柱面号、磁头号、扇区号三者给出，磁头号就是盘面号，磁道号就是柱面号。温盘每个扇区由头空、ID 域、间隙、数据域和尾空组成，数据域中真正的数据为 512 B。硬盘与主机之间是高速外设接口，硬盘控制器与主机采用成批数据交换方式，经 DMA 把数据传送到主存储器。RAID 的级别不是简单的层次关系，而是具有三个共同特性的不同设计结构。

## 3 互连与总线 {#s3}

**必背：** 系统总线由地址线、数据线、控制线三组构成；带宽 $B=W\times F\div N$；同步总线靠公共时钟定时但有最慢设备与时钟偏移两个限制，异步握手以请求应答协调。

地址、数据和控制是总线模型中的三类信息。同步总线按共同节拍约定采样，异步握手以请求与应答协调；仲裁决定多个主控者争用时谁先使用共享资源。串行点到点链路与传统共享并行总线的拓扑不同。

模型：32 位数据宽、每周期一次数据传输、频率 50 MHz，理想数据带宽为 200 MB/s；若一次完整事务占 4 周期且只交付一个数据字，事务层有效值为 50 MB/s。

![原创示意：四周期事务与有效数据交付](figures/bus-transaction.svg)

总线连接的两个优点是灵活与成本低，缺点是有可能产生通信瓶颈。同步总线的定时以最慢设备为准，且时钟偏移使总线不能过长，因此现代高速互连越来越多采用异步串行方式，例如 PCI-Express 在每条通路上用差分信号成对收发，并把每个数据字节转换成 10 位传输以便接收端用锁相环从跳变中恢复时钟。

## 4 I/O 接口与寻址 {#s4}

**必背：** 接口四项职能是数据缓冲、错误或状态检测、控制和定时、数据格式转换；I/O 端口有独立编址与统一编址两种，后者也称存储器映射方式，用访存指令即可访问端口。

接口寄存器常承担数据、状态和控制职责。统一编址把设备寄存器映射到内存地址空间，独立编址使用专用 I/O 空间及相应指令；实际访问仍应遵守设备副作用与顺序规则，不能把设备地址当普通可缓存 RAM 随意读写。

一次典型交互先检查或等待就绪，再按方向搬运数据，最后确认完成或错误。读状态是否清除某些位、写控制是否启动操作，都要由接口协议定义。

接口在主机侧叫内部接口、在外设侧叫外部接口，两侧的分工决定了整条通路是“CPU 和内存—I/O 总线—I/O 接口—接口电缆—外设”。独立编址下地址码形式无法区分两个空间，必须靠专门 I/O 指令；统一编址下靠地址范围区分，因此不需要专用指令。I/O 指令属于特权指令，只能在内核的底层 I/O 软件中使用。

## 5 控制方式与开销 {#s5}

**必背：** 三种控制方式是程序直接控制、中断控制、DMA 控制；中断响应三条件是开中断、有未屏蔽请求、当前指令执行完；DMA 请求总线控制权而中断请求处理器时间。

查询方式由 CPU 反复检测状态，中断方式在事件到来时转入服务，DMA 把批量搬运交给设备侧或专门引擎。中断优先级、屏蔽与嵌套策略影响响应顺序，响应中断不等于一定切换进程。

| 比较项 | 程序查询 | 中断控制 | DMA |
| --- | --- | --- | --- |
| 就绪通知 | CPU 反复读状态 | 事件引发中断 | 控制器按传送协议工作 |
| 常规模型中的数据搬运者 | CPU | CPU | DMA 控制器或设备 DMA 引擎 |
| CPU 的准备工作 | 设置命令和缓冲 | 设置命令、缓冲和中断 | 设置地址、长度、方向与描述符 |
| 等待期间 CPU | 查询占用执行机会 | 可执行其他任务 | 可执行其他任务 |
| 完成处理 | 查询发现完成 | 中断服务处理 | 常以完成中断通知 |
| 共享资源影响 | 指令与访存开销 | 服务程序和切换开销 | 总线或内存竞争及一致性维护 |

DMA 周期挪用使共享传输资源的部分周期交给 DMA，不保证 CPU 完全不停顿，也不要求整个传送阶段都停机。现代架构下的 DMA 还要处理设备可见地址、IOMMU 和 Cache 一致性；设备能访问物理资源，不表示可以无约束地绕过隔离。

开销模型：设备速率 10000 字/s，按每字一次中断、每次服务 5 μs 计，CPU 服务时间占比为 5%。若每 20 字一次 DMA 完成中断、每次 8 μs，则中断服务占比为 0.4%，但尚未计初始化、映射、同步与内存争用。

多重中断靠中断屏蔽字实现，屏蔽字决定本中断能被哪些中断打断。中断服务程序在准备与恢复阶段必须关中断，否则断点与现场可能被新中断破坏；进入处理阶段后再开中断，才能允许更高优先级的中断嵌套。

## 本章小结

- 接口选型既看峰值带宽，也看粒度、响应期限和完成开销。设备寄存器即便统一编址，也可能有副作用及顺序约束。
- 总线节拍上限由每次字节数与传输频率决定，事务交付率还要扣除地址、等待和其他规定周期；两种口径必须分开。
- 查询、中断与 DMA 的 CPU 负担应按题设计量。完成中断占比下降不证明初始化、同步及所有系统成本都已消失。

## 练习

**1. 为传感器与离线备份盘设计接口，为什么不能只比较最高带宽？机械盘的平均半转等待又有哪些假设？**

考点：第 1、2 节；层次：领会。

**答案：** 还要比较响应期限、数据粒度、随机延迟和可靠性。平均半转采用随机且均匀的到达相位等模型，不能描述 SSD，也不等于每次机械访问恰好等半转。

**2. 32 位、50 MHz 总线每事务用 4 周期传一个字，理想节拍带宽与该事务有效带宽各是多少？**

考点：第 3 节；层次：简单应用。

**答案：** 每字 32÷8=4 B，时钟周期 1/(50×10⁶)=20 ns；每周期一字的节拍上限为 4×50×10⁶=200 MB/s。每事务占 4×20=80 ns，只交付 4 B，故事务有效带宽为 4/(80×10⁻⁹)=50 MB/s。前提未包含其他仲裁和等待。

**3. 某设备把状态寄存器放在普通地址空间中，是否可以把读取它当作没有副作用、可任意重排的普通变量访问？**

考点：第 4 节；层次：领会。

**答案：** 不可以。统一编址只说明地址组织，设备访问仍需遵守缓存属性、顺序和副作用协议，例如读取清除状态位。

**4. 10000 字/s 的设备每字中断服务 5 μs，求服务占比；改为每 20 字一次、服务 8 μs 的 DMA 完成中断后，该占比是多少？是否等于全部 CPU 成本？**

考点：第 5 节；层次：简单应用、领会。

**答案：** 原占比 10000×5 μs=0.05，即 5%；新占比 500×8 μs=0.004，即 0.4%。这只计指定中断服务，还需考虑初始化、同步等开销。
