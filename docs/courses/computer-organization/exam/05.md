## 必背名词

| 术语 | 必背一句话 | 常考 |
| --- | --- | --- |
| 随机存取存储器 | 按地址访问存储单元且每个地址译码时间相同的存储器，半导体存储器属于此类 | 单选 |
| 顺序存取存储器 | 信息按顺序存放和读出、存取时间取决于信息存放位置的存储器，如磁带 | 单选 |
| 直接存取存储器 | 存取方式兼有随机访问和顺序访问特点的存储器，可直接选取所需信息所在区域再按顺序存取，如磁盘 | 单选 |
| 相联存储器 | 按内容检索到存储位置进行读写的存储器，也称按内容访问存储器，快表就是一种 | 单选 |
| 易失性存储器 | 电源关闭时信息自动丢失的存储器，如 RAM 和 cache | 单选 |
| 非易失性存储器 | 信息可一直保留、不需电源维持的存储器，如 ROM、磁表面存储器、光存储器 | 单选 |
| 存储元 | 具有两种稳态、能表示二进制 0 和 1 的物理器件，也称记忆单元或位元 | 填空 |
| 编址单位 | 具有相同地址的那些位元构成的一个单位，可以是一个字节或一个字 | 填空 |
| 存取时间 | 从存储器接到读命令开始至信息被送到数据线上所需的时间 | 填空 |
| 存储周期 | 存储器进行一次读写操作所需要的全部时间，即连续读写所允许的最短间隔时间 | 填空、计算 |
| 存储器带宽 | 存储器被连续访问时可提供的数据传送速率，通常用每秒传送的位数或字节数衡量 | 计算 |
| SRAM | 静态随机存取存储器，用六管触发器存储一位，无需刷新、速度快、集成度低，用作 cache | 单选 |
| DRAM | 动态随机存取存储器，用单管栅极电容存储一位，需刷新且读后要再生，集成度高，用作主存 | 单选 |
| 刷新 | 定时给 DRAM 存储元的栅极电容充电以防止信息丢失的过程 | 填空 |
| 位扩展 | 用多片位数较少的芯片构成给定存储字长的内存条，位数增加而字数不变 | 填空 |
| 字扩展 | 容量的扩充，位数不变而字数增加 | 填空 |
| 连续编址 | 主存地址高位表示模块号、低位表示模块内地址的多模块编址方式，也称按高位地址划分模块 | 填空 |
| 交叉编址 | 主存地址低位表示模块号、高位表示模块内地址的多模块编址方式，也称按低位地址划分模块 | 填空 |
| Flash 存储器 | 高密度非易失性读写存储器，兼有 RAM 和 ROM 的优点，功耗低、集成度高、不需后备电源 | 单选 |
| 时间局部性 | 被访问的某个存储单元在一个较短时间间隔内很可能又被访问 | 单选、简答 |
| 空间局部性 | 被访问的某个存储单元的邻近单元在一个较短时间间隔内很可能也被访问 | 单选、简答 |
| 主存块 | 主存中被划分出的等长区域，是 cache 和主存之间的信息交换单位，也称块 | 填空 |
| cache 行 | cache 中存放一个主存块的区域，也称槽 | 填空 |
| 有效位 | 说明 cache 行中的信息是否有效的标志位 | 填空 |
| 命中率 | 命中次数与访问总次数之比 | 计算 |
| 缺失率 | 不命中次数与访问总次数之比 | 计算 |
| 命中时间 | 命中时在 cache 中直接存取信息所用的时间开销 | 填空 |
| 缺失损失 | 从主存读入一个主存块到 cache 的时间 | 填空 |
| 直接映射 | 每个主存块映射到 cache 固定行中的映射方式，也称模映射 | 填空、计算 |
| 全相联映射 | 每个主存块可装入 cache 任意一行中的映射方式 | 填空 |
| 组相联映射 | 每个主存块映射到 cache 固定组中任意一行的映射方式，采用组间模映射、组内全映射 | 填空、计算 |
| 标记 | cache 行中反映当前行存放的是哪个主存块的信息 | 填空 |
| 全写法 | 写命中时同时写 cache 和主存的写策略，写不命中分写分配与非写分配两种处理 | 简答 |
| 回写法 | 写命中时只写 cache 不写主存、替换时才一次性写回主存的写策略 | 简答 |
| 修改位 | 说明对应 cache 行中的主存块是否被修改过、替换时是否需要写回的标志，也称脏位 | 填空 |
| 虚拟地址空间 | 虚拟存储器机制为程序员提供的极大的逻辑地址空间 | 填空 |
| 页表 | 为说明每个虚拟页的存放位置、存取权限、使用情况、修改情况而在主存中生成的表 | 简答 |
| 快表 | 后备转换缓冲器，把最活跃的几个页表项复制到高速缓存中组成的页表，简称 TLB | 简答 |
| 缺页 | 要访问的页面不在主存中的情况 | 填空 |
| 段页式 | 程序按模块分段、段内再分页、用段表和页表两级定位的虚拟存储器类型 | 填空 |

## 必背清单

**第 1 节**

1. 【考纲 1】存储器的四种分类方式：按存储元件分为半导体、磁表面、光介质存储器；按存取方式分为随机、顺序、直接和相联存储器；按信息可更改性分为读写存储器和只读存储器；按断电后信息可保存性分为易失性和非易失性存储器。
2. 【考纲 1】按存取方式分类的四类定义：随机存取存储器每个地址译码时间相同、访问时间与地址无关；顺序存取存储器信息按顺序存放和读出、存取时间取决于存放位置；直接存取存储器兼有随机与顺序访问特点；相联存储器按内容检索存储位置进行读写。
3. 【考纲 1】主存储器的组成：由记忆单元构成的存储阵列是核心，此外还有地址译码器、驱动器、I/O 控制电路和读/写控制信号；数据线宽度与 MDR 宽度相同，地址线宽度与 MAR 宽度相同。
4. 【考纲 1】地址线位数决定主存地址空间的最大可寻址范围，例如 36 位地址的最大寻址范围为 $0\sim2^{36}-1$。
5. 【考纲 1】三个主要性能指标：容量、速度和价格；速度可用存取时间、存储周期或带宽表示；每位价格 $c=C/S$，C 为总价、S 为按位计算的容量。
6. 【考纲 1】存取时间与存储周期的关系：存取时间分读出时间 $T_{A}$ 与写入时间 $T_{W}$；存储周期 $T_{M}$ 等于存取时间加下一次存取开始前所需的附加时间，故 $T_{M}>T_{A}$ 且 $T_{M}>T_{W}$。
7. 【考纲 1】层次化结构的构成原则：速度越快则容量越小、越靠近 CPU；数据一般只在相邻两层之间复制传送，且总是从慢速存储器复制到快速存储器；传送单位是一个定长块，需确定块大小并建立块映射关系。

**第 2 节**

8. 【考纲 2】六管静态存储元件的结构：T1 和 T2 构成触发器，T5、T6 是负载管，T3、T4 是门控管；T2 导通时 T1 截止为存 1，反之存 0。
9. 【考纲 2】单管动态存储元件的结构与读出特点：利用 MOS 管栅极电容 $C_{s}$ 保存信息，读写时加选通脉冲使字选门控管导通；读出时电荷放电电位下降，是破坏性读出，读后应有再生操作。
10. 【考纲 2】刷新的原因：MOS 管栅极上存储的电荷会缓慢放电，超过一定时间就丢失信息，因此必须定时给栅极电容充电。
11. 【考纲 2】SRAM 与 DRAM 的对比四条：SRAM 用管多、占硅片面积大、功耗大、集成度低，但无需刷新也无需读后再生，读写速度快，适合做高速小容量存储器；DRAM 用管少、面积小、功耗小、集成度高，但必须定时刷新和读后再生，读写速度慢，适合做慢速大容量主存。
12. 【考纲 2】存储器芯片的五个组成部分：存储体（存储矩阵）、地址译码器、驱动器、I/O 控制电路、读/写控制信号。
13. 【考纲 2】二维双译码结构：地址译码器分 X 和 Y 两个方向，选中行和列交叉点上的单元只有一位，因此采用该结构的芯片称为位片式芯片。
14. 【考纲 2】SDRAM 的两个关键参数：突发长度 BL 指一次连续传送的数据个数；CAS 潜伏期 CL 指从收到读命令到开始传送数据的延迟时间，因只有读操作才有 CL 故也称读取潜伏期。
15. 【考纲 2】DDR SDRAM 的提速原理：利用芯片内部 I/O 缓冲的两位预取功能，并利用存储器总线上时钟的上升沿与下降沿各传送一次，实现一个时钟内传送两次数据。

**第 3 节**

16. 【考纲 3】三种扩展方式：位扩展是用若干片位数较少的芯片构成给定存储字长的内存条；字扩展是容量的扩充、位数不变；当容量和位数都不满足要求时需字和位同时扩展。
17. 【考纲 3】连续编址与交叉编址的区别：连续编址高位表示模块号、低位表示模块内地址，访问连续块时先在一个模块内访问完再转到下一个模块，不能提高存取速度；交叉编址低位表示模块号、高位表示模块内地址，访问连续数据时可同时并行读写多个模块，能提高访存速度。
18. 【考纲 3】交叉编址多模块存储器的两种启动方式：轮流启动适用于每个模块一次读写的位数等于总线数据线条数的情况，每隔 1/m 个存储周期启动一个体；同时启动适用于所有模块一次读写的总位数等于总线数据线条数的情况。
19. 【考纲 3】内存条插槽就是存储器总线；支持两条总线同时传输的为双通道插槽，还有三通道、四通道，传输带宽可分别提高到单通道的两倍、三倍和四倍。
20. 【考纲 3】DRAM 芯片内地址的划分：芯片内地址位数为 n，其中行地址位数为 $\log_{2}r$、列地址位数为 $\log_{2}c$，芯片地址引脚数为 $\log_{2}r$ 与 $\log_{2}c$ 中的较大者，数据引脚数为位平面数 b。

**第 4 节**

21. 【考纲 4】四类只读存储器：MROM 掩膜只读存储器内容由厂家写入、用户不能修改，可靠性高但灵活性差；PROM 出厂全为 0、用户可一次编程且写入不可逆；EPROM 可写入并擦除全部信息后重写；EEPROM 可用电擦除和重编程且可只删除个别字。
22. 【考纲 4】Flash 存储器的特点：高密度非易失性读写存储器，兼有 RAM 和 ROM 的优点，功耗低、集成度高、不需后备电源；沿用了 EPROM 的简单结构和浮栅热电子注入的编程方式，又兼备 EEPROM 的可擦除特点。
23. 【考纲 4】Flash 存储元的三种基本操作：编程即充电，在需要改写为 0 的存储元控制栅加正电压；擦除即放电，在所有存储元源极加正电压使浮空栅中电子被吸收，全部变成 1 状态；读取即在控制栅加正电压，按读出电路能否检测到电流区分 0 与 1。
24. 【考纲 4】Flash 写的过程是先全部擦除使全部变成 1 状态，再在需要的地方改写为 0；其读操作速度与半导体 RAM 相当，写数据速度则与硬磁盘相当。

**第 5 节**

25. 【考纲 5】时间局部性的定义：被访问的某个存储单元在一个较短时间间隔内很可能又被访问；空间局部性是被访问的某个存储单元的邻近单元在一个较短时间间隔内很可能也被访问。
26. 【考纲 5】程序访问局部性的成因：指令在主存按顺序存放、地址连续，循环程序段或子程序段通常被重复执行，故指令访问具有明显的局部化特性；数据在主存一般也连续存放，特别是数组元素常被按序重复访问。
27. 【考纲 5】cache 与主存交换信息的单位：主存中的区域称为块即主存块；cache 中存放一个主存块的区域称为 cache 行或槽；每个 cache 行需要一个有效位说明信息是否有效。
28. 【考纲 5】命中与缺失的判定与代价：访问单元所在的块在 cache 中为命中，命中时开销为 cache 访问时间 $T_{c}$；不在则为缺失，缺失时开销为主存访问时间与 cache 访问时间之和，其中从主存读入一个块到 cache 的时间 $T_{m}$ 称缺失损失。
29. 【考纲 5】cache 与主存层次的平均访问时间：$T_{a}=p\times T_{c}+(1-p)\times(T_{m}+T_{c})=T_{c}+(1-p)\times T_{m}$，其中 p 为命中率。
30. 【考纲 5】三种映射方式的定义：直接映射把主存的每一块映射到固定的一个 cache 行中；全相联映射允许一个主存块装入 cache 任意一行；组相联映射把 cache 所有行分成若干组，每个主存块被映射到固定组中的任意一行。
31. 【考纲 5】直接映射的行号公式：cache 行号等于主存块号对 cache 行数取模；主存地址分成标记、cache 行号（行索引）和块内地址三个字段，高 t 位为标记、中间 c 位为行号、低位为块内地址。
32. 【考纲 5】全相联映射的地址划分：主存地址中无需 cache 行索引，只有标记和块内地址两个字段；比较时要比较所有 cache 行的标记，因而实现困难、不适合容量较大的 cache。
33. 【考纲 5】组相联映射的组号公式：cache 组号等于主存块号对 cache 组数取模；主存地址分成标记、cache 组号和块内地址三个字段；$2^{s}$ 路组相联指每组有 $2^{s}$ 行，s 为 1 是 2 路、s 为 2 是 4 路。
34. 【考纲 5】组相联与另两种映射的关系：当 cache 的组数为 1 时变为全相联映射；当每组只有一个 cache 行时变为直接映射。
35. 【考纲 5】直接映射与全相联映射的优缺点：直接映射容易实现、命中时间短，但多个同余的主存块只能映射到同一行，访问集中在同余块时会引起频繁调进调出，命中率较低；全相联映射只要有空闲行就不会发生冲突、块冲突概率低，但比较开销大。
36. 【考纲 5】四种替换算法：先进先出 FIFO 总是淘汰最早装入的主存块，实现方便但不能正确反映访问局部性；最近最少用 LRU 总是淘汰近期最少使用的主存块，能较好反映局部性但实现较复杂，需 LRU 位；最不经常用 LFU 淘汰引用次数最少的块；随机替换与使用情况无关，性能稍逊但代价低。
37. 【考纲 5】两种写策略：全写法在写命中时同时写 cache 和主存，写不命中分写分配法与非写分配法；回写法在写命中时只写 cache，写不命中时分配一行并调入主存块后更新，只有该行被替换时才一次性写回主存，需设置修改位。
38. 【考纲 5】cache 一致性问题的来源：cache 中的内容是主存块副本，若 CPU 修改了 cache 内容而主存块没有更新，则从主存传送到 I/O 设备的内容无效；若 I/O 设备修改了主存块，则对应 cache 行中的内容无效。

**第 6 节**

39. 【考纲 6】程序与进程的区别：程序是代码和数据的集合、是静态概念，可作为目标模块存放在磁盘中；进程是程序的一次运行过程，具有动态含义，有自己的生命周期。
40. 【考纲 6】虚拟存储器给每个进程带来的三个好处：每个进程具有一致的虚拟地址空间从而简化存储管理；把主存看成磁盘存储器的缓存，使有限的主存空间得到有效利用；每个进程的虚拟地址空间是私有的，可以保护各自进程不被破坏。
41. 【考纲 6】进程页面的三个不相交集合：未分配页集合、缓存页集合和未缓存页集合；已调入主存而被缓存在 DRAM 中的页面称缓存页，未调入主存而存在磁盘上的称未缓存页。
42. 【考纲 6】页表项的六个字段：存放位置、装入位（也称有效位或存在位）、修改位、使用位即替换控制位、存取权限位、禁止缓存位。
43. 【考纲 6】虚拟存储器的三种类型：分页式、分段式和段页式；分页式把主存和虚拟地址空间都划分成大小相等的页面并按页交换信息，虚拟页简称 VP，物理页即页框简称 PF 或 PP。
44. 【考纲 6】分页式地址转换：虚拟地址分虚拟页号和页内偏移两个字段，物理地址分物理页号和页内偏移两个字段，两者的页内偏移相等；由页表基址寄存器找到页表首地址，以虚拟页号为索引查页表项，装入位为 1 则取出物理页号与页内地址拼接，为 0 则缺页。
45. 【考纲 6】快表的作用：把页表中最活跃的几个页表项复制到高速缓存中组成 TLB，地址转换时先查快表，命中则无需访问主存中的页表，是减少访存时间开销的有效方法。
46. 【考纲 6】三种缺失：TLB 缺失指要访问页面对应的页表项不在 TLB 中；cache 缺失指要访问的主存块不在 cache 中；缺页指要访问的页面不在主存中。
47. 【考纲 6】缺失组合中的不可能情形：页缺失说明信息不在主存，此时 TLB 中一定没有该页表项、cache 中也一定没有该信息，所以 TLB 命中而页缺失的组合不可能出现。
48. 【考纲 6】三种缺失的处理主体：cache 缺失处理由硬件完成；缺页处理由软件完成，操作系统通过缺页异常处理程序实现；TLB 缺失既可用硬件也可用软件处理。
49. 【考纲 6】分段式的三个异常与优缺点：缺段即装入位为 0、地址越界即偏移量超出最大段长、保护违例即操作方式与指定访问权限不符；优点是段的分界与程序自然分界相对应、逻辑独立便于管理和共享、某些段长度可变，缺点是段长不等造成主存分配麻烦且易留下零碎空间。
50. 【考纲 6】段页式的做法与代价：程序按模块分段、段内再分页，用段表和每段一个页表两级定位；兼有页式和段式的优点，但地址转换要先查段表再查页表因而需要多次查表。

## 必背数字与公式

| 项目 | 必背内容 |
| --- | --- |
| 地址线与容量 | 地址线 n 位则地址数 $=2^{n}$；按字节编址时容量 $=2^{n}$ B |
| 芯片片数 | 片数 $=$ 深度扩展倍数 $\times$ 位宽扩展倍数 |
| 存储周期 | $T_{M}>T_{A}$ 且 $T_{M}>T_{W}$；$T_{M}=$ 存取时间 $+$ 附加时间 |
| 每位价格 | $c=C\div S$，C 为总价、S 为按位容量 |
| 存储器带宽 | 每秒传送的位数或字节数；例如 200 MHz 乘 2 乘 64 位除 8 得 3.2 GB/s |
| DRAM 芯片引脚 | 地址引脚数为行地址位数与列地址位数中的较大者，数据引脚数为位平面数 |
| 交叉编址提速 | m 体交叉且轮流启动时，每隔 $1/m$ 个存储周期启动一个体，存取速度提高 m 倍 |
| 命中率与缺失率 | 命中率 $p=$ 命中次数 $\div$ 访问总次数；缺失率 $=1-p$ |
| 平均访问时间 | $T_{a}=p\times T_{c}+(1-p)\times(T_{m}+T_{c})=T_{c}+(1-p)\times T_{m}$ |
| 主存块数与块内地址 | 块内地址位数 $=\log_{2}$(块大小)；主存块数 $=$ 主存容量 $\div$ 块大小 |
| cache 行数 | 行数 $=$ cache 数据区容量 $\div$ 块大小 |
| 直接映射行号 | 行号 $=$ 主存块号 $\mathrm{mod}$ cache 行数；行号位数 $=\log_{2}$(行数) |
| 组相联组数与路数 | 组数 $=$ 行数 $\div$ 路数；$2^{s}$ 路组相联即每组 $2^{s}$ 行 |
| 组相联组号 | 组号 $=$ 主存块号 $\mathrm{mod}$ cache 组数；组号位数 $=\log_{2}$(组数) |
| 标记位数 | 标记位数 $=$ 主存地址位数 $-$ 组号或行号位数 $-$ 块内地址位数 |
| cache 总容量 | 行数 $\times$（每行数据位数 $+$ 标记位数 $+$ 1 位有效位 $+$ 可能的 1 位修改位） |
| 页内偏移 | 页内偏移位数 $=\log_{2}$(页面大小)；虚拟页号位数 $=$ 虚拟地址位数 $-$ 偏移位数 |
| 页表项数 | 页表项数 $=$ 虚拟地址空间大小 $\div$ 页面大小 |
| 例：直接映射 | 块 512 字、cache 数据区 8 K 字、主存 1 M 字，则 16 行、行号 4 位、块内 9 位、标记 7 位 |
| 例：组相联 | 8 K 字 cache 划成 8 组乘 2 行乘 512 字，则组号 3 位、标记 8 位、块内 9 位 |

## 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 随机存取与直接存取 | 随机存取的每个单元访问时间与地址无关；直接存取要先定位区域再按顺序存取 | 是否需要先找区域再顺序读 |
| 顺序存取与直接存取 | 顺序存取完全按顺序存放和读出，时间取决于位置；直接存取可直接选取所需区域 | 能否跳过前面的内容 |
| SRAM 与 DRAM | SRAM 用触发器、不刷新、速度快、集成度低；DRAM 用电容、需刷新和再生、集成度高 | 是否靠电荷保存、是否需刷新 |
| 破坏性读出与刷新 | 破坏性读出指读后原信息丢失需要再生；刷新是定时补充电荷，与读写无关 | 读操作后的动作还是定时动作 |
| 位扩展与字扩展 | 位扩展增加数据位数、字数不变；字扩展增加字数、位数不变 | 目标存储字的位数是否超过单片 |
| 连续编址与交叉编址 | 连续编址高位为模块号，不能并行访问多个模块；交叉编址低位为模块号，可并行读写多个模块 | 模块号取自地址高位还是低位 |
| 易失与非易失 | 易失存储器断电即丢信息，如 RAM 与 cache；非易失可长期保留，如 ROM 与磁盘 | 断电后信息是否保留 |
| 时间局部性与空间局部性 | 时间局部性指同一单元被重复访问；空间局部性指邻近单元被访问 | 重复的是地址本身还是相邻地址 |
| 命中率与命中时间 | 命中率是命中的比例；命中时间是命中时一次访问的时间开销 | 一个是比例一个是时间 |
| 直接映射与组相联 | 直接映射每块只有唯一候选行；组相联在固定组内可任选一行 | 候选行是否只有一个 |
| 全相联与组相联 | 全相联可装入任意行、要比较全部标记；组相联只在组内全相联、比较器少 | 候选范围是整个 cache 还是一个组 |
| 全写法与回写法 | 全写法写命中时同时写 cache 与主存；回写法只写 cache，替换时才写回 | 主存何时被更新 |
| 写分配与非写分配 | 写分配在写不命中时先分配一行并调入主存块；非写分配只更新主存不调入 | 写不命中时是否把块搬进 cache |
| FIFO 与 LRU | FIFO 淘汰最早装入的块；LRU 淘汰近期最少使用的块 | 按装入时间还是按使用情况 |
| 缓存页与未缓存页 | 缓存页是已调入主存并被 DRAM 缓存的页；未缓存页是未调入主存而存在磁盘上的页 | 页面当前是否在主存 |
| TLB 与 cache | TLB 缓存的是页表项即地址转换信息；cache 缓存的是数据块 | 存的是映射关系还是数据 |
| 分页式与分段式 | 分页按等长页面划分、对用户不可见；分段按程序逻辑结构划分、段长可变 | 划分单位是否等长 |

## 简答答题模板

**程序访问的局部性及其两种表现**

程序访问的局部性指在较短时间间隔内程序产生的地址往往集中在存储空间的一个很小范围。分两种：时间局部性指被访问的某个存储单元在一个较短时间间隔内很可能又被访问；空间局部性指被访问的某个存储单元的邻近单元在一个较短时间间隔内很可能也被访问。成因是指令按顺序连续存放且循环段被重复执行，数据也连续存放尤其数组元素被按序重复访问。

**cache 的三种映射方式**

直接映射把主存的每一块映射到固定的一个 cache 行中，行号等于主存块号对行数取模，地址分标记、行号、块内地址三段，实现简单但同余块会争同一行。全相联映射允许一个主存块装入 cache 任意一行，地址只有标记和块内地址两段，冲突概率低但要比较全部标记、实现困难。组相联映射把 cache 行分成若干组，主存块映射到固定组中的任意一行，组号等于主存块号对组数取模，地址分标记、组号、块内地址三段，兼顾两者优点；组数为 1 时退化为全相联，每组一行时退化为直接映射。

**cache 与主存层次的平均访问时间**

设命中率为 p，命中时开销为 cache 访问时间 $T_{c}$，缺失时需从主存读入一个主存块到 cache 并把所需信息送 CPU，开销为主存访问时间与 cache 访问时间之和，其中读入一个块的时间 $T_{m}$ 称为缺失损失。则平均访问时间 $T_{a}=p\times T_{c}+(1-p)\times(T_{m}+T_{c})=T_{c}+(1-p)\times T_{m}$。由于程序访问的局部性，命中率可接近 1，故平均访问时间仍接近 cache 访问时间。

**全写法与回写法的区别**

全写法在写命中时同时写 cache 和主存；写不命中时若采用写分配法，先在主存块中更新相应单元再分配一行并调入该块，若采用非写分配法只更新主存单元而不调入。回写法在写命中时只写 cache 不写主存；写不命中时在 cache 中分配一行，把主存块调入并更新相应单元，只有该行被替换时才把整块一次性写回主存，因此每行需一个修改位。回写法减少写主存次数、降低带宽需求，但 cache 与主存内容可能不一致。

**虚拟存储器的作用与三种类型**

作用有两个层面：解决主存容量受限制与程序不受物理内存大小制约之间的矛盾；让多个程序有效而安全地共享主存。它给每个进程一个极大且私有的虚拟地址空间，带来一致地址空间便于管理、把主存当成磁盘缓存、进程间互相保护三个好处。三种类型是分页式、分段式和段页式；分页式按等长页面划分并按页交换，分段式按程序逻辑结构划分且段长可变，段页式先分段再在段内分页，用段表和页表两级定位。
