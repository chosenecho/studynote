## 复习路径

<ol class="course-steps" markdown>

<li><strong>背</strong>：进章节先看应试导航，必背数字与公式那张表要能默写，再做默写自测。</li>
<li><strong>读</strong>：读概念讲解，每节首行的“必背”一句钩回考点，读完按本章小结复述。</li>
<li><strong>练</strong>：做章节练习，数值题写清位宽、编码与单位再展开答案。</li>

</ol>

容量单位：KiB、MiB 按 1024 进位；带宽按题设换算。地址默认从 0 编号，其他条件见各题。
