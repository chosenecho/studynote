### 必背清单

**第 1 节**

1. 【考纲 1】多媒体平台软件也称多媒体创作工具，能够集成处理和统一管理文本、图形、图像、音频、视频和动画等素材，按用户需要生成多媒体应用系统。
2. 【考纲 1】平台软件分两类：多媒体素材制作软件包括文本编辑与录入、图形图像编辑与处理、音频编辑与处理、视频编辑与处理、动画编辑软件；另一类是多媒体制作软件。
3. 【考纲 1】常见的多媒体制作软件有 PowerPoint、Animate、Authorware、Director、ToolBook 和方正奥思。
4. 【考纲 1】理想平台软件的四项功能：提供可视化、集成性的开发环境并做到所见即所得；提供媒体的导入导出功能；提供超文本、超媒体和多媒体数据管理功能；支持应用程序的动态链接。
5. 【考纲 1】超文本基于网络节点和连接数据库实现信息的非线性组织，节点可以包括正文、图形、图像、声音和其他媒体。
6. 【考纲 1】一般创作工具都提供超链接功能，链接把节点连成非线性结构，便于检索和查询，也可通过动态链接扩充作品功能。
7. 【考纲 1】PowerPoint 面向演示类作品、不需要编程；ToolBook 按书和页组织内容、可不按顺序跳页；Visual Basic 介于传统语言与平台工具之间、需要写代码；Dreamweaver 是集网页制作与网站管理于一身的网页编辑器。

**第 2 节**

8. 【考纲 2】以卡片或页面为基础的工具把作品看作一本书或一叠页面，页与页之间可以任意跳转，ToolBook 与 PowerPoint 属于这一类。
9. 【考纲 2】以图标为基础的工具提供可视化编程方法，用户按事件播放顺序把图标连成流程图，每个图标代表一步操作，Authorware 属于这一类。
10. 【考纲 2】以时间为基础的工具按时间轴安排素材出现的时刻。
11. 【考纲 2】以脚本语言为基础的工具以传统程序设计语言作为集成手段，Visual Basic 属于这一类，需要写代码。
12. 【考纲 2】“图标”有两层含义：图标制作软件编辑的是图标文件本身；以图标为基础的创作工具把图标当作流程中的事件节点，两者对象不同。

**第 3 节**

13. 【考纲 3】网络作品是基于浏览器/服务器模式开发、能在互联网或局域网中发布的作品，两层含义是在网上执行、通过浏览器执行。
14. 【考纲 3】共享性指一个网络作品可以同时供很多人使用；易用性指通过浏览器直接使用，方式简单统一。
15. 【考纲 3】交互性既包括人机交互，也包括人与人之间的交互，论坛、留言本、电子信箱、新闻组、博客都是常用手段。
16. 【考纲 3】开放性指设计几种情境模式，让不同用户按各自要求浏览；方便性指通过动态的后台管理增减内容、调用资源方便快捷。
17. 【考纲 3】网络型应用系统本质上就是一个网站：站点管理组织文件，网页文档承载页面内容，媒体与链接构成呈现和导航。

**第 4 节**

18. 【考纲 4】图标实际是一个尺寸很小的位图，编辑图标就是逐点编辑像素；Windows 系统中默认的图标尺寸为 $32\times32$ 像素点。
19. 【考纲 4】IconCool Editor 可同时编辑 10 个图标，提供 21 个图形滤镜和 13 个影像处理效果；图标可保存为 ICO、CUR、ICL、BMP、GIF、JPEG、PNG，也能从 EXE、DLL、ICL 中提取。
20. 【考纲 4】自启动方案先新建方案文档，可选空白模板或 34 个方案模板之一；用“方案→当前设置”设窗口标题、页面大小与图标，用“页面→属性”设页面名称与背景。
21. 【考纲 4】添加的声音文件要求是 .ogg 格式；按钮在“快速动作”中设置单击操作，完成后用“发布→预览”检查效果。
22. 【考纲 4】发布时选“发布→创建发布”，在向导的发布目标中选“ISO图像”生成 ISO 映像；ISO 是发布映像，生成映像与刻录到实体光盘是两个环节。
23. 【考纲 4】可刻录光盘有 CD-R（一次擦写）、CD-RW（多次擦写）以及 DVD-R、DVD-RW；刻录步骤是放入盘片、选“刻录数据光盘”、添加文件并核对容量、选刻录机并设名称速度与方法、开始刻录。
24. 【考纲 4】刻录注意事项：尽量不运行其他程序；关闭电源管理；开始刻录尽量先用慢速；刻录前先做模拟测试；不要连续刻录多张，以免温度过高损坏光驱。
25. 【考纲 4】制作流程：规划站点、创建本地站点（填入站点名称与本地站点文件夹）、管理站点、建立和保存网页、规划布局、插入媒体、使用超链接。
26. 【考纲 4】规划布局用可视化助理、标尺、网格和跟踪图像，页面排版主要用表格；插入动画用“插入→HTML→Flash SWF”，插入视频用“插入→HTML→Flash Video”。
27. 【考纲 4】FLV 分累进式下载视频和流视频两种类型，播放需要 Flash Player；页面上出现动画图标或组件不等于能播放。
28. 【考纲 4】超链接分四类：页间链接跳转到其他文档或文件；页内链接又称锚记链接，跳到本站点指定文档的位置；E-mail 链接启动邮件程序；空链接及脚本链接用于附加行为或执行 JavaScript。
29. 【考纲 4】绝对路径是包含服务器协议在内的完全路径，与源端点无关，便于跨站链接但不利于测试和站点移植；相对路径分根相对路径与文档相对路径两种。
30. 【考纲 4】根相对路径从站点根文件夹算起并以 / 开头；文档相对路径从当前文档所在的文件夹算起，页面移动后原路径会指向别处，要按新位置逐级重算。

### 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 平台软件与素材制作软件 | 平台软件组织并集成多种媒体生成应用系统；素材制作软件只处理单项媒体 | 处理的是单个素材还是整部作品 |
| 以页面为基础与以图标为基础 | 页面型按书和页组织、可跳页；图标型按事件顺序把图标连成流程图 | 组织单位是页还是流程中的图标 |
| 以时间为基础与以页面为基础 | 时间型按时间轴决定素材出现的先后；页面型按页的组织决定浏览顺序 | 先后顺序由时间轴还是页面结构决定 |
| 图标文件与流程图标 | 前者是 ICO 等图像文件；后者是以图标为基础的工具里代表一步操作的事件节点 | 说的是资源文件还是流程节点 |
| 绝对路径与相对路径 | 绝对路径含服务器协议、与源端点无关；相对路径按参照位置计算 | 路径里有没有协议与域名 |
| 根相对路径与文档相对路径 | 根相对路径从站点根文件夹算起、以 / 开头；文档相对路径从当前文档所在文件夹算起 | 参照的是站点根还是当前文档所在目录 |
| ISO 映像与实体刻录 | ISO 是发布向导生成的镜像文件，可先检查内容；写入盘片和读取播放要另行验证 | 产物是文件还是盘片 |
| SWF 与 FLV | SWF 是插入页面的 Animate 动画文件；FLV 是插入页面的视频文件，分累进式下载与流视频 | 插入的是动画还是视频 |
| 页间链接与页内链接 | 页间跳到别的文档或文件；页内即锚记链接，跳到本站点某文档的指定位置 | 跳转目标是另一个文件还是同一文档中的位置 |

### 简答答题模板

**多媒体平台软件的功能**

四条各一句：提供可视化、集成性的开发环境，鼠标单击、拖放即可完成素材集成与画面布局，编辑效果与运行效果基本一致即所见即所得；提供媒体的导入导出功能，能读写不同格式并与其他编辑软件交换素材；提供超文本、超媒体和多媒体数据管理功能，用节点和链接组织非线性结构；支持多媒体数据之间以及与外部应用程序之间的动态链接，借外部程序扩充功能。

**四类多媒体创作工具**

按组织方式分条：以卡片或页面为基础，把作品看作书或页面，ToolBook、PowerPoint 属此类；以图标为基础，按事件播放顺序把图标连成流程图，Authorware 属此类；以时间为基础，按时间轴安排素材出现的时刻；以脚本语言为基础，用程序设计语言写交互，Visual Basic 属此类。末句补判据：看它靠什么组织作品。

**网络型多媒体作品的优点**

五项各一句：共享性是一个作品可同时供很多人使用；易用性是通过浏览器直接使用、方式简单统一；交互性包括人机交互与人与人之间的交互；开放性是设计几种情境模式让不同用户按需浏览；方便性是通过动态后台管理增减内容。开头补定义：基于浏览器/服务器模式开发、能在互联网或局域网中发布。

**文档相对路径怎么写、移动后怎么重算**

先写规则：文档相对路径从当前文档所在的文件夹算起，用 ../ 逐级上退再进入目标位置。再举例：站点根下 pages/visit.html 引用根下 assets/sign.png，应写 ../assets/sign.png；页面移入 pages/archive/ 后，按新位置要写 ../../assets/sign.png。末句提醒：软件是否自动更新引用要另记实际观察，不能假定。

**自启动光盘的制作流程**

按步骤写：启动 AutoPlay Media Studio 新建方案文档，选空白模板或方案模板；用“方案→当前设置”设窗口标题、页面大小与图标；用“页面→属性”设页面名称与背景；需要声音时添加 .ogg 文件；添加按钮并设置单击动作；用“发布→预览”检查；再用“发布→创建发布”在向导中选“ISO图像”生成映像，最后检查映像内容。

**光盘刻录的注意事项**

五条：刻录时尽量不运行其他程序；关闭电源管理，避免长时间无响应导致失败；开始刻录尽量先用慢速观察是否稳定；刻录前先做模拟测试；不要连续刻录多张，以免温度过高导致出错甚至损坏光驱。末句补区分：ISO 生成、实际刻录与目标环境运行是三件不同的事。

## 1 多媒体平台软件 {#s1}

**必背：** 平台软件＝集成处理并统一管理素材、生成应用系统的编辑工具，分素材制作软件与制作软件两类；四项功能按原文背；超文本靠节点与链接实现非线性组织。

多媒体平台软件又叫多媒体创作工具。它把文本、图形、图像、音频、视频、动画等素材放在一处管理，再按用户的需要组织成一个多媒体应用系统。它分两类：多媒体素材制作软件处理单项媒体素材，例如文本、图形图像、音频、视频和动画的编辑软件；多媒体制作软件负责把素材组织、集成为多媒体应用系统。常见的多媒体制作软件有 PowerPoint、Animate、Authorware、Director、ToolBook 和方正奥思等。

理想的多媒体平台软件一般具备以下功能：

1. 提供可视化、集成性的开发环境。用鼠标单击、拖放就能完成素材集成和画面布局，编辑时的效果与运行时的效果基本一致，即“所见即所得”；同时具备选择、循环等流程控制，以及对媒体空间分布、呈现顺序和动态输入/输出的编排能力。
2. 提供媒体的导入、导出功能。能读写不同格式的媒体文件，并与其他媒体编辑软件交换素材。
3. 能组织超文本和超媒体，把多媒体数据管理起来；节点和链接把内容连成非线性结构，便于检索和查询。
4. 支持多媒体数据之间、以及多媒体数据与外部应用程序之间的动态链接，借助外部程序扩充作品功能。

常见平台软件各有侧重：PowerPoint 面向演示类作品，按演示页面组织，不需要编程；Animate 擅长矢量动画，发布得到文件较小、供播放器播放的 SWF；ToolBook 按书和页组织内容，允许不按顺序跳页；Visual Basic 介于传统语言与平台工具之间，需要写代码；Dreamweaver 用于网页制作与网站管理。

## 2 创作工具类型与易混概念 {#s2}

**必背：** 四类工具按“靠什么组织作品”判：页面组织对 ToolBook、事件控制对 Authorware、时间安排对时间轴、脚本逻辑对 Visual Basic；“图标”的两层含义要分开答。

多媒体创作工具按组织作品的方式，大致分为四类：以卡片或页面为基础的、以图标（事件驱动）为基础的、以时间为基础的，以及以脚本语言为基础的。判断一款工具属于哪一类，看它靠什么组织作品：页面组织把内容排成书或页，事件控制把图标按流程连起来，时间安排按时间轴定先后，脚本逻辑用程序语言写交互。

以页面为基础的工具把作品看作一本书或一叠页面，ToolBook 按书和页组织内容，页与页之间可以任意跳转；PowerPoint 也是以页面制作为基础的工具。以图标为基础的工具提供可视化的编程方法，用户按事件播放顺序把图标连成流程图，每个图标代表一步操作，Authorware 属于这一类。以时间为基础的工具按时间轴安排素材出现的时刻。脚本语言类工具以传统程序设计语言作为集成手段，Visual Basic 就属于此类，需要写代码。

“图标”有两层含义：图标制作软件（如 IconCool Editor）编辑图标文件本身；以图标为基础的创作工具把图标当作流程中的事件节点。两者对象不同。

## 3 网络型多媒体作品 {#s3}

**必背：** 网络作品基于浏览器/服务器模式，两层含义是在网上执行、通过浏览器执行；五个优点是共享性、易用性、交互性、开放性、方便性。

网络型作品采用浏览器/服务器模式，能在互联网或局域网里发布和访问。它的两层含义是：内容在网上执行，用户通过浏览器使用。跟传统作品比，这类作品体积小、便于网上传递、也便于多人共用；信息容量大，能装下多种格式的素材，体系开放，改、增、删内容都方便。

网络作品具有以下优点：

| 特点 | 含义 |
| --- | --- |
| 共享性 | 一个网络作品可以同时供很多人使用 |
| 易用性 | 通过浏览器直接使用，方式简单统一 |
| 交互性 | 人机交互与人与人的交流 |
| 开放性 | 设计几种情境模式，让不同用户按各自要求浏览 |
| 方便性 | 通过动态的后台管理增减内容、调用资源方便快捷 |

交互性既包括人机交互，也包括人与人之间的交流，论坛、留言本、电子信箱都是常用手段。

网络型应用系统本质上就是一个网站：站点管理负责组织文件，网页文档承载页面内容，媒体与链接构成呈现和导航。做网站常用的是 Adobe Dreamweaver。

## 4 公式、条件与步骤 {#s4}

**必背：** 四套流程各记产出物：图标存 ICO、方案发布出 ISO、光盘要写入盘片、站点要能逐页访问；文档相对路径从当前文档所在文件夹算起，移动后逐级重算。

本章没有计算公式，操作步骤按所用软件版本整理。

### 制作图标

常用的图标制作软件有 goodICON、IconCool Editor、Icon Workshop 等，以 IconCool Editor 为例。图标实际是一个尺寸很小的位图，编辑图标就是逐点编辑像素；Windows 里图标默认就是 32×32 像素点大小。界面左侧是工具箱，右侧是图标显示区，可同时显示 10 个图标，其下方能设置图标尺寸和颜色深度；中间是带坐标线的编辑区，右上角有 32×32 的预览窗口；编辑区下方是调色板。制作流程是：

- 新建图标或导入照片时，先选好大小和颜色。
- 用工具箱逐点绘制；也可把照片加工成正方形后导入，照片宜取人物或景物的局部，尺寸太大、细节太多的照片不适合做图标。
- 在编辑区修改，在预览窗口查看小尺寸下的效果，必要时改变颜色、方向或加上文字。
- 选择 File 菜单中的 Save As 保存，默认文件类型为 ICO。图标还可以保存成 CUR、ICL、BMP、GIF、JPEG、PNG 等格式，也能从 EXE、DLL、ICL 文件中提取图标。

### 自启动光盘制作

自启动光盘制作软件有 AutoPlay Media Studio、AutoPlay Menu Builder、EasyBoot 等，以 AutoPlay Media Studio 6.0 汉化版为例。操作流程是：启动后创建一个新的方案文档，选空白模板或 34 个方案模板之一；用“方案→当前设置”设置窗口标题、页面大小和自定义图标，用“页面→属性”设置页面名称和背景；需要自动播放声音时添加音频，文件须为 .ogg 格式；在页面中添加按钮，设置显示文字和“快速动作”里的单击操作；用“发布→预览”检查效果，再选“发布→创建发布”，在向导中选中“ISO图像”生成 ISO 映像；最后用 UltraISO 或虚拟光驱查看映像内容。ISO 是发布映像，生成映像和刻录到实体光盘是两个环节。

### 光盘类型、刻录流程与注意事项

刻录光盘是向 CD-R、CD-RW、DVD-R、DVD-RW 等可刻录式光盘写入数据的过程。CD-R 只能写一次，CD-RW 可以多次擦写，DVD-R 与 DVD-RW 同理。

常见的刻录软件有 WinOnCD、Direct CD、Easy CD Creator、Nero Burning ROM 等。以 Nero 9 制作数据光盘为例，步骤是：

1. 先启动刻录程序，把 CD-R、CD-RW 或 DVD-R 盘片放进刻录机，再选“刻录数据光盘”。
2. 在“数据光盘”窗口添加待刻录文件，注意数据量不要超过盘片容量。
3. 选择刻录机，设置光盘名称、写入速度和写入方法。
4. 开始刻录，等待完成提示。

刻录的注意事项有：刻录时尽量别同时开别的程序；关闭电源管理，避免计算机长时间停止响应导致刻盘失败；开始刻录时尽量先用慢速，观察过程是否稳定；刻录前最好先做模拟测试；不要连续刻录多张，以免温度过高导致刻录出错甚至损坏光驱。

### Dreamweaver 2020 网页工作流

Dreamweaver 2020 界面里，应用程序栏集中菜单命令，切换视图靠文档工具栏，左侧竖排的是工具栏，中间的大块是文档窗口，状态栏显示文档窗口尺寸；还有“属性”面板和面板组。制作网络型作品的流程是：

1. **查看界面并规划站点**：先规划网站需要哪些页面、功能和文件结构。
2. **创建站点**：用“站点→新建站点”的向导创建本地站点，填写站点名称和本地站点文件夹，服务器一项可以先不选；也可以在“高级设置”标签下逐项配置。
3. **管理站点**：用“窗口→文件”打开文件面板查看站点文件，用“站点→管理站点”管理已有站点；在文件面板里可以新建、重命名和删除文件夹与文件。
4. **建立和保存网页**：用“文件→新建”创建空白 HTML 文档，也可用模板创建；用“文件→打开”“文件→保存”读写文档。用“窗口→属性”打开页面属性，可设置标题、背景图像、背景颜色、文本与链接颜色、边距等。
5. **规划布局**：可视化助理辅助定位，标尺用于测量和规划，网格让绝对定位元素移动时自动靠齐，跟踪图像可以把现成网页的布局载入作草稿；页面排版主要用表格，表格可以插入、调整大小、增删行列、拆分合并并设置属性。
6. **插入媒体**：可输入、复制或导入文本，插入图像或图像占位符；插入 Animate 动画时用“插入→HTML→Flash SWF”插入 SWF 文件，用“插入→HTML→Flash Video”插入 FLV 视频，FLV 有累进式下载视频和流视频两种类型，播放需要 Flash Player。
7. **使用超链接**：在属性面板的“链接”框中填写地址，或用“插入→Hyperlink”菜单命令，或用“指向文件”图标拖到目标文件。

### 站点与页面操作检查卡

完成一步就核对一次对象和结果：

| 对象 | 操作前要明确 | 完成后要检查 |
| --- | --- | --- |
| 本地站点 | 根文件夹和内容、资源的目录安排 | 站点文件能在管理面板定位 |
| 站点管理 | 新建、移动或改名的是哪个文件 | 页面引用的图片与链接仍有效 |
| 网页文档 | 新建、打开、属性与保存位置 | 保存后能重新打开并继续编辑 |
| 页面布局 | 标题、正文、导航和媒体的位置 | 内容层次；表格布局结果 |
| 媒体元素 | 文本、图像等来源及相对位置 | 素材路径、尺寸和预览结果 |

插入的 SWF、FLV 还依赖播放器支持：页面上出现的是动画图标或组件，能不能播放要单独检查。

### 超链接与路径辨析

超链接指从一处跳到另一处的链接。Dreamweaver 2020 里可以创建四类：页间链接能跳到别的网页或文件，图像、影片、PDF、声音都行；页内链接，也叫锚记链接，跳到本站点里某篇文档的指定位置；E-mail 链接，启动电子邮件程序并填入地址；空链接及脚本链接，用于给对象附加行为或执行 JavaScript。

链接路径分绝对路径和相对路径。绝对路径是包含服务器协议在内的完全路径，与链接的源端点无关，目标站点地址不变时，文档在站点里怎么移动都能正常跳转；它不利于测试和站点移植，链接本站点之外的网页或网站必须使用它。相对路径又分根相对路径和文档相对路径：根相对路径从站点根文件夹算起，以 / 开头；文档相对路径从当前文档所在的文件夹算起。

判断一个链接写得对不对，要同时看链接目标和参照位置。原书相对路径一节的示例把两种相对路径的写法混在一起（原书如此），路径也不完整，这里按两种相对路径的定义说明。

### 任务：把集成与交付分开验收

图标用 IconCool Editor，自启动方案用 AutoPlay Media Studio 6.0，刻录用 Nero 9，站点用 Dreamweaver 2020；这几个版本按教材记录。

| 任务 | 初始条件与操作 | 交付与检查 |
| --- | --- | --- |
| 图标 | 新建；设尺寸与颜色；绘制标记 | ICO；预览主体与边缘 |
| 本地菜单 | 新建方案；设标题、图标与按钮动作 | 工程；逐个预览入口 |
| 发布映像 | 从已检查的方案发布 | ISO；检查文件及引用 |
| 数据光盘 | 选介质；添加文件；核对容量与写入条件 | 盘片；独立读取和播放 |
| 网络站点 | 定义本地根目录；保存页面与资源 | 站点文件；逐页访问 |

映像任务与实体刻录分开记录。没有刻录机或适用介质时，刻录、读取与目标环境启动都只能登记为待验证；ISO 已生成并不说明这些环节通过，图标的小尺寸预览也代替不了完整菜单或站点测试。

### 站点任务：移动页面后找回资源

建立如下目录。目录树表示文件位置，文件名为本任务自拟。

```text
guide/
├── index.html
├── pages/
│   └── visit.html
└── assets/
    ├── sign.png
    └── intro.wav
```

1. 在 Dreamweaver 中定义 `guide/` 为本地站点根目录，新建并保存首页和参观页；登记站点、文档与文件面板各在管理什么。
2. 在首页输入标题和说明，安排导航与媒体位置；在参观页插入自绘图片，创建返回首页的链接。
3. 对 `pages/visit.html` 采用文档相对路径：图片是 `../assets/sign.png`，返回首页是 `../index.html`。先从当前目录退一级，再进入目标位置，逐段解释路径。
4. 将参观页移到 `pages/archive/visit.html`，重新检查引用。按移动后的文档位置，图片应为 `../../assets/sign.png`，首页应为 `../../index.html`；软件是否自动更新引用另记实际观察。
5. 关闭编辑预览，从站点入口逐页检查文字、图像和链接。音频文件存在、媒体已插入和实际播放是三个不同的检查项；SWF、FLV 按示例版本操作，能否播放单独记录。

记录包括软件版本、操作系统、素材来源、移动前后位置、预期路径、实际路径、预览结果与日期。相对路径按本任务目录逐级推算。

## 本章小结

- 单项媒体编辑和作品集成是两种职责；选平台要看它对媒体编排、导航、交互和交付的支持，软件名字本身说明不了全部能力。
- 文档相对路径从当前页面所在目录解释：页面移动后，原路径会指向别的位置，要按新位置逐级重算。
- 本地介质和网络作品都要在目标环境检查资源、入口和播放；ISO 映像生成、实际刻录和成功运行是三件不同的事。

## 练习

**1. 博物馆已有照片、旁白和动画，现在需要把它们组合成可交互导览。图像处理软件为什么不足以完成平台选型？还要核查哪些组织能力？**

考点：第 1、2 节；层次：识记。

**答案：** 单一媒体编辑与多媒体作品组织的职责不同。导览平台还要能安排多种媒体、页面或场景、用户操作及播放控制，并支持编辑和交付。选型时应从作品结构和交互要求反推能力；软件出现在平台软件名单里，只说明它属于平台软件，不说明它满足某项具体要求。

**2. 准备把同一份导览内容分别交付为本地介质作品和网络型作品。设计两份检查单，比较素材组织、菜单导航和访问路径；不以光盘菜单能启动代替完整作品测试。**

考点：第 3、4 节；层次：识记、简单应用。

**答案：** 本地介质要核对素材完整性、菜单入口和目标环境中的启动与播放；网络型作品要核对站点组织、页面与媒体资源位置和超链接访问。两者都要检查内容和导航，一个入口能打开只是第一项检查，全部资源是否可用要逐项验证。刻录或发布后要在脱离制作目录的环境复测。

**3. 站点根目录含pages/exhibit.html与assets/logo.png。图片从exhibit.html引用时，使用相对于当前文档的路径应如何写？若把页面移入pages/archive/，为什么原路径可能失效？**

考点：第 4 节；层次：识记、简单应用。

**答案：** 原位置应写../assets/logo.png：从pages返回根目录再进入assets。页面移到pages/archive后，文档参照位置改变，原路径将指向pages/assets；按新位置应写../../assets/logo.png。这里明确采用文档相对路径，不混用站点根参照。

**4. 本章示例包含旧版制作工具、刻录流程和Animate媒体。团队没有相同运行环境，却想把“菜单存在、文件已生成”写成验收通过。应如何记录版本和验证结果？**

考点：第 4 节；层次：领会、简单应用。

**答案：** 按示例所用版本记录需要学习的制作流程，分别标明未在指定环境验证的操作和媒体播放条件。生成文件只说明某个输出步骤发生过，目标环境能否启动、播放、链接是否正确，要另行验证。验收应记录环境、操作、预期与实际结果；缺少运行验证的项目继续列为待验证。

**5. 图标在编辑区里细节清楚，但放入菜单后主体难辨。说明图标编辑、菜单集成和预览检查分别应观察什么；“ICO 已保存”能证明哪些步骤完成？**

考点：第 4 节；层次：识记、简单应用。

**答案：** 图标编辑应检查尺寸、颜色和构图，小尺寸预览检查主体与边缘是否可辨，菜单集成还要核查引用及实际显示。ICO 已保存只说明产生了相应文件；菜单引用是否正确、小尺寸效果是否合格，仍要检查。应调整自绘素材，重新保存并在菜单中复查。

**6. 一个制作方案已生成 ISO，但没有写入盘片，也没有在使用端运行。分别列出已完成、尚待验证的环节，以及下一步需要保存的观察记录。**

考点：第 4 节；层次：识记、领会、简单应用。

**答案：** 可以记录映像已生成，但仍要检查映像文件内容与素材引用；实体写入、盘片读取、目标环境启动和媒体播放没有由此完成。后续应登记刻录软件和设备、介质、容量检查、写入结果、读取情况及菜单与各媒体的实际表现，缺少条件的环节保持待验证。
