## 必背清单

**第 1 节**

1. 【考纲 1.1】物体振动引起压力波，压力波到达人的耳膜时人感觉到这种压力的变化或振动，这就是声音。
2. 【考纲 1.1】波形的最大位移称振幅 A，反映音量；两个连续波峰或波谷之间的距离称周期 T，其倒数 $1/T$ 即频率 f，以 Hz 为单位，反映声音的音调。
3. 【考纲 1.1】声音按频率分 3 类：低于 20Hz 为次声，20Hz～20kHz 为音频，高于 20kHz 为超音频（或超声）。
4. 【考纲 1.1】振幅和频率不变的声音为纯音；语音、乐声等大多数是由不同振幅和频率组成的复音，复音中最低频一般为常数，称基频，是决定音调的基本因素，其他频率称谐音；音色是辨别声音的特征。
5. 【考纲 1.2】声音的强度水平用 dB 表示，dB 值等于在对数标尺上选定的参考声强与实际感受的声强的比值；输出功率提高到原来的 4 倍，dB 值只增加 6；提高到 100 倍只增加 20。
6. 【考纲 1.2】音频只是存储在计算机里的声音，用声卡可以把声音录制下来并以文件方式存储，播放时由音频程序还原；多媒体计算机中的音频主要有波形音频、CD 音频和 MIDI 音乐 3 种形式。
7. 【考纲 1.2】波形音频是外部声音源经数字化采集到计算机中的所有声音形式；CD 音频是存储在音乐 CD 光盘中的数字音频；MIDI 音乐把音乐符号化保存在 MIDI 文件中，通过音乐合成器产生声音波形还原播放。

**第 2 节**

8. 【考纲 2.4】数字化的具体过程包括采样、量化和编码 3 个环节：采样和量化完成模拟信号的数字化表示，编码实现数字音频的标准化和数据压缩；数字化后的质量取决于采样频率、量化位数以及编码压缩算法。
9. 【考纲 2.1】采样主要参数是采样频率，即每秒钟抽取声波幅度样本的次数，单位 kHz；采样频率越高声音失真越小，但存储数据量也越大。
10. 【考纲 2.1】奈奎斯特采样定理指出采样频率不应低于声音信号最高频率的两倍；音频的频率在 20Hz～20kHz，为保证不失真，采样频率应在 40kHz 左右。
11. 【考纲 2.1】常用音频采样率有 8kHz、11.025kHz、16kHz、22.05kHz、37.8kHz、44.1kHz（CD 音质）、48kHz。
12. 【考纲 2.2】量化位数是每个采样点能够表示的数据范围，位数越多量化值越接近原始波形；常用 8 位、16 位、24 位；语音可用 8 位对应 256 个量化级，音频可用 16 位对应 65536 个量化级。
13. 【考纲 2.2】量化级的大小决定声音的动态范围，16 位量化级足以表示极细微的声音到巨大噪声的范围；量化时每个采样数据四舍五入到最接近的整数，波形幅度超过可用的最大位时顶部和底部被削去，称为削峰，可能造成严重失真。
14. 【考纲 2.3】记录声音时每次生成一个声波数据为单声道，每次生成两个为双声道（立体声），每次生成两个以上为多声道（环绕立体声）。
15. 【考纲 2.4】采样量化后的数字音频要经过编码压缩才能以音频文件形式存储或传输，播放时通过解码器还原；压缩要去除数据冗余，同时把音频质量控制在许可范围内。

**第 3 节**

16. 【考纲 3.1】单位时间数据量 $\nu=f_c\cdot b\cdot s/8$（原书标为 KB/s），$f_c$ 为采样频率（kHz）、b 为量化位数、s 为声道数；具体计算时再与采样时间 t 相乘，并注意采样频率的单位换算。
17. 【考纲 3.1】原书例算：22.05kHz 采样频率、8 位量化、单声道、10s，得 220500，该数值是 10 秒内的字节数，不是每秒的 KB 数。
18. 【考纲 3.2】CD 音质的具体参数为 PCM 编码格式、采样频率 44.100kHz、16 位量化位数、双声道立体声，这组参数每秒产生约 172KB 数据量；PCM 即脉冲编码调制编码。
19. 【考纲 3.2】容量与时长互相换算时，先算每秒字节数再乘秒数；字节率用 B/s、容量用 B，两种单位必须相配，已压缩文件不能套用采样公式。

**第 4 节**

20. 【考纲 4.1】音频数据压缩编码分无损压缩和有损压缩两大类：无损压缩主要包含各种熵编码；有损压缩分波形编码、参数编码和同时利用多种技术的混合编码。
21. 【考纲 4.1】波形编码在模拟音频抽样和量化过程中根据人耳听觉特性编码，并使编码后的信号与原始信号波形尽可能匹配；适应性强、音频质量好，但压缩比不大。
22. 【考纲 4.1】参数编码把音频信号表示成某种模型的输出，抽取必要的模型参数和激励信号信息进行编码，输出端再合成原始信号；压缩率很大，但计算量大、保真度不高，适合电话音质的一般语音。混合编码介于两者之间，可在较低码率上得到较高音质。
23. 【考纲 4.2】WAV 是微软推出的格式、Windows 使用的标准数字音频，采样数据不经过压缩，不会失去任何记录信息，音质最好、数据体积最大。
24. 【考纲 4.2】MP3 全称 MPEG-1 Layer3 音频文件，MP1 压缩率为 4:1、MP2 为 6:1～8:1、MP3 高达 10:1～12:1；它是有损压缩，1 分钟 CD 音质音乐未压缩约 10MB，压缩后约 1MB。
25. 【考纲 4.2】WMA 采用流式压缩技术，压缩率一般可达 18:1 左右，支持音频流、适合网络在线播放。
26. 【考纲 4.2】MIDI 文件不对声波采样量化和编码，而是记录电子乐器键盘的演奏信息（键名、力度、时间长短等），是乐谱的一种数字式描述，文件比声音文件小得多（5 分钟乐曲不到 20KB）；MIDI 播放音质取决于用户的 MIDI 设备。
27. 【考纲 4.2】CD-DA 是标准光盘文件，数据量大、音质好；Audio 格式（au）是 Sun 为 UNIX 系统开发的格式；RealAudio 是流式音频格式，主要用于网络在线音乐；AIFF 由 Apple 开发，被 Macintosh 平台及其应用程序支持。

**第 5 节**

28. 【考纲 5.1】Adobe Audition 是专业音频编辑和混合环境，可录制、混合、编辑和控制数字音频，也能创建音乐、制作广播短片、修复录制缺陷。
29. 【考纲 5.1】GoldWave 集声音编辑、播放、录制和转换于一体，可从 CD、VCD、DVD 或其他视频文件中提取声音。
30. 【考纲 5.1】All Editor 提供 20 余种音频效果并自带多重剪贴板；Total Recorder 用虚拟声卡截取其他程序输出的声音，支持硬件、软件与网络音源，理论上不会出现失真。
31. 【考纲 5.1】格式工厂是多媒体格式转换软件，支持转为 MP3、WMA、FLAC、3GP、OGG 等格式，可从光盘提取音频，还可进行音频编辑。

**第 6 节**

32. 【考纲 6.1】采集数字音频先要选择并设置恰当的采样参数：参数太低音质差，太高则产生巨大数据量；一段音频只能有一个采样率，录制过程中不能修改，因此要在音质与数据量之间折中。
33. 【考纲 6.1】录音前要检测输入音频强度：输入强度太低则音量小、录制结果夹杂许多噪声；输入强度过高超出允许范围则录制产生失真。
34. 【考纲 6.2】抓取音轨可用 Windows Media Player、WaveLab 等，普遍使用的无损抓轨工具是 Exact Audio Copy，它采用 C2 级校错、间隙检测、精确流控制、音频缓冲、音轨同步、采样偏移等技术改善抓取质量。
35. 【考纲 6.2】制作 MIDI 音乐需要声卡带声音合成器、一个 MIDI 键盘，并用音序器软件采集电子乐器发出的指令，记录到 .mid 文件中；声卡播放 MIDI 最常用的方法是 FM 合成与波表合成，波表用真实乐器采样，效果好于 FM。
36. 【考纲 6.3】Audition 新建音频文件时要选择采样率（默认 48000 Hz），可在多轨会话中分轨；导入素材采样率与会话不一致时按提示自动匹配。
37. 【考纲 6.3】Audition 的降噪在单轨编辑视图里做：先在有声段落处捕捉噪声样本，再选中要处理的音频段，用降噪窗口调节参数线；处理强度越高声音越干净，人声失真的可能也越大。

## 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 响度、音高与音色 | 响度由振幅决定，音高由频率决定，音色用于辨别声源 | 改哪一项物理量会变哪个听觉特征 |
| 采样与量化 | 采样在时间上把波形离散，量化在幅度上把取值离散 | 离散的是时间点还是幅值 |
| 采样频率与量化位数 | 采样频率决定每秒取多少样本，量化位数决定每个样本能分多少级 | 影响的是时间密度还是幅值精度 |
| 波形音频与 MIDI | 波形音频记录数字化波形，MIDI 记录键名、力度、时长等演奏信息 | 文件里存的是波形数据还是指令 |
| 无损与有损编码 | 无损以熵编码为主、可还原；有损含波形、参数、混合编码 | 解码后能否完全还原原信号 |
| 波形编码与参数编码 | 波形编码尽量贴合原波形、压缩比不大；参数编码只传模型参数与激励、压缩率大但保真度不高 | 编的是波形本身还是模型参数 |
| WAV 与 MP3 | WAV 不压缩、体积最大；MP3 有损、压缩率高 | 体积与是否丢信息 |
| kB 与 KiB | $1\text{ KB}=1000\text{ B}$；$1\text{ KiB}=1024\text{ B}$ | 除以 1000 还是 1024 |
| 位率与字节率 | 位率单位 bit/s，字节率单位 B/s，两者相差 8 倍 | 除以 8 没有 |
| FM 合成与波表合成 | FM 靠声音振荡合成、人工痕迹强；波表用真实乐器采样、效果好 | 音色来自振荡还是采样表 |
| 录音与抓轨 | 录音从声源采集，抓轨从已有媒体提取音轨 | 声音从哪来 |

## 简答答题模板

**声音的三要素与对应的物理量**

三项各一句：响度由振幅决定，振幅是波形的最大位移；音高由频率决定，频率是周期的倒数；音色是辨别声音的特征，由基频与谐音的组合决定。末句补纯音与复音的区别。

**音频数字化的过程**

三环节各一句：采样是每隔一段时间读取一次声音幅度，使声音在时间上离散，主要参数是采样频率；量化把采样得到的幅度转换为数字值，使声音在幅度上离散，常用 8、16、24 位；编码把量化后的数据形成可存储或传输的数字音频表示，并实现标准化与压缩。

**采样定理与常用采样率**

先写奈奎斯特定理：采样频率不应低于声音信号最高频率的两倍，才能把离散数字音频还原为原来的声音。再写音频频率为 20Hz～20kHz，故采样频率应在 40kHz 左右。最后列常用采样率 8、11.025、16、22.05、37.8、44.1（CD 音质）、48 kHz。

**未压缩 PCM 数据量的计算**

先写 $B=f_s\times b\times s\times t/8$ 并说明各符号；再写列算顺序，kHz 先乘 1000；最后声明只计未压缩采样数据，不含文件头与封装开销，已压缩文件不能套用此式。

**无损压缩与有损压缩**

无损压缩主要包含各种熵编码，解码后可完全还原。有损压缩分三类：波形编码使编码信号尽量匹配原波形，适应性强、音质好但压缩比不大；参数编码只编码模型参数与激励信息，压缩率大但计算量大、保真度不高；混合编码介于两者之间。

**MIDI 与波形音频的区别**

MIDI 不对声波进行采样、量化与编码，而是记录键名、力度、时间长短等演奏信息，是乐谱的数字式描述；播放时读出 MIDI 消息，由音乐合成器产生波形再放大输出。所以 MIDI 文件小得多，但播放质量取决于用户的 MIDI 设备。

**录音采集前要确认什么**

两件事：按用途定采样参数，参数太低音质差、太高数据量巨大，而且一段音频只能有一个采样率、录制中不能改；检测输入强度，太低则噪声突出、太高则超出允许范围而失真，调整后再正式录制。
