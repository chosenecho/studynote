## 必背清单

**第 1 节**

1. 【考纲 1】模拟视频的五个特点：以连续模拟信号记录信息、用隔行扫描在输出设备上还原图像、用模拟设备编辑处理、用模拟调幅在空间传播、用模拟录像机存于磁带。
2. 【考纲 1】模拟视频信号包括亮度信号、色度信号、复合同步信号和伴音信号；信号类型分复合、分量、分离（Y/C）、射频四种。
3. 【考纲 1】复合视频信号含亮度、色差和所有定时信号，不含伴音，带宽较窄，一般只能提供 240 线左右的水平分辨率。
4. 【考纲 1】分量视频信号把每个基色分量作为独立信号，可用 R、G、B 或 Y、I、Q 等亮度-色差表示，是表示颜色的最好方法，但需要较宽带宽和同步信号。
5. 【考纲 1】分离视频信号把亮度 Y 和色差 C 分离，是分量与复合的折中，既减少交叉干扰，又提高亮度信号的带宽。
6. 【考纲 1】射频信号把包括伴音在内的全电视信号调制成射频，每个信号占用一个频道，用于远距离传输。
7. 【考纲 1】模拟视频标准也称电视制式，最常用 NTSC、PAL、SECAM 三种，区别主要在帧频（场频）、信号带宽与载频、色彩空间的转换关系。
8. 【考纲 1】NTSC 由 525 条水平扫描线构成，场频 59.94 Hz（习惯记 60 场/s）、帧频 30 f/s，隔行扫描，实际帧频为 29.97 Hz；中国与多数欧洲国家用 PAL，美国和日本用 NTSC，法国等用 SECAM。
9. 【考纲 1】PAL 把屏幕分辨率增加到 625 线、扫描速率降到 25 fps、刷新频率 50 Hz，采用隔行扫描；SECAM 帧频 25 f/s、625 行、50 Hz、画面比例 4:3。
10. 【考纲 1】数字电视在拍摄、编辑、制作、播出、传输、接收全过程都用数字技术，支持 4:3 与 16:9 两种宽高比，清晰度分 PDTV、SDTV、HDTV 三级，支持隔行与逐行两种扫描方式。

**第 2 节**

11. 【考纲 2】数字视频的五个特点：以离散数字信号记录信息、用逐行扫描在输出设备上还原图像、用数字化设备编辑处理、通过数字化宽带网络传播、可存储在数字存储媒体上。
12. 【考纲 2】与模拟视频相比的三个优点：可用计算机编辑处理；再现性好，可不失真地无限次复制，不因存储、传输和复制而退化；适合于数字网络，长距离传输不衰减。
13. 【考纲 2】数字视频的缺陷是数据量巨大，需要适当压缩才能处理；播放时要通过解压缩还原，处理速度较慢。
14. 【考纲 2】数字视频编辑包括视频内容编辑与视频效果处理两方面；内容编辑的对象是特定格式的计算机数据文件，最大特点是定位准确，主要是插入（拼接）和删除（裁剪）。
15. 【考纲 2】效果处理是对已有画面添加艺术效果和特技镜头，如放大、缩小、冻结、翻转、字幕、合成、淡入淡出；两类编辑都要同时处理相应的伴音，伴音效果要与画面效果相适应。
16. 【考纲 2】编辑结果有两种输出形式：直接输出压缩的视频文件（AVI、MPEG、MOV 等），或直接输出到数字录像带保存。

**第 3 节**

17. 【考纲 3】线性编辑强调编辑过程的顺序性：磁带信息按时间顺序记录，选取片段要频繁倒带、进带甚至换带，费时费力、效率较低。
18. 【考纲 3】非线性编辑建立在多媒体计算机系统之上，编辑对象是各种音视频文件，利用计算机的处理能力和交互性完成裁剪、拼接、合成及其他效果处理。
19. 【考纲 3】非线性编辑的四个特点：可随时、随地、重复编辑处理；任何编辑操作都不会引起画面质量下降；编辑方便简单、对位准确、效果丰富；设备数字化、小型化、功能强，便于联网共享资源。
20. 【考纲 3】MPEG 是运动图像专家组，1988 年由 ISO 与 IEC 联合成立，负责制定电视图像与声音的编码、解码及同步标准；已开发的 MPEG 标准有 MPEG-1、MPEG-2、MPEG-4、MPEG-7、MPEG-21。
21. 【考纲 3】MPEG-1 正式名称为“基于数字存储媒体运动图像和声音的压缩标准”，着眼于解决存储问题，VCD 与 MP3 是代表产品。
22. 【考纲 3】MPEG-2 正式名称为“通用的图像和声音压缩标准”，解决多媒体传输问题，最引人注目的产品是数字电视机顶盒与 DVD，与 MPEG-1 兼容。
23. 【考纲 3】MPEG-4 是超低码率运动图像和语言的压缩标准，用于低于 64 kb/s 的实时图像传输，更多定义格式与架构而不是具体算法。
24. 【考纲 3】MPEG-7 是多媒体内容描述接口，提供标准化的描述符集合；MPEG-21 支持通过异构网络和设备使用多媒体资源，目标是建立交互的多媒体框架。
25. 【考纲 3】ITU-T 制定的 H.261、H.262、H.263、H.264 主要用于实时视频通信；H.262 等同于 MPEG-2 的视频编码，H.264 在 ISO/IEC 中称为 MPEG-4 第 10 部分即 AVC。
26. 【考纲 3】H.261 面向 ISDN 上的视频会议与可视电话，以 $p\times64$ kb/s 为标准码率、p 取 1～30，又称 $p\times64$ 标准，采用混合编码方案。
27. 【考纲 3】H.263 是最早用于低码率视频信号压缩的标准，目前是可视电话中应用最广泛的视频压缩标准。
28. 【考纲 3】H.264 最大的优势是数据压缩比高：同等图像质量下，压缩比是 MPEG-2 的 2 倍以上、MPEG-4 的 1.5～2 倍。
29. 【考纲 3】数字视频体系包括编码格式与识别播放该格式的播放器，主要有 QuickTime、Windows 媒体格式、RealMedia 和 MPEG，对应扩展名 .mov、.avi、.rm、.mpg 或 .dat。
30. 【考纲 3】视频文件分两类：多媒体出版的普通文件质量高、体积大；网络传输的流式文件边传输边播放。
31. 【考纲 3】AVI 是音视频交叉记录格式，音视频数据交替存储，解决同步问题，一般采用帧内有损压缩；MOV 采用 QuickTime 体系，可压缩或非压缩；RM 面向流式播放，RMVB 采用可变比特率。

**第 4 节**

32. 【考纲 4】采集模拟视频先建立采集环境：把摄像机、录像机、VCD 机等模拟源接到装有视频采集卡的计算机上，接口按信号类型选择，还要连接音频并同步采集。
33. 【考纲 4】采集数字视频经 IEEE 1394 接口把 DV 信号送入计算机；DV 数据量巨大，应从 CPU、RAM、硬盘三方面改进性能，连接电缆一端 4 针接摄像机、一端 6 针接接口卡。
34. 【考纲 4】屏幕录像软件把屏幕变化直接录下，作为采集的补充，Camtasia Studio 可完成录屏、配音、剪辑、加字幕水印、压缩与播放。
35. 【考纲 4】格式工厂可把视频转成 MPG、AVI、3GP、FLV、MP4，音频转成 MP3、OGG、WMA、M4A、WAV，图片转成 JPEG、BMP、PNG、TIF、ICO，源文件支持 RMVB，还能修复损坏的视频文件。
36. 【考纲 4】Premiere 编辑流程八步：创建和设置项目、采集素材、添加和整理素材、编辑素材、特效处理、添加字幕、保存项目、输出影片。
37. 【考纲 4】保存项目用于以后继续编辑和修改，输出影片把处理后的视频按格式打包存储，也可直接刻录成 DVD、SVCD 或 VCD 光盘。
38. 【考纲 4】时间轴按时间进度合成视频、音频和图片，是视频后期处理的中心；“音频音量栏”只监视音频大小，不能编辑音量。
39. 【考纲 4】源监视器用于预览和剪辑原素材，节目监视器用于实时预览编辑结果，媒体浏览器与项目面板分别用于查找和放置素材。
40. 【考纲 4】Premiere 的功能包括素材组织与管理、广泛的格式支持、视频素材剪辑、过渡效果、滤镜效果与项目发布。

## 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 复合信号与分量信号 | 复合把亮度、色差和定时信号合成一路且不含伴音；分量把每个基色分量作为独立信号 | 信号是合成一路还是分成多路 |
| 分离信号与复合信号 | 分离把亮度 Y 与色差 C 分开，是分量与复合之间的折中 | 色差是否单独走一条线 |
| 帧频与场频 | 帧频是每秒帧数，场频是每秒扫描场数，隔行扫描一帧由两场组成 | 数值上是两倍关系，NTSC 为 30 对 60 |
| NTSC 与 PAL | NTSC 为 525 行、30 f/s；PAL 为 625 行、25 fps | 行数与帧频两两配对记，不拆开 |
| 模拟视频与数字视频 | 模拟用连续信号、隔行扫描还原、模拟设备编辑；数字用离散信号、逐行扫描还原、数字化设备编辑 | 还原扫描方式与编辑设备是两处可判之处 |
| 线性编辑与非线性编辑 | 线性按时间顺序在磁带上找素材、要倒带；非线性在计算机中按文件调用、可重复编辑 | 定位素材要不要顺序查找 |
| 内容编辑与效果处理 | 内容编辑做插入与删除，改的是片段构成；效果处理加特技与艺术效果，改的是画面观感 | 改的是片段构成还是画面效果 |
| MPEG 与 H.26X | MPEG 面向存储、传输与内容描述；H.26X 面向实时视频通信 | 应用场合是存储播放还是可视电话、会议 |
| MPEG-7、MPEG-21 与编码标准 | 前两者不是视频编码算法；MPEG-7 是内容描述接口，MPEG-21 是交互式框架 | 是否给出压缩算法 |
| 编码标准与文件格式 | 编码标准规定怎样压缩，文件格式规定怎样组织与保存数据 | 换扩展名不等于换了编码 |
| 保存项目与输出影片 | 保存项目保留编辑工程供继续修改；输出影片生成可播放文件 | 拿到对方机器上能否直接播放 |

## 简答答题模板

**数字视频的特点与优点**

先写五个特点（离散信号记录、逐行扫描还原、数字化设备编辑、宽带网络传播、数字媒体存储），再写三个优点（可用计算机编辑处理、再现性好可无限次复制、适合数字网络长距离传输），最后补一句缺陷：数据量巨大需压缩，播放需解压缩。

**线性编辑与非线性编辑的区别**

分三点：素材存在方式不同，线性基于磁带按时间顺序记录，非线性是计算机中的音视频文件；定位方式不同，线性要反复倒带进带，非线性可直接调用；结果不同，线性反复编辑会损伤画面，非线性可随时重复编辑而不降低画面质量。再补非线性编辑系统以高性能计算机为平台、配高速大容量硬盘与视频处理软件。

**MPEG 标准系列各自解决什么问题**

按标准分条：MPEG-1 解决数字存储，代表是 VCD 与 MP3；MPEG-2 解决传输，与 MPEG-1 兼容，代表是数字电视机顶盒与 DVD；MPEG-4 面向超低码率实时图像传输，定义格式与架构；MPEG-7 是多媒体内容描述接口；MPEG-21 建立支持异构网络与设备的交互式框架。末句点明 MPEG-7 与 MPEG-21 不是视频编码算法。

**模拟视频的信号类型与制式区别**

信号类型四条：复合、分量、分离、射频，各写一句定义与用途。制式三条：NTSC 525 行、30 f/s、场频 60；PAL 625 线、25 fps、50 Hz；SECAM 25 f/s、625 行、50 Hz。区别落在帧频（场频）、信号带宽与载频、色彩空间转换关系三处。

**Premiere 的编辑流程**

按八步写：创建和设置项目、采集素材、添加和整理素材、编辑素材、特效处理、添加字幕、保存项目、输出影片。每步补一句产出物；末句区分保存项目（保留工程供继续编辑）与输出影片（生成播放文件），并说明还要在目标环境检查画面、声音与完整时长。
