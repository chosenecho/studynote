## 必背清单

**第 1 节**

1. 【考纲 1.1】操作系统的两个主要目标：与硬件相互作用，为底层可编程部件提供服务；为应用程序提供执行环境。
2. 【考纲 1.2】操作系统管理的四类资源：处理机、内存、设备、文件；网络操作系统还包括网卡、带宽。
3. 【考纲 1.1】操作系统是覆盖在裸机上的第一层软件，编译程序、数据库管理系统和应用程序都运行在它之上。

**第 2 节**

4. 发展顺序：无操作系统 → 单道批处理系统 → 多道程序系统（多道批处理、分时）→ 微机操作系统、网络操作系统、实时操作系统、嵌入式操作系统、物联网操作系统。
5. 【考纲 2.1】单道批处理系统的三个特点：自动性、顺序性、单道性。
6. 【考纲 2.1】多道批处理系统的四个特点：多道性、无序性、调度性、复杂性。
7. 【考纲 2.1】多道批处理系统的优点：提高 CPU、内存和 I/O 设备的利用率与系统吞吐量；缺点：平均周转时间长、缺乏交互能力。
8. 【考纲 2.2】分时系统的四个特点：多路性、独立性、及时性、交互性。
9. 【考纲 2.2】分时系统需要解决的两个关键问题：及时接收、及时处理。
10. 【考纲 2.3】实时系统的五个特点：多路性、独立性、及时性、交互性、可靠性，比多分时系统一项可靠性。
11. 批处理、分时、实时是三种基本类型，一个实际的操作系统可能兼有两者或三者的功能特点。
12. 【考纲 2.4】三个“第一”：CP/M 是第一个微机操作系统；CTSS 是第一个通用分时系统；OS/360 是 IBM 开发的第一个多道程序系统。

**第 3 节**

13. 【考纲 2.5】现代操作系统的四个特征：并发、共享、虚拟、异步性。
14. 【考纲 2.5】共享的两种方式：互斥共享，任意时刻资源只能被一个进程访问，如打印机；同时共享，宏观上资源可被多个进程同时访问，如磁盘。
15. 【考纲 2.5】并发与共享相互依赖：不支持并发就无须共享，资源共享不好并发也支持不好。

**第 4 节**

16. 【考纲 2.6】内存管理的四项功能：内存分配、内存保护、地址映射、内存扩充。
17. 内存分配的两种方式：静态分配，分区大小和数量固定；动态分配，按进程请求分配，大小和数量可变。
18. 内存保护的两个任务：内核空间不被用户随意访问；每道用户程序只在自己的内存空间内运行，互不干扰。
19. 内存扩充的两个功能：请求调入、置换。
20. 【考纲 2.6】进程管理的五项功能：进程的描述与组织、进程控制、进程同步、进程通信、进程调度。
21. 【考纲 2.6】设备管理的四项功能：缓冲管理、设备分配、设备处理、设备独立性和虚拟设备。
22. 【考纲 2.6】文件管理的三项功能：文件存储空间的管理、目录管理、文件的读、写管理和存取控制。
23. 【考纲 2.6】用户接口的三类：命令接口（联机用户接口、脱机用户接口）、图形用户接口、程序接口即系统调用。

**第 5 节**

24. 【考纲 2.7】单体结构：所有软件和数据结构放在一个逻辑模块中，对外只提供系统调用；结构简单、效率高，但子程序可互相调用，易引起循环调用和死锁，可修改性与可维护性差。代表：UNIX、MS-DOS、Linux、Mac OS X、BSD。
25. 【考纲 2.7】层次结构：单向调用，每层只依赖下层提供的服务；便于实现、调试和测试，可读性、可靠性、可移植性增强；困难在于层的顺序与内容划分、循环依赖，以及穿越多层带来的性能开销。代表：Dijkstra 的 THE 系统。
26. 【考纲 2.7】微内核：核心功能外移，内核只保留处理机调度、内存管理和消息通信，服务器进程在用户空间通过消息传递交互；灵活性、可靠性、可维护性好，缺点是效率不高。代表：Windows NT、COS-IX V2.3、Mach、VxWorks。
27. 【考纲 2.7】动态可扩展的两种技术：UPCALL，由核心层调用用户层服务，典型是外核结构 Exokernel；DOWNLOAD 即核心扩展技术，把构件动态下载到内核，典型是 VINO。两者都要额外解决安全性。

**第 6 节**

28. 【考纲 3.1】寄存器分工：PC 存下一条待取指令的地址；IR 存正在执行的指令；AC 是累加器，暂存操作数与结果；ALU 完成算术逻辑运算。
29. 【考纲 3.2】指令周期分为取指周期和执行周期。
30. 【考纲 3.2】取指后 PC 自动递增，指向按顺序的下一条指令；只有分支等控制操作才改变顺序。
31. 【考纲 3.2】执行指令的动作分四类：处理器与存储器之间的数据传送、处理器与 I/O 设备之间的数据传送、算术运算或逻辑运算、控制操作。
32. 【考纲 3.2】模型机指令和数据都是 16 位：4 位操作码，最多 16 种指令；12 位地址，可直接访问 4096 字节。

## 必背数字与公式

| 项目 | 必背内容 |
| --- | --- |
| 模型机字长 | 16 位，指令与数据同宽 |
| 操作码字段 | 4 位，最多 $2^{4}=16$ 种操作 |
| 地址字段 | 12 位，可寻址 $2^{12}=4096$ 个单元，按字节编址即 4096 B |
| 地址数与字节数换算 | 地址数 $=2^{\text{地址位数}}$；字节数 $=$ 地址数 $\times$ 每个地址单位的字节数 |
| 吞吐量 | 单位时间内处理的作业量 |
| 平均周转时间 | 各作业周转时间之和 $\div$ 作业数量 |

## 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 并发与并行 | 并发是同一时间间隔内发生；并行是同一时刻发生 | 单 CPU 多任务只有并发，没有并行 |
| 互斥共享与同时共享 | 互斥共享任意时刻只允许一个进程访问；同时共享宏观上多进程同时访问 | 资源被交替使用会不会互相破坏，打印机互斥、磁盘同时 |
| 单道与多道批处理 | 内存中驻留一道作业与多道作业 | 作业等 I/O 时 CPU 是否只能空闲 |
| 分时与实时 | 及时性的标准不同：分时按人可接受的等待时间，实时按开始或完成截止时间；实时多一条可靠性 | 超时算不算错，实时算错，分时只是体验差 |
| 批处理与分时 | 批处理无交互，分时有交互 | 用户能否在作业运行过程中干预 |
| 单体与层次 | 单体没有位置概念、子程序可互相调用；层次单向调用、只依赖下层 | 模块之间能否互相调用 |
| 单体与微内核 | 单体把功能都放在内核地址空间直接调用；微内核把服务外移到用户空间靠消息传递 | 服务运行在内核空间还是用户空间 |
| 逻辑地址与物理地址 | 逻辑地址相对程序起始地址计算；物理地址是内存单元的地址 | 是否需要经过地址映射才能访问内存 |

## 简答答题模板

本章近年没有出简答题，但 2.5 与 3.2 是领会层次，仍按简答准备。

**操作系统的作用和功能**

作用两条：提供用户与硬件之间的接口，屏蔽硬件细节；为应用程序提供执行环境。功能五项：处理机管理、内存管理、设备管理、文件管理、提供用户接口，每项补一句具体职责。

**单道批处理、多道批处理、分时系统的特点与优缺点**

分三段答：先逐条列特点（单道三个、多道四个、分时四个），再写优点，最后写缺点。多道的缺点固定是平均周转时间长、缺乏交互能力。

**内存管理的功能**

四项各一句：内存分配为每道程序分配空间；内存保护防止越界访问与互相干扰；地址映射把逻辑地址转换为物理地址；内存扩充用请求调入和置换从逻辑上扩大内存。

**指令的执行过程**

取指：按 PC 指示的地址取出指令送入 IR，PC 递增。译码：解释操作码。执行：完成传送、运算或控制四类动作之一，结果写入寄存器或内存。指令周期由取指周期和执行周期组成。

**操作系统的特征**

四项各一句：并发是多个事件在同一时间间隔内发生；共享是资源供多个并发进程共同使用；虚拟是把一个物理实体变成多个逻辑对应物；异步性是进程以不可预知的速度推进。
