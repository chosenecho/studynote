## 必背名词

| 术语 | 必背一句话 | 常考 |
| --- | --- | --- |
| I/O 系统 | 包括各种 I/O 设备、与设备相连的设备控制器，有些系统还配备通道，并通过总线与 CPU、内存相连 | 填空 |
| 通道 | 一种特殊的处理机，具有执行 I/O 指令的能力，通过执行通道程序控制 I/O 操作，是大型主机系统中专门用于 I/O 的专用计算机 | 单选、简答 |
| 设备控制器 | CPU 与 I/O 设备之间的接口，接收 I/O 的命令并控制设备完成 I/O 工作 | 单选、简答 |
| 块设备 | 数据的存取以数据块为单位，块大小通常固定，一次只传送一块，如磁盘 | 单选 |
| 字符设备 | 传送字节流、没有使用块结构的设备，如终端、打印机、通信端口和鼠标 | 单选 |
| 独占设备 | 必须作为临界资源以互斥方式访问的设备，一个进程未用完其他进程不能访问，如打印机 | 单选、简答 |
| 共享设备 | 允许多个进程共同访问的设备，一个进程的任务未完成即可把设备分配给另一进程，如硬盘 | 单选 |
| 虚拟设备 | 通过某种虚拟技术把一台物理设备变成若干逻辑设备，多个用户各有一个逻辑设备 | 单选 |
| 轮询 | 反复检测设备控制器状态寄存器的忙闲标志位，直到空闲才发送 I/O 指令 | 单选 |
| 缓冲区 | 用来保存两个设备之间或设备与应用程序之间传输数据的内存区域 | 填空 |
| 双缓冲 | 一个缓冲区传送数据时，操作系统正在清空或填充另一个缓冲区 | 单选 |
| 循环缓冲 | 用多于两个的缓冲区，分空缓冲区、已装满数据的缓冲区和现行工作缓冲区，配三个指针 | 单选 |
| 缓冲池 | 设置多个可供若干进程共享的缓冲区，提高缓冲区利用率，可同时用于输入和输出 | 单选 |
| 设备控制表 | 系统为每个设备建立的表，记录设备类型、标识符、忙闲状态、指向控制器表的指针和设备队列队首指针 | 单选 |
| 系统设备表 | 系统范围的数据结构，记录系统中全部设备的情况，每个设备占一个表目 | 单选 |
| 设备独立性 | 又称设备无关性，基本含义是应用程序独立于具体使用的物理设备 | 填空、简答 |
| 逻辑设备表 | 记录逻辑设备名与物理设备名映射的数据结构，可为整个系统或每个用户设一张 | 单选 |
| SPOOLing | 在联机情况下实现的同时外围操作，用磁盘上的井暂存输入输出任务 | 单选、简答 |
| 输入井和输出井 | 位于磁盘上分别存放输入数据和输出数据的存储区域，作为大量输入输出数据的缓存 | 单选 |
| 设备驱动程序 | I/O 进程与设备控制器之间的通信程序，把抽象的 I/O 请求转换为具体要求发给设备控制器 | 简答 |
| 寻道时间 | 把磁臂移动到指定磁道上所经历的时间，是启动磁臂时间与移动 n 条磁道时间之和 | 填空 |
| 旋转延迟时间 | 将指定扇区移动到磁头下面所经历的时间 | 填空 |
| 传输时间 | 把数据从磁盘读出或写入磁盘所经历的时间，与读写字节数和旋转速度有关 | 填空 |
| 虚拟盘 | 利用内存空间仿真磁盘，又称 RAM 盘，内容操作完全由用户控制 | 单选 |
| 磁盘高速缓存 | 内存中用来暂存从磁盘读出的一系列盘块信息的存储空间，内容由操作系统控制 | 单选 |

## 必背清单

**第 1 节**

1. 【考纲 1.1】I/O 系统的结构分两大类：微机 I/O 系统为总线型，CPU 与内存可直接交换信息，但不能与设备直接交换信息，必须经过设备控制器。
2. 【考纲 1.1】主机 I/O 系统可采用四级结构：主机、通道、控制器和设备；一个通道可以控制多个设备控制器，一个设备控制器也可以控制多个设备。
3. 【考纲 1.2】按传输速率分三类：低速设备如键盘和鼠标，几个至几百个字节每秒；中速设备如打印机，数千至数万个字节每秒；高速设备如磁带机、磁盘机、光盘机，几十万至几兆字节每秒。
4. 【考纲 1.2】按信息交换的单位分两类：块设备如磁盘，字符设备如终端、打印机、通信端口和鼠标；驱动程序要区分两者，缓冲管理与实现方式不同。
5. 【考纲 1.2】按共享属性分三类：独占设备、共享设备、虚拟设备；共享的含义是一个进程的任务未完成也可把设备分配给另一进程，并不是任意时刻都能同时读写。
6. 【考纲 1.3】设备控制器的六项功能：接收和识别命令、数据交换、设备状态的了解和报告、地址识别、数据缓冲、差错控制。
7. 【考纲 1.3】设备控制器的三部分：与处理机的接口有数据线、控制线和地址线；与设备的接口有数据、状态和控制三类信号；I/O 逻辑由指令译码器和地址译码器构成。
8. 【考纲 1.1】通道用于大型主机系统控制 I/O 设备，引入通道使 CPU 从控制 I/O 的任务中解脱，CPU 与 I/O 并行工作，提高 CPU 利用率和系统吞吐量。

**第 2 节**

9. 【考纲 2.1】轮询方式在发命令前反复检测忙闲标志位，发送命令后又进入轮询检测本次 I/O 是否结束，使 CPU 经常处于循环测试状态，影响系统吞吐量。
10. 【考纲 2.2】中断方式中设备忙则进程阻塞等待；设备工作完毕经中断控制器发中断请求，CPU 执行中断处理程序，唤醒被阻塞的进程。
11. 【考纲 2.3】DMA 控制器的四类寄存器：命令／状态寄存器 CR、内存地址寄存器 MAR、数据寄存器 DR、数据计数器 DC。
12. 【考纲 2.3】DMA 的 MAR 在输出时存输出数据在内存的起始地址，在输入时存输入数据将放入内存的起始地址；DC 指示发中断前要读写的次数。
13. 【考纲 2.3】DMA 传送时每读入一个字或字节就送到 MAR 指示的单元，MAR 递增、DC 减 1，DC 减为 0 时由 DMA 向 CPU 发中断请求。
14. 【考纲 2.1】I/O 控制方式发展的目标始终是尽量减少主机对 I/O 控制的干预，提高主机与 I/O 的并行程度。

**第 3 节**

15. 【考纲 3.1】引入缓冲的两点原因：缓和生产者与消费者之间的速度差异；协调传输数据大小不一致的设备，如消息的分段和重组。
16. 【考纲 3.1】缓冲的作用：缓和 CPU 与 I/O 设备速度不匹配的矛盾，降低对 CPU 中断频率的要求，放宽对中断响应时间的限制，提高 CPU 与 I/O 设备的并行性。
17. 【考纲 3.2】循环缓冲的三种缓冲区：空缓冲区 R、已装满数据的缓冲区 G、现行工作缓冲区 C；三个指针为 Nextg、Nexti、Current。
18. 【考纲 3.2】循环缓冲的同步：Nexti 追上 Nextg 说明全部缓冲区已满，阻塞生产者；Nextg 追上 Nexti 说明缓冲区全空，阻塞消费者。
19. 【考纲 3.2】公共缓冲池有三种类型的缓冲区、三个队列即空缓冲队列 emq、输入队列 inq、输出队列 outq，还有四种工作缓冲区；每队列设互斥信号量 MS 与资源信号量 RS。
20. 【考纲 3.2】缓冲池的四种工作方式：收容输入、提取输入、收容输出、提取输出，都由 Getbuf 与 Putbuf 过程完成。

**第 4 节**

21. 【考纲 4.1】设备分配的四张表：设备控制表 DCT、控制器控制表 COCT、通道控制表 CHCT、系统设备表 SDT。
22. 【考纲 4.1】设备控制表含设备类型、设备标识符、忙闲状态、指向控制器表的指针、重复执行的次数或时间、设备队列的队首指针。
23. 【考纲 4.1】系统设备表是系统范围的数据结构，每个设备占一个表目，含设备类型、设备标识符、设备控制表及设备驱动程序的入口地址。
24. 【考纲 4.2】分配设备时考虑三个因素：设备的固有属性、设备分配算法、设备分配时的安全性。
25. 【考纲 4.2】设备的固有属性三种：独占性、共享性、可虚拟性；独占设备用独享分配策略，缺点是设备得不到充分利用，还可能引起死锁。
26. 【考纲 4.2】设备分配算法两种：先来先服务、基于优先权的分配算法，优先权相同的请求按先来先服务排队。
27. 【考纲 4.2】安全分配方式下进程发出 I/O 请求便阻塞，运行中不保持资源，摒弃了请求和保持条件，代价是 CPU 与 I/O 设备串行工作。
28. 【考纲 4.2】不安全分配方式下进程发出请求后继续运行，可能具备请求和保持条件而出现死锁，优点是一个进程可同时操作多个设备。
29. 【考纲 4.1】独占设备的分配程序按顺序分配设备、分配控制器、分配通道，三者都到手本次分配才算成功。

**第 5 节**

30. 【考纲 4.3】设备独立性的基本含义是应用程序独立于具体使用的物理设备；引入逻辑设备名与物理设备名，由系统完成两者之间的转换。
31. 【考纲 4.3】实现设备独立性带来三条好处：增减或变更外围设备不需要修改应用程序；易于处理输入输出设备的故障，可用不同型号打印机替换；提高系统可靠性，增加设备分配的灵活性。
32. 【考纲 4.3】逻辑设备表 LUT 的每个表目含逻辑设备名和物理设备名，可为整个系统设一张，也可为每个用户设一张。

**第 6 节**

33. 【考纲 4.4】SPOOLing 系统的组成：输入井和输出井、输入缓冲区和输出缓冲区、输入进程与输出进程、请求 I/O 队列。
34. 【考纲 4.4】SPOOLing 的三个特点：提高 I/O 速度；将独占设备改造为共享设备；实现虚拟设备功能，宏观上同时响应多个请求，微观上任意时刻只为一个进程服务。

**第 7 节**

35. 【考纲 4.5】设备管理软件分四层：用户层软件、与设备无关的软件层、设备驱动程序、中断处理程序，后者处于底层。
36. 【考纲 4.5】设备管理软件的六项功能：实现 I/O 设备的独立性、错误处理、异步传输、缓冲管理、设备的分配和释放、实现 I/O 控制方式。
37. 【考纲 4.5】设备驱动程序的任务是接受上层软件发来的抽象 I/O 请求，把它们转换为具体要求后发送给设备控制器启动设备执行，并把控制器发来的信号传送给上层软件。
38. 【考纲 4.5】中断处理程序的作用是将发出 I/O 请求而被阻塞的进程唤醒。
39. 【考纲 4.5】与硬件无关的 I/O 软件七项功能：设备命名、设备保护、提供独立于设备的块大小、为块设备和字符设备提供缓冲技术、块设备的存储分配、分配和释放独立设备、错误处理。
40. 【考纲 4.5】错误应尽可能接近硬件处理，低层处理不了才通知高层；驱动程序属内核程序，一般由设备厂商随硬件提供，须遵循内核与驱动的接口标准。

**第 8 节**

41. 【考纲 4.6】磁盘数据布局：盘面分成若干同心环即磁道，每条磁道划分成若干扇区，一个物理记录存储在一个扇区上，物理记录数目由扇区数、磁道数及盘面数决定。
42. 【考纲 4.6】磁盘先低级格式化划分扇区，每个扇区含标识符字段与数据字段；再分区并记录在分区表中；最后高级格式化，设置引导块、根目录和一个空文件系统。
43. 【考纲 4.6】固定头磁盘每条磁道都有读写磁头，可并行读写、提高 I/O 速度；移动头磁盘每面只有一个磁头，须寻道，只能串行读写。
44. 【考纲 4.6】磁盘访问时间分三部分：寻道时间、旋转延迟时间、传输时间；前两部分基本与读写数据多少无关，通常占访问时间的大头。

**第 9 节**

45. 【考纲 4.7】磁盘调度的重要目标是使磁盘的平均寻道时间最少；常用算法有先来先服务、最短寻道时间优先、扫描等。
46. 【考纲 4.7】先来先服务公平、简单，每个请求都能依次得到处理，但未对寻道优化，平均寻道时间可能较长，只适用于请求数目较少的场合。
47. 【考纲 4.7】最短寻道时间优先每次选距当前磁道最近的请求，每次寻道最短，但不能保证平均寻道时间最短，可能导致进程饥饿。
48. 【考纲 4.7】SCAN 算法优先考虑磁头当前移动方向，扫到再无更外或更里的磁道才折返，可防止饥饿，因规律似电梯又称电梯调度算法。
49. 【考纲 4.7】CSCAN 规定磁头单向移动，移到最外磁道后立即返回最里的待访问磁道，把最小磁道号紧接着最大磁道号构成循环。
50. 【考纲 4.7】NStepSCAN 把请求队列分成若干长度为 N 的子队列，子队列之间按 FCFS、子队列内按 SCAN，避免磁臂粘着；N 很大时接近 SCAN，N 为 1 时退化为 FCFS；FSCAN 只分两个子队列，扫描期间的新请求推迟到下一次扫描。

**第 10 节**

51. 【考纲 4.8】提高磁盘 I/O 速度的五种方法：提前读、延迟写、优化物理块的分布、虚拟盘、磁盘高速缓存。
52. 【考纲 4.8】提前读是按现在请求的内容把预计接着要读的下一块一起读入缓冲；延迟写是把修改过的页暂时留在内存，到将被覆盖前才写盘，减少写盘次数。
53. 【考纲 4.8】优化物理块分布的原则是尽可能把文件存放在同一磁道或相邻磁道，手段有以簇为分配单位和把磁盘分成块组；磁盘 I/O 速度比内存访问速度低 4 至 6 个数量级。
54. 【考纲 4.8】虚拟盘与磁盘高速缓存都在内存中，但虚拟盘的内容完全由用户控制，高速缓存的内容由操作系统控制；虚拟盘通常存放临时性文件。

## 必背数字与公式

| 项目 | 必背内容 |
| --- | --- |
| 设备传输速率 | 低速几个至几百字节每秒，中速数千至数万字节每秒，高速几十万至几兆字节每秒 |
| 中断方式的代价 | 一块 512 B 的数据，若控制器数据寄存器为一字节，每传一字节就要中断一次 |
| 磁盘物理格式 | 一条磁道 30 个固定大小扇区，每扇区 600 字节，其中 512 字节存数据 |
| 磁盘访问时间 | 寻道时间 $+$ 旋转延迟时间 $+$ 传输时间 |
| 每转时间 | 转速 $r$ 转每分时，每转 $60 \div r$ 秒，6000 转每分即 10 ms |
| 平均旋转延迟 | 随机相位下取半转，即 $60 \div (2r)$ 秒，6000 转每分时为 5 ms |
| 教材寻道对比 | 起点 100 号磁道、9 个请求：FCFS 平均 55.3、SSTF 27.5、SCAN 27.8、CSCAN 35.8 条磁道 |
| 缓冲池规模 | 3 种缓冲区、3 个队列、4 种工作缓冲区 |
| 磁盘与内存速度差 | 磁盘 I/O 速度比内存访问速度低 4 至 6 个数量级 |

## 易混对照

| 对照项 | 区别 | 判断依据 |
| --- | --- | --- |
| 独占设备与共享设备 | 独占设备是临界资源，一个进程用完才释放；共享设备在一个进程的任务未完成时即可让另一进程使用 | 另一进程能否在任务中途插进来访问 |
| 缓冲与假脱机 | 缓冲是内存中暂存数据、缓和速度差与大小不一致；SPOOLing 用磁盘上的输入井输出井把独占设备改造成共享设备 | 暂存发生在内存还是磁盘，是否排成作业队列 |
| DMA 与通道 | DMA 是控制器内部的成块搬运，CPU 仍要初始化每次传输；通道是能执行通道程序的专用处理机，可带多个控制器 | 有没有独立的指令执行能力 |
| 轮询与中断 | 轮询由 CPU 反复读状态寄存器；中断由设备在事件到来时发出请求 | 是 CPU 等设备，还是设备通知 CPU |
| 单缓冲与双缓冲 | 单缓冲只有一块系统缓冲区；双缓冲一块供设备填充、一块供 CPU 处理 | 设备填充时 CPU 有没有另一块可用 |
| 安全分配与不安全分配 | 安全分配发出请求即阻塞，摒弃请求和保持条件；不安全分配发请求后继续运行，可能死锁 | 进程拿到设备后会不会再申请其他资源 |
| 固定头磁盘与移动头磁盘 | 固定头每磁道一个磁头、可并行读写；移动头每面一个磁头、须寻道、串行读写 | 读写是否要移动磁臂 |
| 虚拟盘与磁盘高速缓存 | 虚拟盘用内存仿真磁盘、内容由用户控制；高速缓存的内容由操作系统控制 | 缓存内容由谁控制 |
| 逻辑设备名与物理设备名 | 应用中以逻辑设备名请求某类设备，系统执行时使用物理设备名 | 名字是否绑定到具体控制器 |

## 简答答题模板

本章每卷一道简答，问的是某机制的好处，或者某部分的任务，分条答就行。

**设备控制器的功能与结构**

功能六条：接收和识别命令；数据交换；设备状态的了解和报告；地址识别；数据缓冲；差错控制。结构三部分：与处理机的接口由数据线、控制线和地址线组成；与设备的接口传送数据、状态和控制三类信号；I/O 逻辑由指令译码器和地址译码器构成，对命令和地址译码后控制指定设备工作。

**实现设备独立性带来的好处**

三条各一句：应用程序与物理设备无关，系统增减或变更外围设备时不需要修改应用程序；易于处理输入输出设备的故障，例如某台打印机故障时可用另一台不同型号、不同品牌的打印机替换而不用改程序；提高了系统的可靠性，增加了设备分配的灵活性。开头补定义一句：设备独立性指应用程序独立于具体使用的物理设备，靠逻辑设备名到物理设备名的转换实现。

**设备驱动程序的主要任务**

两句核心加一句补充：接受上层软件发来的抽象 I/O 请求，如 read 或 write 命令；把这些请求转换为具体要求后发送给设备控制器，启动设备去执行；同时把设备控制器发来的信号传送给上层软件。可补：驱动程序包含与设备相关的全部代码，每个驱动程序只处理一种或一类紧密相关的设备。

**SPOOLing 系统的组成与特点**

组成四项：输入井和输出井，位于磁盘上分别存放输入与输出数据；输入缓冲区和输出缓冲区，暂存设备与井之间的数据；输入进程与输出进程，完成数据在设备、缓冲区与井之间的搬移；请求 I/O 队列，存放各进程提交的任务。特点三条：提高 I/O 速度；将独占设备改造为共享设备；实现虚拟设备功能。

**DMA 控制方式与中断控制方式的区别**

三点区别：数据搬运者不同，中断方式由 CPU 在中断处理中搬运，DMA 由控制器直接在主存与设备之间搬运；干预次数不同，中断方式每传一块要多次中断，DMA 只在开始设置寄存器、结束时收一次中断；CPU 与 I/O 的并行程度不同，DMA 的并行程度更高。再补 DMA 的四个寄存器与 MAR 递增、DC 递减的过程。

**磁盘访问时间的构成与减少寻道的办法**

三部分：寻道时间是磁臂移动到指定磁道的时间；旋转延迟时间是指定扇区转到磁头下的时间；传输时间是读出或写入数据的时间。前两项与数据量基本无关且占大头。减少办法：优化物理块分布，把文件放在同一磁道或相邻磁道，用簇作分配单位、把磁盘分成块组；用磁盘调度算法缩短平均寻道时间；用提前读、延迟写、磁盘高速缓存与虚拟盘减少实际访问次数。
