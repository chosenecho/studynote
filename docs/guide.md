# 学习指南

复习顺序：先确认用的是哪本教材、哪个版本（见[课程目录](courses/index.md)），再按章读讲解、做练习。来源核对和软件实测状态记在[版本与勘误](errata.md)。

1. 选课：从课程导航进课，用学习导航按大纲条目找讲解和题。
2. 先背：每章另有一页考点，必背清单、数字与公式、易混对照、简答模板、默写自测都放那儿。背完再读讲解。
3. 再读：讲解每节开头那句“必背”是钩子，想不起来就回考点页看一眼。
4. 后练：章节题的答案默认折叠。先写条件和步骤，再展开对答案，计算题别跳单位。
5. 记进度：勾“本章已复习”。首页会记住你读到哪儿、下一步该看哪一章。

## 保存范围

进度、字号、阅读位置和自测记录只存在这台浏览器里，不上传，也不跨设备。清掉站点数据就没了；隐私模式下可能存不住，重要的结果自己留一份。

## 阅读与操作

工具栏可以调字号。宽表格、代码和公式能横向滚动，键盘用户按 Tab 聚焦后再滚。插图默认适屏显示，点开看原图，Esc 关闭。打印时章节答案会自动展开，打完恢复折叠。

## 版本和反馈

题目与图示是自编的，不是真题，也不是官方答案。旧协议和简化模型以所在章节给出的条件为准。

发现问题从[版本与勘误](errata.md)提交：页面链接、位置、现有表述、建议改法、可核对依据。许可相关见[许可与版权](licensing.md)。
