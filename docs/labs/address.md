## 模型约定

按字节编址，页号和物理块号都从 0 起算。页表第 n 项对应第 n 页，`-` 表示这页合法但还没驻留。超出页表范围就是地址越界，和缺页不是一回事。TLB、访存耗时、缺页后的调入，这里都不模拟。

页号 = ⌊逻辑地址 ÷ 页大小⌋；偏移 = 逻辑地址 mod 页大小。物理地址 = 物理块号 × 页大小 + 偏移。

把地址改成 `3072`，会触发缺页；换成 `4096`，则越界。

## 算例：2500 怎样转换为物理地址

按字节编址，页大小为 1024 B，逻辑地址为 2500；页表第 0 至 3 项依次为物理块 5、2、7、未驻留。

1. 2500 = 2 × 1024 + 452，因此页号为 2，页内偏移为 452 B。
2. 第 2 页驻留在物理块 7，转换时保留页内偏移。
3. 物理地址为 7 × 1024 + 452 = **7620**。

地址 3072 落在第 3 页，偏移为 0，这页未驻留，会触发缺页；地址 4096 落在第 4 页，已超出这张页表的范围。两种情形都算不出物理地址。页号、页框和偏移的关系见[分页与地址变换](../courses/operating-systems/chapter-04.md#s4)。
