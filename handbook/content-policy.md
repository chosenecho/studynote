# 内容贡献规则

## 唯一课程资料来源

本仓库的课程资料只取自 OCR 仓库的“成书”。四门课程的成书与历年真题统一存放于独立资料库 `C:\WorkSpace\textbook-library`（含 `成书/`、`题库/`、`笔记/` 与 `多媒体技术与应用_13511_真题资料/`，自身另有 Git 历史），取源一律从该库读取。先把指定版本复制到被忽略的 local/sources/，逐文件核对 SHA-256，再据该快照写作。源仓库可能含未提交的成书修订，以核验清单中的文件内容为版本依据，不只记一个 Git 提交。不得改用制作中间件、其他教材、旧笔记或网络资料补齐课程知识。

逐节保留本地对照记录：快照清单、文件摘要、成书章/小节和行范围、大纲条目、讲解与练习位置；印刷页码仅在源文件明确提供时记录。该记录和原书均不分发。公开仅保留书目、必要的短考点标签与版本边界，不在站点写入本地绝对路径。遇到来源不足先标记并核对成书，不凭模型记忆填写。

对明确勘误须核对所在正文及附录，尚待核实的内容不能当成唯一标准答案。旧版产品、协议简化模型与历史描述要标明适用范围，不据此宣称当前状态。框架文档和软件依赖仍按其正常来源与许可管理，唯一来源限制针对课程知识资料。

## 写作与出题

以 config/syllabus.json 中的复习条目、能力层次与讲解位置为索引，先确定学习目标，再独立组织解释。识记重在辨认概念，领会重在解释机制与边界，应用重在建模、计算及验证。大纲版本要写明确，旧版条目不要称作最新公告。

参考教材题目时，只提取考查知识与技能，重新设计任务、约束、情境、数据及解析。不沿用有辨识度的题干、结构、插图或答案表达；改名、替换数字、翻译、逐句改写并不自动使作品独立。无法独立设计时就不收录该题。

每道章节题注明考点小节、能力层次与完整答案，条件须足够解题。计算须声明位宽、单位、编号、算法变体和成本模型，并用独立计算或模型验证。不要标作真题、官方答案或预测题。交互题库也适用同一规则。

## 引用与图像

优先用自己的讲解替代非必要引用；事实、思想与算法可自行说明，但他人的具体表达、题目安排与图像仍需判断权利。概念图从空白布局绘制，不描摹教材构图。开放资源要核对实际许可、作者、版本、署名和再分发要求。

当前版本不含教材逐字引文。今后如确有必要，使用唯一 quote 标记标出起止，并在 config/quotations.json 登记标识、路径、作者、作品、版本定位、来源链接、引用必要性、传播依据、审阅日期和引文摘要。标注边界内的第三方内容排除在项目开放许可之外。

人工审阅应考虑引用目的、分量、与评论的关系、是否替代原作及对正常使用和权利人利益的影响，不能只看字数或百分比。不确定就暂不公开，或取得覆盖网络传播与预期用途的授权。权利清单检查是发布约束，不是法律认定。

## 站点组织规则

页面放在哪、叫什么、分几层，按下列规则决定。新增页面前先对照本规则，再写正文。

- 层级固定为三层：课程导航（课程落地页）→ 学习导航 / 应试导航（分区落地页）→ 章正文与考点页。内容页不跨层放置。
- 顶层分区固定为：首页、各门课程、复习、关于。复习下分「速查」（易错点清单、术语与缩写表）与「交互练习」（练习入口与各实验）；关于下放学习指南、版本与勘误、许可。不再设独立的课程目录或速查首页这类空壳页。
- 导航标签与页面标题：内容页（章、考点页、练习、速查）的导航标签必须与页面 H1 一致；分区落地页允许用角色名（课程导航、学习概览、考点总览、首页、速查首页、练习入口），这些角色名登记在 `tools/checks/structure.py` 的白名单里。
- 页脚由构建钩子生成：章页脚指向本课程在速查页的分组，考点页页脚指向学习导航、本章练习与速查。页脚只放指路链接，不加标题、不加折叠块，避免改变页面的块结构；也不重复页面开头已有的链接。
- 标题最多四级：H2 是节，H3 是节内条目，H4 是条目内分组，右侧目录展开到四级。跨课程主题在速查页单列「跨课程专题」，不与课程分组并列。
- 每个内容页留反向指路：章页指向速查，考点页指向学习导航与本章练习。没有出链的页面按死端处理。

## 核验与贡献许可

学习文字与自绘图示采用 CC BY 4.0，第一方软件及其题库数据采用 Apache-2.0，第三方资源保持原许可。原文引用始终按登记表排除，不跟随所在文件改换许可。

提交时记录作者来源、独立设计依据、关联考点、数值验证及已知限制。先审正文与附件，再计算摘要；不要为了让检查通过直接重算整张清单。自动检查无法判断文字是否抄袭。

公开归档也属于分发：审计报告、截图、附件、测试夹具都不能夹带教材原题或答案。教材扫描与内部对照资料只放在忽略提交的 local/，不打包进站点、CI 附件或发行版。

## 权利通知

收到可定位的权利主张后，立即移除相关公开页面和下载文件并核查，保存处理记录。确认需要清理历史时，先备份，再列出提交、分支、PR、发行附件、部署与缓存的影响；历史改写需要单独处理，不能把普通删除提交称作彻底撤回。
